## 设计核心

“它不咬你，也不撞你。**它只是落下来，然后打开。**”

**动作姿势**：**落地后完全静止**。荚壳只做一件事：从纵向裂开。

## SRP 特征保留

1. **攻击力为 0**——`ATTACK_DAMAGE = 0.0D`
2. **独立实体**——类注释明确：*"Legacy Ancient Drop Pod (EntityDropPod)"*
3. **由远古恐慑的 `DreadPodGoal` 投放**——两个实体在源码中直接联动
4. **实现类为 Primitive**——`extends PrimitiveParasiteEntity`，而非 ANCIENT 的类
5. **没有行为**——它唯一的动作是打开

## 宝可梦化改造

* **`attackDamage = 0.0` 说明源码根本不把它当战斗单位**。它是**容器**——所以我给了它极端防御向的种族值（防御 140 / 特防 110），攻击 10 / 速度 4
* **它由恐慑的 `DreadPodGoal` 投放**，是那个目标组的产物。所以它的设计必须与恐慑的空投招式**一一对应**
* **它与根团孢囊（`rooterball`）是仅有两只攻击力为 0 的实体**——但根团孢囊完全惰性，它至少会打开并释放

## 特性

**普通特性：荚壳装载（podcargo）**

自身出场时**装载 1 只寄生体**（对应恐慑的 `DreadPodGoal`）。**只有在自身被击倒时才会释放**——被击倒时立刻召唤该单位。对应"打开"这一唯一行为。

**隐藏特性：空投缓冲（droppod）**

自身入场时视为**从高空坠落**：对场上所有对手造成 1/10 其最大 HP 的固定伤害（落地冲击），但自身本回合无法行动。对应 `DreadPodGoal` 的空投方式。

## 独家技能 1：荚壳开启 / Pod Hatch

| 字段 | 值 |
|---|---|
| 属性 | 虫 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 5 |
| 范围 | 全场 |

**效果**：荚壳纵向裂开并**释放装载的 1 只寄生体**（来自白名单）。**使用后自身立即被击倒**（容器打开后即失效）。造成 0 点伤害。

**触发条件**：自身必须仍有装载。

**视觉表现**：荚壳从顶端向下裂开一道暗红缝隙，生物质从内涌出并在地面聚合成一具躯体；随后荚壳整体塌软并干瘪。

**为什么只有它**：`ATTACK_DAMAGE = 0.0` 与 *"Legacy Ancient Drop Pod"* 的翻译。**它是全族唯一「以自我销毁为代价完成职能」的招式**——一个容器打开之后就不再是容器了。
