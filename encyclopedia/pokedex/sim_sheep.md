总和 272。SRP 中 health 13.0 / damage 6.0 / armor **1.3** / knockbackResistance 0.3 / speed 0.28。护甲 1.3 虽然不高，但**它是唯一带纹理变体的家畜**——源码里有 `SHEEP_TEXTURE_VARIANT` 同步数据与专属分支。

## 设计核心

“羊毛是唯一没被寄生组织完全吃掉的部分。所以它比牛和猪都多一层缓冲——**虽然只有一层**。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 保留了羊的颅骨与卷角，面部被寄生组织撑裂 | SRP `sim_sheep` 的宿主外形 |
| 眼睛 | 原本的羊眼被暗红薄膜覆盖，横向瞳孔仍可辨认 | 同化特征 |
| 毛层 | **残留的羊毛层**，下方渗出寄生组织 | `SHEEP_TEXTURE_VARIANT` 与 armor 1.3 |
| 躯干 | 体型中等，比牛略小但比猪大 | health 13.0 |
| 蹄部 | 四蹄保留完整，步态仍像羊 | speed 0.28 |
| 颜色 | 暗红寄生组织 + 残留的白色/灰色羊毛（多套纹理变体） | SRP 纹理系统 |

**动作姿势**：低头、四蹄并拢站立；受惊时会短暂僵直（与真实羊相同），然后才转向逃离或顶撞。

## SRP 特征保留

1. **纹理变体**——`SHEEP_TEXTURE_VARIANT` 同步数据与 `if (kind == Kind.SHEEP)` 专属分支
2. **羊毛残留**——armor 1.3 高于猪（0.1）与马（0.5）
3. **完整四蹄**——mobilitySpeed 0.28
4. **熔解时长 63**——介于猪（25）与牛（73）之间
5. **死亡后留下头颅**——`case SHEEP -> ModEntities.SIM_SHEEP_HEAD.get().create(serverLevel)`
6. **转化为野化羊**——`case SHEEP -> ModEntities.FER_SHEEP.get().create(level)`

## 宝可梦化改造

* **`SHEEP_TEXTURE_VARIANT` 是家畜里唯一的纹理变体系统**，我把它做成隐藏特性：不同纹理对应不同的毛层状态（相当于随机获得一项小增益）
* **它的护甲 1.3 比猪和马都高**，来源是残留的羊毛。我没有把它做成"毛甲很硬"，而是保持在一个很低但确实存在的数值上
* **羊的僵直反应是真实动物行为**，我保留为机制：受惊时会短暂无法行动——这是它唯一的"缺陷"，也和它的宿主身份一致

## 特性

**普通特性：残留毛层（`residualwool`）**

自身受到的第一次攻击伤害减少 25%。对应 armor 1.3 高于同批家畜，但仅够抵挡一次。

**隐藏特性：纹理变体（`texturevariant`）**

出场时随机获得一种羊毛状态：**厚毛**——受到伤害 -10% 但速度 -1 阶段；**稀毛**——速度 +1 阶段但受到伤害 +10%。对应 `SHEEP_TEXTURE_VARIANT`。

## 独家技能 1：毛层顶撞 / Wool Guard Ram

| 字段 | 值 |
|---|---|
| 属性 | 一般 |
| 分类 | 物理 |
| 威力 | 75 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体 |

**效果**：造成伤害。**若本回合自身尚未受到伤害，威力提高 25% 且自身防御提升 1 阶段**（毛层完好时更能顶）。使用后毛层状态重置（下回合恢复为未受损状态）。

**触发条件**：取决于本回合是否已受伤。

**视觉表现**：低头用卷角顶向目标，体表羊毛层在撞击瞬间绷紧并弹开一部分冲击。

**为什么只有它**：armor 1.3 与 `SHEEP_TEXTURE_VARIANT` 的翻译。**它是全族唯一"状态可重置"的防御型招式**——毛层被破坏后会在下一回合恢复，与真实羊毛的再生特性一致。

## 生态

* **生活环境**：感染区外围的“牧场”，与同化牛一同活动
* **食物**：被同化的草料
* **猎物**：不主动狩猎，受惊时会顶撞
* **天敌**：能连续攻击的对手——它的毛层只够挡一次
* **行为**：低头站立、受惊僵直、然后顶撞或逃跑。行为模式与真实羊高度一致
* **群体**：**保持羊群结构**，是群居性最强的同化体之一
* **巢穴**：不建巢，属于巢穴的外围单位
* **繁殖**：不繁殖，由被感染的羊转化而来
* **与其他 SRP 宝可梦关系**：同化羊头（`sim_sheephead`）；可转化为野化羊（`fer_sheep`）
