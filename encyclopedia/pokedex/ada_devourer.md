## 基础种族值

| HP | 攻击 | 防御 | 特攻 | 特防 | 速度 | 总和 |
|---|---|---|---|---|---|---|---|
| 94 | 98 | 82 | 50 | 66 | 48 | **438** |

总和 438（原初形态 392）。各项小幅提升，但**属性发生了根本变化**：SRP 中它新增了 `TryFindWaterGoal` 与 `RandomSwimmingGoal`——它会主动寻找水域并在水中游动。原初形态完全不具备这些目标。

## 设计核心

【同一副下压的颚。区别是原初形态永远待在原地，适应形态带着这套装置下水了。】

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 颚部两侧出现水生寄生体特有的鳃裂结构 | `TryFindWaterGoal` 的水生适应性 |
| 前肢 | 杵状前肢之间长出蹼状膜，水中划动时展开 | `RandomSwimmingGoal` 的游动 |
| 背甲 | 甲壳表面覆有防水生物质层，出水后快速干燥 | 两栖定位 |
| 体侧 | 成排的推进孔，水中会喷出细流 | 水中机动 |
| 皮肤 | 保留正常/厚重两套皮 | `DEVOURER_SKIN_*` 常量组 |
| 颜色 | 深灰褐主体 + 鳃裂暗青 | SRP 模型配色 + 水生特征 |

**动作姿势**：陆地上与原初形态姿态相同；入水后身体拉长、蹼膜展开，改为水平游动。

## SRP 特征保留

1. **保留下压近战**——`DevourerMeleeGoal`（原初形态为 `DevourerAttackGoal`，同一机制的适应版）
2. **新增水域搜寻**——`TryFindWaterGoal`
3. **新增游动**——`RandomSwimmingGoal`
4. **保留两套皮肤**——`DEVOURER_SKIN_NORMAL / HEAVY`
5. **仍具备适应能力**——`supportsDamageAdaptation()` 返回 true

## 宝可梦化改造

* **这一对的 tier 差异是从不能动到能移动**：原初形态源码里 speed = 0.0D，而适应形态新增了 TryFindWaterGoal 与 RandomSwimmingGoal——这是同类里唯一一次从静到动的进化
* `TryFindWaterGoal` 是一个**主动寻找**行为，说明水域对它不是偶然经过而是必须条件。我据此把它做成水属性并给出水域依赖的机制
* 它保留了下压机制（`DevourerMeleeGoal`），所以它的对空能力没有消失——它变成了水陆两用的坠击单位

## 特性

**普通特性：两栖下压（`amphibiousslam`）**

自身接触类招式对飞行/浮空目标威力 +40%；在雨天或水属性场地时，对**所有**目标威力 +25%。对应 `TryFindWaterGoal` 与保留的下压效果。

**隐藏特性：水域优势（`waterexpertise`）**

自身在水属性场地或雨天中每回合结束回复 1/10 最大 HP，且不会被强制换场。对应 `RandomSwimmingGoal` 的水中机动。

## 独家技能 1：坠击·适应 / Gravity Slam (Adapted)

| 字段 | 值 |
|---|---|
| 属性 | 地面 |
| 分类 | 物理 |
| 威力 | 110 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体 |

**效果**：对飞行/浮空目标必中且威力提高 50%；**在水属性场地或雨天时对任何目标均必中且威力提高 35%**。命中后使目标速度下降 2 阶段并封锁先制招式 1 回合。

**触发条件**：空中目标或水域环境均可触发强化，两者同时满足时不叠加（取较高值）。

**视觉表现**：前肢压住目标整体下压；若在水中，身体会带着目标一起沉下去再顶出水面，水花与尘土同时扬起。

**为什么只有它**：**与原初吞噬的坠击是同一个招式**：威力 95→110、追加水域必中（`TryFindWaterGoal` + `RandomSwimmingGoal`）、速度下降维持 2 阶段。它把下压从"对空"扩展到"对水"，这是源码里两个新目标带来的实际战斗变化。

## 生态

* **生活环境**：感染区的水域与海岸线——它会主动寻找水体
* **食物**：被砸落或拖入水中的猎物
* **猎物**：飞行生物、水中生物，以及任何在水边停留的目标
* **天敌**：能在干燥内陆作战的对手（它远离水就会失去一部分优势）
* **行为**：寻找水体—在水中游动—伏击岸边或水面的目标
* **群体**：单独行动，占据一片水域
* **巢穴**：巢穴的**水陆两用单位**
* **繁殖**：不繁殖
* **与其他 SRP 宝可梦关系**：原初吞噬的直接上位形态（`pri_devourer -> ada_devourer`）

## 进化 / 阶段

```
【资料冲突】本对关系未被源码确认。

- 版本 A（命名约定）：`pri_devourer` 与 `ada_devourer` 成对存在，暗示同一物种的两个成熟度。
- 版本 B（`ParasiteTransformation.java`）：`evolutionType()` 中明确写着
  `if (type == ModEntities.PRI_BURROWER.get() || type == ModEntities.PRI_DEVOURER.get()`
  `    || type == ModEntities.PRI_TOZOON.get()) { return null; }`
  —— 也就是说，**这三个原生体被显式排除在 pri_ -> ada_ 的转化路径之外**，
  `devolutionType()` 同样排除了对应的三个适应形态。
- 本次采用：**不承认二者之间存在转化关系**。两只实体都真实存在、都可以设计，
  但它们之间的关系标注为【待核实】。

同样受影响：`pri_burrower` / `ada_burrower`、`pri_tozoon` / `ada_tozoon`。
（其余 9 组 pri_/ada_ 配对不受影响，转化路径在代码中成立。）
```
