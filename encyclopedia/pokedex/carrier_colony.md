## 设计核心

“其他 Preeminent 在天上。**它在水里，而且它在拉人**——你打它的时候，队伍正在变大。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 宽扁的头部，正面有可开合的吸水腔 | CarrierSwimmingGoal |
| 眼睛 | 两排位于头顶的单眼，出水时才会张开 | 潜水与跃出两种状态 |
| 躯干 | **流线型厚重躯体**，体表覆有可闭合的甲板缝 | 水域形态 |
| 尾部 | 粗大的尾部推进结构 | speed 0.242 + WaterLeap |
| 背部 | 背侧有多个可容纳同伴的凹槽 | CarrierRecruitGoal |
| 颜色 | 暗红寄生组织 + 水域形态下的暗青色膜层 | SRP 模型配色 |

**动作姿势**：水中平游时完全流线型；出水跃起时甲板缝同时张开。**从不长时间离水。**

## SRP 特征保留

1. **游泳**——`CarrierSwimmingGoal`
2. **水域跃出**——`CarrierWaterLeapGoal`
3. **持续增益**——`CarrierBuffGoal`，其 `canUse()` 直接返回 `true`（**无时无刻不在生效**）
4. **招募同伴**——`CarrierRecruitGoal`：`tickCount % 20 == 0 && getLeader() == null && getTarget() == null`
5. **最慢速度**——speed **0.242**，PREEMINENT 层最低
6. **不飞行**——`Kind.CARRIER_COLONY(false, ...)`

## 宝可梦化改造

* **`CarrierBuffGoal` 的 `canUse()` 直接 `return true`**——这是我在整个模组里见到的唯一一个**无条件常驻**的目标。它意味着这只生物**每一刻都在给周围的东西加 buff**
* **`CarrierRecruitGoal` 的触发条件很明确**：每 20 tick 检查一次，且只有在**没有队长、没有目标**时才招募。也就是说——**它不打仗的时候在拉人**
* 它是 PREEMINENT 层唯一的**水域**单位（`flying = false` 且有完整的游泳/跃出目标组）。我给了它水属性，因为源码就是这么写的

## 特性

**普通特性：聚落常在（colonyaura）**

自身在场时，我方**所有寄生系宝可梦每回合结束回复 5% 最大 HP**。对应 `CarrierBuffGoal` 的 `canUse() { return true; }`——**常驻、无条件、永不中断**。

**隐藏特性：招募本能（recruitinstinct）**

自身**未成为对手的攻击目标时**，每 2 回合可从以下选择一项：回复 15% 最大 HP、或使我方全体速度提升 1 阶段。对应 `CarrierRecruitGoal` 的"无目标时才招募"。

## 独家技能 1：聚落招募 / Colony Recruit

| 字段 | 值 |
|---|---|
| 属性 | 虫 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 5 |
| 范围 | 我方全体 |

**效果**：**只有自身当前不是对手攻击目标时可用**。为我方全体回复 20% 最大 HP 并各清除 1 层【感染】；同时使自己在本回合内**不会被选为攻击目标**（对应"无目标时才招募"）。造成 0 点伤害。

**触发条件**：**自身必须未被锁定**。

**视觉表现**：背侧凹槽同时张开，向四周释放一圈暗青色脉冲，被扫过的同伴身上寄生组织转为稳定色，而它自己沉入水中只露出头顶的单眼。

**为什么只有它**：`CarrierRecruitGoal` 的逐字翻译（`getTarget() == null` 才启动）。**它是全族唯一「必须不被注意才能发动」的辅助招式**——一个在大后方不断扩军的单位。

## 独家技能 2：尾流运送 / Wake Ferry

| 字段 | 值 |
|---|---|
| 属性 | 水 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 10 |
| 范围 | 我方单体 |

**效果**：**把我方一只宝可梦拉入水中**（若场地无水则改为使其免疫下一次地面类招式），并使其速度提升 1 阶段。对应 `CarrierWaterLeapGoal`。造成 0 点伤害。

**触发条件**：无。

**视觉表现**：尾部推进结构划出一道明显的尾流，同伴被拖入水线以下，随后从另一处跃出——整个过程与它自己的 `CarrierWaterLeapGoal` 完全一致。

**为什么只有它**：聚落载虫是 PREEMINENT 层唯一的水域单位，拥有 `CarrierSwimmingGoal` 与 `CarrierWaterLeapGoal`。主招式用于招募，**这一招把「水域」本身变成给队友的位移工具**。

* **生活环境**：感染区的水体——它**不能长时间离开水**
* **食物**：水中的猎物
* **猎物**：被拖入水的目标
* **天敌**：能把它逼上岸的对手；speed 0.242 让它几乎无法脱离
* **行为**：**游动—增益—招募**。不打仗的时候就在拉人
* **群体**：它本身就是队伍的集结中心
* **巢穴**：巢穴的**水域集结节点**
* **繁殖**：不繁殖，由巢穴生产
* **与其他 SRP 宝可梦关系**：PREEMINENT 层唯一的水域单位；与其余四只的空/陆定位完全不同
