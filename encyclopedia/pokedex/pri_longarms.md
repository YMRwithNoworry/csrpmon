总和 408。攻击 96、护甲 9.0（SRP 中 `ARMOR=9.0`）——它是 PRIMITIVE 层最"重"的一只近战单位。速度 56 中等。真正的特点是它同时拥有**两套独立技能**：近距离震波与中距离灾厄球。

## 设计核心

“它的手臂长到不适合近身，所以它学会了两种打法：**近的用震，远的用扔**。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 小而扁，几乎缩在肩甲之间 | SRP `LongarmsEntity` 的头部结构 |
| 眼睛 | 两枚横向排列的暗红眼，间距极宽 | SRP 模型头部结构 |
| 手臂 | **极长**，末端膨大成钝锤状，长度超过身高 | Longarms 的核心外形特征 |
| 肩甲 | 发达的肩部硬壳，用于承受挥击反冲 | 护甲 9.0 的外形依据 |
| 震波环 | 双锤落地时从小臂根部释放可见的环状冲击 | `STATUS_SHOCKWAVE = 10` / `SHOCKWAVE_COOLDOWN_TICKS = 100` |
| 灾厄球 | 胸口裂口可生成一枚暗紫色球体 | skill 21 的 `ScaryOrbSkill` |

**动作姿势**：重心极低、双臂垂到地面；进入震波状态时会把双锤高高举起再砸下。

## SRP 特征保留

1. **震波技能**——`STATUS_SHOCKWAVE = 10`、`SHOCKWAVE_COOLDOWN_TICKS = 100`，且有精确的触发窗口：水平距离 ≥ `SHOCKWAVE_MIN_DISTANCE_SQR = 4.0`、垂直差在 `-2.0` 到 `+4.0` 之间
2. **灾厄球技能**——`// Legacy EntityShyco tasks.addTask(2, EntityAISkill(this, 80, 4, false, 21)): the scary orb`，实现为 `new ParasiteSkillGoal(this, 21, new ScaryOrbSkill(), 80, 4, false)`
3. **跳向高处目标**——`JumpAtHigherTargetGoal`
4. **水域跳跃**——`WaterLeapAtTargetGoal`
5. **原始类名**——注释明确写出它对应 SRP 的 `EntityShyco`
6. **具备适应能力**——原生体层级 `supportsDamageAdaptation()` 返回 true

## 宝可梦化改造

* **震波的触发窗口非常具体**，我把它如实做成了条件：只在"中距离、且高度差不大"时可用——**贴脸打不出震波，高低差太大也打不出**
* 灾厄球是 skill id 21 的独立技能，冷却 80、射程 4，所以它与震波是两套独立系统，不是同一个招式的两种表现
* 跳向高处目标与水跃这两个移动目标我没有做成招式，而是做进了特性——它们是**位移方式**而不是攻击手段

## 特性

**普通特性：长臂杠杆（`leverarms`）**

自身攻击时的有效距离视为增加 1 格；使用接触类招式时不会被对手的"远距离"保护打断。对应它极长的手臂与 `LONGARMS_MELEE_RANGE_SQR`。

**隐藏特性：高位突进（`highjump`）**

对手处于更高位置（或处于飞行/浮空状态）时，自身招式威力提高 25%。对应 `JumpAtHigherTargetGoal`。

## 独家技能 1：落地震波 / Groundshock

| 字段 | 值 |
|---|---|
| 属性 | 地面 |
| 分类 | 物理 |
| 威力 | 90 |
| 命中 | 95 |
| PP | 10 |
| 范围 | 自身周围 |

**效果**：对场上所有对手造成伤害。**只能在自身与目标水平距离 ≥2 格、且垂直高度差在 -2 到 +4 之间时使用**；距离过近或高低差过大时招式失败。

**触发条件**：距离与高度双条件，直接来自源码的 `SHOCKWAVE_MIN_DISTANCE_SQR` 与 `SHOCKWAVE_MIN_VERTICAL_DISTANCE / MAX`。

**视觉表现**：双锤高举后砸向地面，从小臂根部向外扩散出一圈可见的环状冲击，地面出现放射状裂纹。

**为什么只有它**：`SHOCKWAVE_*` 系列的翻译。它是全族**唯一带"距离窗口"限制**的招式——SRP 里贴脸打不出震波，宝可梦侧同样打不出。

## 独家技能 2：灾厄球 / Scary Orb

| 字段 | 值 |
|---|---|
| 属性 | 毒 |
| 分类 | 特殊 |
| 威力 | 70 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体，射程 4 |

**效果**：必中。命中后使目标获得 1 层【感染】并降低 1 阶段特防。

**触发条件**：无。

**视觉表现**：胸口裂口生成一枚暗紫色球体，缓慢飘向目标后贴附并渗入。

**为什么只有它**：skill 21 `ScaryOrbSkill` 的翻译——**它与震波是完全独立的两套系统**（射程 4 vs 贴身、冷却 80 vs 100）。这是长臂少见的"近远双线"设计，也是它区别于其他原生体的核心。

## 生态

* **生活环境**：感染区中开阔的中距离地带——它需要空间挥动手臂
* **食物**：被震波震倒的猎物
* **猎物**：成群但保持距离的目标
* **天敌**：能贴脸压制的快速单位——震波在近距离失效
* **行为**：保持中距离游走，用灾厄球消耗；一旦对手进入窗口就砸地震波
* **群体**：单独行动，长手臂在狭窄处会互相妨碍
* **巢穴**：巢穴的中距离火力点
* **繁殖**：不繁殖
* **与其他 SRP 宝可梦关系**：适应长臂的前置形态（`pri_longarms -> ada_longarms`）；对应 SRP 原始类名 `EntityShyco`
