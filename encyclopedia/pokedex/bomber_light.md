总和 432。SRP 中 health 75.0 / armor 20.0 / damage 25.0 / speed 0.27 / **knockbackResistance 0.15（PURE 层最低）** / followRange 32。**`flying = true, climbs = false`**——它是空中单位，而 0.15 的击退抗性说明它**在空中很轻**。

## 设计核心

“它不上岸。它在上面转，然后把东西扔下来——**而它自己一碰就飘。**”

**动作姿势**：全程滞空；投弹时短暂收翼俯冲，随后立刻爬升——**落地对它来说是危险的**。

## SRP 特征保留

1. **飞行**——`Kind.BOMBER_LIGHT(true, false, ...)`，flying = true
2. **不攀爬**——climbs = false
3. **最低击退抗性**——**0.15**，PURE 层最低，对应它在空中的轻质结构
4. **高护甲**——armor 20.0，与观察者同级
5. **中等生命**——health 75.0
6. **方块破坏能力**——`blockHardness = 5.0F` / `blockRange = 2.0D`

## 宝可梦化改造

* **armor 20.0 配 knockbackResistance 0.15 是一个矛盾组合**：它很硬，但一推就飞。我据此把它设计成**空中单位特有的脆弱平衡**——远程打不动它，但任何位移效果都能把它掀翻
* **它与重轰炸机（`bomber_heavy`，PREEMINENT 层）是同一系列的两端**。我在这里只设计轻轰炸机，重轰炸机留到 PREEMINENT 层——**它们不是同一只生物的两个形态，是两种不同的实体**
* 它 `climbs = false` 说明它完全不适应垂直面——**它的世界只有空中和地面两个平面**

## 特性

**普通特性：轻质翼膜（lightwings）**

自身处于浮空状态时受到的远程招式伤害减少 25%；但**受到任何击退/位移类效果时，位移量加倍**。对应 armor 20.0 与 knockbackResistance 0.15。

**隐藏特性：空中轰炸（aerialbombing）**

自身处于浮空状态时，投弹类招式的 PP 消耗减半。对应 flying = true 的空中定位。

## 独家技能 1：轻量轰炸 / Light Bombing Run

| 字段 | 值 |
|---|---|
| 属性 | 飞行 |
| 分类 | 物理 |
| 威力 | 90 |
| 命中 | 95 |
| PP | 10 |
| 范围 | 单体，全场 |

**效果**：**只有自身处于浮空状态时可用**。无视距离造成伤害并使目标获得 1 层【感染】。**使用后自身击退抗性在本回合内降为 0**（投弹动作让它在空中失去平衡）。

**触发条件**：**必须浮空**。

**视觉表现**：收翼俯冲、从腹部投下载荷后立刻张开翼膜爬升，整个动作中间有一段明显的失衡摆动。

**为什么只有它**：flying = true 与 knockbackResistance **0.15** 的组合翻译。**它是全族唯一「攻击后自己变脆」的空中单位**——投弹与稳定不可兼得。

## 生态

* **生活环境**：感染区上空——它不落地
* **食物**：靠巢群供给
* **猎物**：地面上的移动目标
* **天敌**：**任何位移类效果**——0.15 的击退抗性意味着它很容易被打偏
* **行为**：盘旋—俯冲投弹—爬升。**从不与地面单位接触**
* **群体**：通常 2~3 只分层盘旋
* **巢穴**：巢穴的**空中打击单位**
* **繁殖**：不繁殖，由巢穴生产
* **与其他 SRP 宝可梦关系**：与重轰炸机（`bomber_heavy`，PREEMINENT 层）同系列；与治安者形成机动性对照（一个只飞，一个只会走）
