## SRP 特征保留

1. **加持半径随阶数增长**——`getBoundingBox().inflate(16.0D + stage * 4.0D)`，本阶 **32 格**
2. **两个命名效果 PIVOT 与 PARATE**——等级 `Math.max(0, stage - 1)` = **3**，持续 300 tick
3. **建立从属关系**——`StatusEffectEvents.linkToRooter(ally, this)` 把友军登记进 `ROOTER_OWNERS` 映射
4. **排除同类**——`if (nexus.activeKind().family == Family.ROOTER || nexus.activeKind().isRooterBall()) continue;` 不给根须柱自己人加
5. **固定脉动节奏**——`supportCooldown = 50`
6. **全 NEXUS 最高生命**——health **300.0**

## 宝可梦化改造

* **这是三个家族里最容易被误解的一个**：它和召唤柱共用数值表，但源码里 `applyRooterSupport()` 对它做的是**给周围寄生体加两个效果并登记从属**——**它一个兵都不放**
* **半径公式 `16.0D + stage * 4.0D` 是源码写死的**：32 格。这个半径比召唤柱与调度柱的 `blockRange` 大得多（后者四阶才是 18 格），说明**它的定位是"覆盖整个战场"而不是"影响一片区域"**
* **`linkToRooter` 会把友军写进一个 `ROOTER_OWNERS` 映射**——这是我在整个模组里见过的唯一一处"建立从属关系"的实现。我把它做成了机制：**它的增益只在它活着的时候有效**
* **300 点生命是全 NEXUS 最高**（召唤柱终阶 220、调度柱终阶 250）。它是最难拆掉的一根柱子

## 特性

**普通特性：终阶根系（rooterlink）**

自身每回合结束时，为**自身 32 格内的所有寄生系友方**施加 PIVOT 与 PARATE 效果，等级 3，持续 3 回合。**同类不享受此效果**（源码明确排除 ROOTER 与 ROOTERBALL）。

**隐藏特性：从属登记（rooterowners）**

被自身加持过的友方**在自身存活期间**额外获得 10% 速度。**自身被击倒时该增益立即消失**（对应 `ROOTER_OWNERS` 映射的生命周期）。

## 独家技能 1：根系脉动·终阶 / Rooter Pulse IV

| 字段 | 值 |
|---|---|
| 属性 | 地面 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 15 |
| 范围 | 自身周围 32 格 |

**效果**：为范围内**所有寄生系友方**施加 PIVOT 与 PARATE 各 1 级（本阶半径 **32 格**，等级 **3**），持续 3 回合。**同类不享受**。造成 0 点伤害。

**触发条件**：无。

**视觉表现**：根系末端的脉动节点同时亮起，一圈暗褐色脉冲沿根系向四周扩散至 32 格外，被扫过的寄生体体表浮现暗红光泽。

**为什么只有它**：`applyRooterSupport(stage)` 的逐字翻译：半径 `16.0 + stage * 4.0`、等级 `Math.max(0, stage - 1)`、排除同类。**它是全族唯一「一个伤害都不造成、也不召唤任何东西」的专属招式**。

## 独家技能 2：从属共担·四阶 / Subordinate Cover IV

| 字段 | 值 |
|---|---|
| 属性 | 地面 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 10 |
| 范围 | 自身周边 |

**效果**：**把自身本回合将受到的伤害转移给我方被加持过的单位**（对应 `StatusEffectEvents.linkToRooter` 建立的 `ROOTER_OWNERS` 从属关系）：由最多 3 只从属单位平摊。造成 0 点伤害。

**触发条件**：我方场上必须有已被自身加持过的单位。

**视觉表现**：根系末端的节点同时亮起并向后收束，伤害在触及柱体前先被一圈暗褐脉冲分散到四周的被加持单位身上。

**为什么只有它**：`linkToRooter` 是源码中唯一一处「建立从属关系」的实现，它把友军写进 `ROOTER_OWNERS` 映射。主招式负责加持，**这一招把从属关系变成实际的分担**。

## 生态

* **生活环境**：感染区的地表——它的根系决定它的影响范围
* **食物**：通过庞大的根系网吸取养分
* **猎物**：无。**它不召唤也不狩猎**
* **天敌**：能突破 300 点生命与 28 点护甲的手段
* **行为**：**完全静止**。脉动—加持—再脉动。每 50 tick 一次
* **群体**：周围有被它加持的寄生体活动，但它自己不参与战斗
* **巢穴**：**巢穴的支援层**，九阶体系第 4 环
* **繁殖**：不繁殖，通过根系扩张
* **与其他 SRP 宝可梦关系**：**ROOTER 家族第 4 阶**；与 BECKON（召唤）和 DISPATCHER（收纳+铺雾）共用数值表但**职能完全不同——它只加持**
