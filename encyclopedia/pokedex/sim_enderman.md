## 基础种族值

| HP | 攻击 | 防御 | 特攻 | 特防 | 速度 | 总和 |
|---|---|---|---|---|---|---|---|
| 64 | 78 | 52 | 72 | 56 | 92 | **414** |

总和 414。速度 **92** 是全图鉴最高——SRP 中它还有 `ATTACKING_SPEED_BOOST_ID`（攻击时附加速度提升）。它最独特的地方不是自己传送：类注释原文是 teleports itself **and idle parasite allies** around its prey。

## 设计核心

“末影人会瞬移。被同化之后，**它带着整个小队一起瞬移**——你面对的不是一个会闪现的敌人，是一群会在你背后同时出现的。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 保留了末影人的高瘦头骨轮廓，双眼位置被两条暗红光带取代 | SRP `sim_enderman` 的宿主外形 |
| 躯干 | 四肢异常细长，关节处可见寄生组织从内部撑开 | 宿主结构保留 |
| 粒子 | 移动时拖出暗红与紫色混杂的粒子轨迹 | 末影人粒子的寄生化 |
| 体表 | 覆有一层流动的暗红薄膜，传送时会短暂透明 | `SCREAMING` / `CRAWLING` 状态 |
| 共鸣节 | 胸口有一处持续脉动的寄生结节，用于同步同伴 | `ALLY_TELEPORT_COOLDOWN = 40` 的群体传送 |
| 颜色 | 暗红寄生膜 + 残留的末影人黑紫 | SRP 模型配色 |

**动作姿势**：静止时直立不动、双手垂在身侧；传送发动前胸口的共鸣节会先亮起，然后整群同时消失。

## SRP 特征保留

1. **自身传送**——`SELF_TELEPORT_COOLDOWN = 20`
2. **同伴传送**——`ALLY_TELEPORT_COOLDOWN = 40`，类注释明确写出它会 teleport idle parasite allies
3. **目标宽限时间**——`TARGET_GRACE_TICKS = 80`
4. **攻击时提速**——`ATTACKING_SPEED_BOOST_ID`
5. **状态同步数据**——`SCREAMING` / `CRAWLING` / `TEXTURE_VARIANT` / `PARASITE_STATUS`
6. **可参与融合**——`mergeValue` 与熔解系统

## 宝可梦化改造

* **带同伴一起传送是这个模组里最有战术价值的行为之一**。我把它做成核心机制：它不是自己逃跑，而是**把整个小队重新部署到目标周围**
* `SELF_TELEPORT_COOLDOWN = 20` 与 `ALLY_TELEPORT_COOLDOWN = 40` 是**两个不同的冷却**——自身传送的频率是群体传送的两倍。我如实保留了这种不对称
* 它速度 92 是最高值，但我**没有**把它做成单纯的快攻手——它的威胁在于位置重构，速度只是配套

## 特性

**普通特性：同伴跃迁（`alliedwarp`）**

自身每次使用传送类招式后，我方下一只上场的宝可梦获得先制 +1（持续 1 回合）。对应 `ALLY_TELEPORT_COOLDOWN = 40` 的群体传送。

**隐藏特性：攻击提速（`attackboost`）**

自身造成伤害的回合结束时速度提升 1 阶段（最多 +2）。对应 `ATTACKING_SPEED_BOOST_ID`。

## 独家技能 1：群体跃迁 / Group Warp

| 字段 | 值 |
|---|---|
| 属性 | 超能 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 10 |
| 范围 | 我方全体 |

**效果**：**把自身与我方全体一同重新部署到对手周围**：本回合我方全体受到的伤害减少 30%，且下一回合我方全体的先制招式先制度 +1。使用后 3 回合内不能再次使用。

**触发条件**：冷却 3 回合，对应 `ALLY_TELEPORT_COOLDOWN = 40` 长于自身传送的 `SELF_TELEPORT_COOLDOWN = 20`。

**视觉表现**：胸口共鸣节亮起，我方全体身上同时浮现末影粒子并短暂透明，随后在对手四周同时显形。

**为什么只有它**：类注释中 teleports itself and idle parasite allies around its prey 的直接翻译。**它是全族唯一以重新部署整个队伍为核心的招式**——不是位移，是阵型重构。

## 独家技能 2：自身闪现 / Self Warp

| 字段 | 值 |
|---|---|
| 属性 | 超能 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 15 |
| 范围 | 自身 |

**效果**：先制 +2，清除自身所有被标记状态并提升 1 阶段闪避（最多 +2）。冷却仅 1 回合。

**触发条件**：无。

**视觉表现**：身影在暗红粒子中瞬间消失并在数格外的位置重新显形，轨迹上留下紫色残影。

**为什么只有它**：`SELF_TELEPORT_COOLDOWN = 20` 的翻译——**自身传送的频率是群体传送的两倍**（20 对 40）。两个冷却的不对称被完整保留为两个独立招式。

## 生态

* **生活环境**：感染区各处——它没有固定领地，哪里需要就传送过去
* **食物**：靠巢群供给
* **猎物**：它不单独狩猎，负责**把同伴送到猎物身边**
* **天敌**：能封锁位移的手段（场地、特性）；它自身耐久一般
* **行为**：静止—传送—重新部署同伴。它是巢群的调度者而不是主攻手
* **群体**：总是与同伴一起行动——单独一只的战术价值远低于带队的一只
* **巢穴**：巢穴的**机动调度单位**
* **繁殖**：不繁殖，由被感染的末影人转化而来
* **与其他 SRP 宝可梦关系**：同化末影人头（`sim_endermanhead`）；可转化为野化末影人（`fer_enderman`）
