总和 464。SRP 中 health **80.0** / armor 20.0 / damage 22.0 / speed 0.27 / knockbackResistance 0.40 / followRange 32。**`flying = true, climbs = false`**。注意：它的全部参数与 `SEEKER` **逐项完全相同**——而源码把 SEEKER 的 tier 记为 PREEMINENT。

## 设计核心

“轻轰炸机负责扔，它负责**看**——它是巢群在天上的那只眼睛。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 横向展开的宽扁头部，正面有整片感光面 | 监视定位 |
| 眼睛 | **整片头部都是感光组织**，没有独立眼点 | 全向监视 |
| 翼膜 | 一对宽大翼膜，比轻轰炸机更薄更长 | flying = true |
| 躯干 | 中空轻质结构，腹部没有弹仓 | 不投弹 |
| 背部 | 脊背有一列向上的信号结节 | 向巢群回传 |
| 颜色 | 暗红寄生组织 + 翼膜半透明暗褐 | SRP 模型配色 |

**动作姿势**：长时间悬停在同一位置，几乎不移动；头部会缓慢整体转向以覆盖更大视野。

## SRP 特征保留

1. **飞行**——`Kind.OVERSEER(true, false, ...)`，flying = true
2. **不攀爬**——climbs = false
3. **PURE 层最高生命之一**——health **80.0**，与典狱长并列
4. **高护甲**——armor 20.0，与轻轰炸机同级
5. **方块破坏能力**——`blockHardness = 5.0F` / `blockRange = 2.0D`

## 宝可梦化改造

* **它的全部参数与 `SEEKER` 逐项相同**（80/20/22/0.27/0.40/32/5.0/2.0）——而源码把 SEEKER 归入 PREEMINENT。这意味着**同一组数值被用在了两个不同 tier 的实体上**。我如实记录这一点，并把监视者放在 PURE（依源码 tier）
* **它不投弹**（腹部没有弹仓），这与轻轰炸机形成分工：**一个负责打，一个负责看**
* 它的定位是**情报节点**：不造成大量伤害，但让整个巢群知道你在哪

## 特性

**普通特性：空中监视（aerialwatch）**

自身在场时，对手**无法获得闪避率提升**（它一直在看）。对应 flying = true 与全向感光头部。

**隐藏特性：信号回传（signalrelay）**

自身在场时，我方**所有 PURE 层级宝可梦的命中率提高 10%**。对应脊背的信号结节——**它把看到的东西传回巢群**。

## 独家技能 1：监视标记 / Overseer Mark

| 字段 | 值 |
|---|---|
| 属性 | 恶 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 15 |
| 范围 | 全体对手 |

**效果**：对场上**所有对手**施加【猎物标记】（对应它全向感光头部没有盲区）。被标记的目标**受到的感染伤害提高 25%**。造成 0 点伤害。

**触发条件**：无。

**视觉表现**：头部感光面整体亮起，视野范围内所有目标身上同时浮现暗红标记纹，纹路随后缓缓渗入皮肤。

**为什么只有它**：flying = true 与全向感光头部的翻译。**它是全族唯一「一次标记全体」的招式**——哨卫只能锁一个，它在天上，看得见所有人。

## 生态

* **生活环境**：感染区上空——它悬停在固定位置，很少移动
* **食物**：靠巢群供给
* **猎物**：不直接狩猎，负责定位
* **天敌**：能打到高空的远程手段
* **行为**：悬停—扫描—标记—回传。**它几乎不参与战斗**
* **群体**：通常单独悬停在一片区域上方
* **巢穴**：巢穴的**空中情报节点**
* **繁殖**：不繁殖，由巢穴生产
* **与其他 SRP 宝可梦关系**：与轻轰炸机同为 PURE 层空中单位，但分工明确（一个投弹、一个监视）；**其全部参数与 SEEKER 逐项相同，而后者 tier 为 PREEMINENT**
