总和 212。SRP 中 health **4.5** / damage **2.7** / speed 0.30 / followRange 16。它的数值与**同化人类头完全相同**（4.5/2.7/0.30/16）——**但它是一个完全独立的类**，带有自己的 **`COTH_AURA_RADIUS = 3.0D`** 与 `HeadCothCloudGoal`。

## 设计核心

“数值上和人类头一模一样。区别在于——**它会往外冒巢群信号**。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 整只冒险者头，仍戴着残破的头盔 | 独立类 `SimAdventurerHeadEntity` 的宿主外形 |
| 眼睛 | 两处暗红凹陷，眼周有持续外溢的粒子 | `HeadCothCloudGoal` 的光环 |

| 颜色 | 暗红寄生组织 + 残留的皮革头盔 | SRP 模型配色 |

**动作姿势**：贴地匍匐，但头顶持续冒出一层薄薄的光雾；跃起时整颗头会短暂离地。

## SRP 特征保留

1. **感染与重建**——与所有头颅共享的机制
2. **巢群光环**——`COTH_AURA_RADIUS = 3.0D` 与 `HeadCothCloudGoal`
3. **跳跃数据**——`LEAP_TICKS` 同步数据
4. **命中施加 COTH 与恐惧**——源码注释：*"Legacy EntityParasiteBase:845 / EntityPInfected:168: on-hit COTH and FEAR, as the sibling head class does."*
5. **数值与人类头相同**——4.5 / 2.7 / 0.30 / 16.0，但**是独立的类**

## 宝可梦化改造

* **它与同化人类头的数值完全相同，但源码给了它独立的类与独立的光环系统**。如果只看数值，这两颗头必然变成换皮——所以我按**机制**区分：人类头什么都没有，冒险者头带着光环
* 它继承了同化冒险者 body 的 `COTH_AURA` 设计（那边是 `COTH_AURA_INTERVAL_TICKS = 20`）——**身体死了，光环没有断**
* 它的 `LEAP_TICKS` 说明它会跳，这与贴地啃咬的其他头颅不同

## 特性

**普通特性：断体重建（`rebuildbody`）**

自身在场满 3 回合后，攻击与防御各提升 2 阶段。若在 3 回合内被击倒则不会触发。

**隐藏特性：残存光环（`residualaura`）**

自身每 2 回合结束，对场上对手全体施加 1 层【感染】。对应 `COTH_AURA_RADIUS = 3.0D` 与 `HeadCothCloudGoal`——**身体死了，巢群光环没有断**。

## 独家技能 1：颅群云 / Cranial Hive Cloud

| 字段 | 值 |
|---|---|
| 属性 | 虫 |
| 分类 | 特殊 |
| 威力 | 55 |
| 命中 | 100 |
| PP | 15 |
| 范围 | 全体对手 |

**效果**：对场上所有对手造成伤害并各附加 2 层【感染】。**使用后自身进入跳跃状态**（下一回合先制 +1）。

**触发条件**：无。

**视觉表现**：头顶的暗红光雾骤然扩散成一片云，覆盖周围区域；随后整颗头弹跳而起脱离原地。

**为什么只有它**：`HeadCothCloudGoal` 与 `COTH_AURA_RADIUS = 3.0D` 的翻译，结合 `LEAP_TICKS` 的跳跃。**它是唯一把"光环"与"跳跃"绑在同一个招式上的头颅**——铺完感染就跳走。

> 观察记录：基础数值与同化人类头完全相同（4.5 / 2.7 / 0.30 / 16.0）。

 ——结论：**数值一样，机制不一样**。身体死了，光环还在。
