## 基础种族值

| HP | 攻击 | 防御 | 特攻 | 特防 | 速度 | 总和 |
|---|---|---|---|---|---|---|---|
| 84 | 88 | 76 | 44 | 58 | 42 | **392** |

总和 392。HP 84 / 攻击 88 / 防御 76——它是 PRIMITIVE 层最"厚"的一只。速度只有 42。它有一个全族独有的近战效果：**不造成额外状态，而是把目标往下砸**（源码：`target.setDeltaMovement(...add(0.0D, -0.5645D, 0.0D))`）。

## 设计核心

“它打你的方式不是让你中毒，是**让你落地**——不管你在树上、岩壁上还是半空中。”

**动作姿势**：四足撑开、身体压低，攻击时不是前扑而是**整体下压**。

## SRP 特征保留

1. **下压近战**——`target.setDeltaMovement(target.getDeltaMovement().add(0.0D, -0.5645D, 0.0D))`，它是全族唯一近战带垂直位移效果的生物
2. **专属攻击目标**——`DevourerAttackGoal`
3. **两套皮肤**——`DEVOURER_SKIN_NORMAL = 0` / `DEVOURER_SKIN_HEAVY = 7`
4. **高耐久低速度**——HP 84 / 防御 76 / 速度 42
5. **具备适应能力**——原生体层级 `supportsDamageAdaptation()` 返回 true

## 宝可梦化改造

* **`-0.5645` 这个数字是关键**：它不是伤害，是**位移**。所以我把它翻译成"把目标从空中打到地面"——**这是全族唯一的对空手段**
* 在宝可梦里没有 Y 轴，所以我用"对飞行/浮空目标必中且威力提升"来表达同一个意思
* 它的两套皮肤我做成特性分支：正常皮均衡，厚重皮更慢更硬

## 特性

**普通特性：坠压（`downforce`）**

自身接触类招式对**飞行属性或处于浮空状态**的目标威力提高 40%，且命中后使其速度下降 1 阶段。对应近战向下的位移效果。

**隐藏特性：厚重甲（`heavycarapace`）**

自身皮肤为"厚重"时受到的伤害减少 20% 但速度下降 1 阶段；为"正常"时无额外效果。对应 `DEVOURER_SKIN_NORMAL / HEAVY`。

## 独家技能 1：坠击 / Gravity Slam

| 字段 | 值 |
|---|---|
| 属性 | 地面 |
| 分类 | 物理 |
| 威力 | 95 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体 |

**效果**：对飞行属性或浮空目标**必中**且威力提高 50%；命中后使目标速度下降 2 阶段并在本回合无法使用先制招式。对地面目标按 95 结算且无追加效果。

**触发条件**：目标必须处于空中/浮空状态才能触发强化。

**视觉表现**：前肢从上方压住目标并整体下压，被击中的目标垂直下坠并砸进地面，扬起一圈尘土。

**为什么只有它**：`setDeltaMovement(...y - 0.5645)` 的翻译。**它是全族唯一的对空招式**——不造成状态，只负责把飞行的东西打下来。这个效果在 SRP 里是物理位移，在宝可梦里是"对空特攻"。

## 生态

* **生活环境**：感染区的开阔地面——它需要空间完成下压动作
* **食物**：被砸落后无法逃脱的猎物
* **猎物**：飞行生物与喜欢待在高处的目标
* **天敌**：纯地面单位（它的对空优势用不上）与远程消耗
* **行为**：缓慢推进，靠近后整体下压。不追逃跑的目标——它更愿意等下一个落地的
* **群体**：单独行动，体型决定它需要较大领地
* **巢穴**：巢穴的**防空单位**
* **繁殖**：不繁殖
* **与其他 SRP 宝可梦关系**：适应吞噬的前置形态（`pri_devourer -> ada_devourer`）

## 进化 / 阶段

```
【资料冲突】本对关系未被源码确认。

- 版本 A（命名约定）：`pri_devourer` 与 `ada_devourer` 成对存在，暗示同一物种的两个成熟度。
- 版本 B（`ParasiteTransformation.java`）：`evolutionType()` 中明确写着
  `if (type == ModEntities.PRI_BURROWER.get() || type == ModEntities.PRI_DEVOURER.get()`
  `    || type == ModEntities.PRI_TOZOON.get()) { return null; }`
  —— 也就是说，**这三个原生体被显式排除在 pri_ -> ada_ 的转化路径之外**，
  `devolutionType()` 同样排除了对应的三个适应形态。
- 本次采用：**不承认二者之间存在转化关系**。两只实体都真实存在、都可以设计，
  但它们之间的关系标注为【待核实】。

同样受影响：`pri_burrower` / `ada_burrower`、`pri_tozoon` / `ada_tozoon`。
（其余 9 组 pri_/ada_ 配对不受影响，转化路径在代码中成立。）
```

## 图鉴描述 1

> 它不会咬住你不放，也不用毒。它只做一件事：把你从你站着的地方压到地上。

## 图鉴描述 2

> 观察记录：样本对悬停目标近战命中后，目标垂直位移 -0.5645 并落地。
对地面目标命中时该位移无实际效果。
 ——结论：它专门对付**待在高处的东西**。站在地上反而更安全。
