总和 574。SRP 中 health 310.0 / armor 15.5 / damage 70.0 / speed 0.28 / knockbackResistance 2.0 / followRange 80 / blockRange 5.0。**它与 `WRAITH` 的全部参数逐项完全相同**——区分只能靠源码里的弹药分支。

## 设计核心

“幽魂会换弹药。**波格尔永远用同一种**——它的威胁不在于变化，在于它从不失误。”

| 部位 | 设计 | 来源 |

| 头部 | 扁平的头冠，正面有一组固定的发射腔 | 定式炮击 |

**动作姿势**：滞空时保持固定高度与朝向；发射节奏恒定，动作几乎像机械。

## SRP 特征保留

1. **单一弹种**——`if (activeKind() == Kind.BOGLE) { mode = ParasiteProjectileEntity.Mode.LENCIA_BALL; }`
2. **发射参数**——`LegacyProjectileAttackGoal(60, 30, 3)`（60 tick 蓄力、30 tick 间隔、3 发）
3. **完全免疫击退**——knockbackResistance **2.0**（超过 1.0）
4. **最远的感知范围**——followRange **80**
5. **最远的方块触及**——`blockRange = 5.0D`
6. **飞行**——`flying = true`
7. **共享的目标组**——`PreeminentChargeAttackGoal` / `LegacyProjectileAttackGoal(60, 30, 3)` / `PreeminentRandomFlightGoal`

## 宝可梦化改造

* **它与幽魂数值逐项相同，唯一区别是弹药**：波格尔只发射 `LENCIA_BALL`，幽魂在 `ELVIA_BALL` 与 `ELVIA_NADE` 之间交替。**同一具身体，两套补给**
* 所以我把它设计成**定式型**：不变化、不切换，靠节奏稳定取胜。这与幽魂的"交替投掷"形成直接对照
* 它与幽魂共享全部三个目标（冲锋、投射、随机飞行），说明源码把它们当作同一种战斗方式的两种变体

## 特性

**普通特性：定式装填（fixedloading）**

自身连续使用同一招式时，**每连续一次威力提高 15%（最多 +45%）**，但**无法在同一回合内切换招式类型**。对应它只发射 LENCIA_BALL 的单一弹种。

**隐藏特性：不换弹药（noresupply）**

—（说明性特性）：源码中波格尔的投射物分支**只有 `LENCIA_BALL` 一种**，没有交替逻辑。因此本条目不提供多弹种切换机制。

## 独家技能 1：定式弹幕 / Lencia Barrage

| 字段 | 值 |
|---|---|
| 属性 | 超能 |
| 分类 | 特殊 |
| 威力 | 60 |
| 命中 | 95 |
| PP | 10 |
| 范围 | 单体，全场 |

**效果**：**连续攻击 3 次**（每次威力 60，对应 `LegacyProjectileAttackGoal(60, 30, 3)` 的 3 发）。**连续使用本招式时，每回合威力提高 15%（最多 +45%）**。

**触发条件**：无。

**视觉表现**：头冠发射腔依次开启，以完全恒定的间隔射出三枚同型弹体，弹道一致、节奏毫无变化。

**为什么只有它**：`LegacyProjectileAttackGoal(60, 30, 3)` 与 `Mode.LENCIA_BALL` 的翻译。**与幽魂的对照就在这里**：波格尔是同一发打三次，幽魂是三种不同的东西轮流打。

## 独家技能 2：定式弹雨 / Lencia Rain

| 字段 | 值 |
|---|---|
| 属性 | 虫 |
| 分类 | 特殊 |
| 威力 | 40 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 全体对手 |

**效果**：对场上**所有对手**造成伤害并各附加 1 层【感染】。**连续使用时每次威力提高 10%（最多 +30%）**。

**触发条件**：无。

**视觉表现**：头冠发射腔同时全开，同型弹体以完全一致的间隔向全场倾泻，弹幕密度均匀得几乎像仪器。

**为什么只有它**：波格尔的弹药分支只有 `Mode.LENCIA_BALL` 一种，与幽魂的交替形成对照。主招式是单体三段，**这一招是同一弹种的全场覆盖**——同一种弹药，两种投放范围。
