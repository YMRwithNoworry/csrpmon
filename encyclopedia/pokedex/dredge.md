## 基础种族值

| HP | 攻击 | 防御 | 特攻 | 特防 | 速度 | 总和 |
|---|---|---|---|---|---|---|---|
| 72 | 58 | 66 | 62 | 64 | 36 | **358** |

总和 358，是全族最"平均"的一只。它的强度不在任何单项上，而在**四种状态的切换**：SRP 中它有 IDLE / COMBAT / SPRINT / **PULLING** 四个状态机分支，产物完全取决于它当前在做什么。

## 设计核心

“它不追你，也不需要追你——它有一根绳子。真正让人绝望的不是被它打到，是**发现跑不掉**。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 前倾的锥形，下颚处挂着一团可伸缩的黏性组织 | SRP `DredgeEntity` 的拖拽器官 |
| 眼睛 | 两枚水平排列的黄绿色眼，始终朝下看 | SRP 模型头部结构 |
| 拖拽索 | 从口部伸出的半透明黏索，长度随拖拽进度增长 | `MAX_PULL_TICKS = 200` / `PULL_STRENGTH = 0.13` |
| 肢体 | 后肢极度发达、呈折叠蓄力状 | `MAX_LIQUID_LEAPS = 8` / `LIQUID_LEAP_INTERVAL_TICKS = 21` 的液体跳跃 |
| 体表 | 覆着一层湿润的反光膜，脱水后会变暗 | `LIQUID_LEAP_HORIZONTAL_SPEED = 1.2` 的液体依赖 |
| 状态光 | 进入 PULLING 状态时索体亮起暗青色 | 四状态机的可视化 |

**动作姿势**：平时半蹲蓄力；进入拖拽状态后身体后倾、四足钉地，把索绷直。

## SRP 特征保留

1. **四状态机**——`STATUS_IDLE / STATUS_COMBAT / STATUS_SPRINT / STATUS_PULLING`
2. **拖拽**——`MAX_PULL_TICKS = 200`、`PULL_STRENGTH = 0.13D`、同步数据 `TARGET_ENTITY` 与 `PULLING`
3. **液体跳跃**——`MAX_LIQUID_LEAPS = 8`、间隔 21 tick、水平 1.2 / 垂直 0.3
4. **持续再生**——`REGENERATION_AMOUNT = 4.0F`，每 `REGENERATION_INTERVAL_TICKS = 20` 一次
5. **招募同伴**——`RECRUIT_RANGE = 16.0D`

## 宝可梦化改造

* "拉住目标" 在宝可梦里最贴近的翻译不是伤害，而是**阻止换人**——这正是 SRP 里被拖住就跑不掉的意思
* 液体跳跃依赖液体，所以我把它做成**条件招式**：有水/雨天场地时才能发挥全力
* 它的再生不是回复招式，而是**每回合自动触发**——对应代码里写死的 20 tick 间隔

## 特性

**普通特性：黏索再生（`tetherregen`）**

每回合结束回复自身最大 HP 的 1/16。对应 `REGENERATION_AMOUNT = 4.0F` / `REGENERATION_INTERVAL_TICKS = 20`。

**隐藏特性：招募本能（`recruit`）**

出场时若我方场上存在空位，随机召唤一只**阶级不高于自身**的真实寄生体支援；每场战斗只能触发 1 次。对应 `RECRUIT_RANGE = 16.0D`。

## 独家技能 1：黏索拖曳 / Tether Drag

| 字段 | 值 |
|---|---|
| 属性 | 虫 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 95 |
| PP | 10 |
| 范围 | 单体 |

**效果**：拴住目标 3 回合：期间目标**无法被替换下场**，且每回合结束被拖向使用者（速度下降 1 阶段，最多 -2）。使用者在这 3 回合内不会因对手换人而失去目标。

**触发条件**：无。

**视觉表现**：黏索从口部射出缠住目标，索身绷紧并持续亮起暗青色，目标被一点点拉近。

**为什么只有它**：`PULLING` 状态与 `TARGET_ENTITY` 同步数据的翻译。它是全族**唯一以"禁止换人"为核心机制**的生物——SRP 里被 Dredge 拖住就是跑不掉，宝可梦里对应的就是锁场。

## 独家技能 2：液体跃击 / Liquid Leap

| 字段 | 值 |
|---|---|
| 属性 | 水 |
| 分类 | 物理 |
| 威力 | 70 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体 |

**效果**：先制 +1，连续攻击 2 次。只有在雨天或水属性场地存在时可使用；使用后自身速度提升 1 阶段（对应连续 8 次的跳跃节奏）。

**触发条件**：**必须有水**。干燥场地上此招式不可用。

**视觉表现**：从水面/积水中弹射而出，带起水花砸向目标，落地后立刻再次弹起。

**为什么只有它**：`MAX_LIQUID_LEAPS = 8` 与 `LIQUID_LEAP_INTERVAL_TICKS = 21` 的翻译。它同时也是一条**生态约束**：Dredge 离开水就失去一半战斗力，所以它不会出现在干燥的感染区。

## 生态

* **生活环境**：感染区的**水域**——沼泽、河流、海岸线。干燥区域几乎见不到它
* **食物**：被拖入水中的猎物
* **猎物**：任何试图逃跑的目标；它对静止目标兴趣不大
* **天敌**：能解除锁场的手段，以及把它逼离水域的对手
* **行为**：潜伏在水边等待，锁定后拖拽。四种状态切换明确：巡逻→交战→冲刺→拖拽
* **群体**：`RECRUIT_RANGE = 16` 说明它会召集附近的同伴一起处理拖住的目标
* **巢穴**：依附水域附近的巢穴
* **繁殖**：不繁殖，由巢穴孵化
* **与其他 SRP 宝可梦关系**：它是巢群的**拘束单位**：负责把目标按住，让其他单位完成击杀

## 图鉴描述 1

> 它的嘴里能吐出一根黏索。被缠住的东西跑不掉——不是因为它力气大，而是因为那根索会一直拽着你，直到别的东西过来。

## 图鉴描述 2

> 观察记录：目标试图脱离时，黏索张力在 200 tick 内保持恒定，位移累计 14 格。
期间有 3 只同类从 16 格外接近。
 ——结论：Dredge 不负责杀死猎物。它负责**让猎物留在原地**。
