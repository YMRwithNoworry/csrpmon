总和 360。SRP 中 health **40.0** / damage **13.0** / armor 5.0 / speed 0.25——**攻血双高，是所有被同化动物里最强的一只**（牛 18/7、羊 13/6、猪 9/3.5）。更关键的是它的 **`mergeValue = 2`**：其他同化体都是 1。

## 设计核心

“它一头就顶得上两头。不是比喻——**源码里它的融合价值就是别人的两倍。**”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 保留了熊的宽颅骨与吻部，额骨被寄生组织撑裂 | SRP `sim_bear` 的宿主外形 |
| 眼睛 | 原本的熊眼被暗红薄膜覆盖 | 同化特征 |
| 前掌 | 巨大的熊掌，掌垫被硬化寄生组织覆盖 | damage 13.0 的外形依据 |
| 肩背 | 厚实的肩背覆有一层额外的寄生装甲板 | armor 5.0 与 health 40.0 |
| 融合囊 | 背部有一处比其他同化体更大的寄生囊 | `mergeValue = 2`——融合价值是两倍 |
| 颜色 | 暗红寄生组织 + 残留的棕色熊毛 | SRP 模型配色 |

**动作姿势**：四足着地、重心极低；起立时能短暂直立，用双掌下砸。

## SRP 特征保留

1. **攻血双高**——health 40.0 / damage 13.0，同化动物中最强
2. **融合价值为 2**——`BEAR("sim_bear", 40.0D, 13.0D, 5.0D, 0.1D, 0.25D, 16.0D, 8, 1.4D, 1.6F, 73, 2)`，最后一个参数 `mergeValue = 2`
3. **熔解时长 73**——与牛相同，比猪（25）与狼（19）都长
4. **死亡后留下头颅**——`case BEAR -> ...` 中头颅分支
5. **转化为野化熊**——`case BEAR -> ModEntities.FER_BEAR.get().create(level)`
6. **被排除在某一随机分支外**——`kind == Kind.BEAR || kind == Kind.SQUID || random.nextFloat() >= 0.5F`

## 宝可梦化改造

* **`mergeValue = 2` 是一个孤例**：所有其他同化体都是 1，只有它是 2。我没有把它当成数值噪声，而是做成机制——**它在融合系统里算两份**
* 它是同化动物中最强的一只，所以我没有给它"笨重但耐打"的老套设计，而是**攻血双高、速度最低（0.25）**的纯重击手
* 它和同化鱿鱼一起被排除在某个 50% 随机分支之外，说明这两只在实现上共享某些特殊处理

## 特性

**普通特性：双重质量（`doublemass`）**

自身参与的召唤类效果或场地类效果，**强度按两只计算**。对应 `mergeValue = 2`——所有其他同化体都是 1。

**隐藏特性：厚背装甲（`backplate`）**

自身受到的物理招式伤害减少 20%，但速度下降 1 阶段。对应 armor 5.0 与 health 40.0 的重装定位。

## 独家技能 1：双掌重砸 / Double Maul

| 字段 | 值 |
|---|---|
| 属性 | 格斗 |
| 分类 | 物理 |
| 威力 | 105 |
| 命中 | 95 |
| PP | 10 |
| 范围 | 单体 |

**效果**：造成伤害。**若自身当前 HP 高于 75%，本招式威力提高 25%**（体力充沛时砸得更重）；若低于 25%，改为自身受到 1/8 最大 HP 的反伤。

**触发条件**：取决于自身 HP 比例。

**视觉表现**：短暂直立后双掌同时下砸，落地时掀起一圈碎屑，背部的融合囊同时绷紧。

**为什么只有它**：damage 13.0（同化动物最高）与 `mergeValue = 2` 的翻译。**它是全族唯一以"体力充沛时最强"为条件的招式**——与狂怒系"低血变强"相反，它强调的是一头健康熊的绝对力量。

## 生态

* **生活环境**：感染区的林地与洞穴——保留熊的领地习性
* **食物**：被同化的猎物，食量比其他同化体大
* **猎物**：不挑体型，只要打得过
* **天敌**：能消耗它体力的持续输出；它速度只有 0.25
* **行为**：直线推进、近身重击。不追击逃跑的目标
* **群体**：单独行动，占一片领地
* **巢穴**：巢穴的**重击单位**
* **繁殖**：不繁殖，由被感染的熊转化而来
* **与其他 SRP 宝可梦关系**：同化熊头（`sim_bearhead`）；可转化为**野化熊**（`fer_bear`）；**融合价值 2**，在融合系统中算两份
