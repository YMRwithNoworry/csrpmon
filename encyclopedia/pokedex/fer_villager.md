总和 320。SRP 中 health 27.0 / damage **17.0（野化层最高）** / armor 8.0 / **knockbackResistance 0.9（野化层最高，全族第二）** / speed 0.26 / followRange 32。**一个失控的村民，成了这一层最难推开、也最会打的东西。**

## 设计核心

“村民本来是聚落里最弱的那一类。野化之后，它变成了**这一层最难推开的东西**——因为它一辈子都在被人推。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 村民的长鼻被撑裂、向前突出成锥形 | 宿主本能极端化 |
| 眼睛 | 两处暗红光点，眉骨异常突出 | 野化特征 |
| 躯干 | **底盘极低、重心下压**，整个身体像一块夯实的土 | knockbackResistance 0.9 |
| 双臂 | 双臂粗壮到不成比例，向前伸展 | damage 17.0 的外形依据 |
| 背部 | 背着一整块硬化的寄生甲板 | armor 8.0 |
| 颜色 | 深红寄生组织 + 几乎褪尽的褐色长袍 | SRP 模型配色 |

**动作姿势**：身体前倾、双臂前伸、底盘压到最低；被击中时几乎不后退，只是把重心再压低一点。

## SRP 特征保留

1. **火焰弱点**——类注释：*"fire weakness"*
2. **击杀回复**——类注释：*"kill-fuelled recovery"*
3. **野化层最高攻击力**——damage **17.0**
4. **野化层最高击退抗性**——**0.9**，与同化村民 body 的 0.2 相比是极端化
5. **"负重"本能的极端形态**——同化村民背着寄生囊，野化村民整个身体都变成了重物

## 宝可梦化改造

* **同化村民的击退抗性是 0.2，野化村民是 0.9**——这是全层里跨度最大的一个数值变化，方向非常清楚：**它把"站得住"推到了极限**
* **它的攻击力 17.0 也是野化层最高**（熊与牛都是 15.0）。一个失控的村民反而成了最会打的——这个反差正是"宿主本能极端化"的意思
* 我把它的机制做成"挨打不后退、越打越重"，而不是"更快更强"。**它的失控方向是质量，不是速度**

## 特性

**普通特性：焦灼之躯（`scorchedflesh`）**

自身受到的火属性招式伤害提高 50%。对应 `FeralParasiteEntity` 类注释中的 fire weakness。

**隐藏特性：夯实地基（`packeddirt`）**

自身完全免疫强制换场与击退效果；**每次被攻击后，下一次接触类招式威力提高 15%（最多 +45%）**。对应 `knockbackResistance = 0.9D`——**它把每一次被推都存了下来**。

## 独家技能 1：夯地重砸 / Immovable Maul

| 字段 | 值 |
|---|---|
| 属性 | 格斗 |
| 分类 | 物理 |
| 威力 | 105 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体 |

**效果**：造成伤害。**自身本回合受到的伤害每累计满 25% 最大 HP，本招式威力提高 15%（最多 +45%）**。使用后自身速度不变（它本来就不靠速度）。

**触发条件**：取决于本回合累计受到的伤害。

**视觉表现**：双臂高举后垂直砸下，落地时整片地面被压出凹痕；即使被击中，它的脚下位置也几乎不动。

**为什么只有它**：damage 17.0 与 knockbackResistance 0.9 的组合翻译。**它是全族唯一"把承伤转换成输出"的招式**——打它等于给它蓄力。

## 生态

* **生活环境**：感染区外围的人类聚落遗址
* **食物**：任何能打倒的东西
* **猎物**：不筛选，但会一直逼近
* **天敌**：火焰（50% 额外伤害）；以及能绕过它直取后排的对手
* **行为**：直线逼近、贴脸重砸。**被推也不后退**
* **群体**：通常单独行动——它的体型与重量不需要同伴
* **巢穴**：不建巢，是被巢穴放弃的失控个体
* **繁殖**：不繁殖，由同化村民转化而来
* **与其他 SRP 宝可梦关系**：**由同化村民转化**；与同化村民的关系是"把负重本能推到极限的版本"
