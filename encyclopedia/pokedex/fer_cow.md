总和 314。SRP 中 health 38.0 / damage 15.0 / armor 8.0 / knockbackResistance 0.8 / speed 0.28 / followRange 32。**这组数值与野化熊完全相同**（38/15/8.0/0.8/0.28/32/16）——同化牛与同化熊的数值也相同。区分只能靠宿主身份。

## 设计核心

“野化熊靠一头撞穿你。野化牛靠**一群一起撞**——它的本能是牛群，不是个体。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 牛头被拉长，额角向外侧大幅展开 | 宿主本能极端化 |
| 眼睛 | 两处暗红光点，没有瞳孔结构 | 野化特征 |
| 体表 | 寄生组织沿肌肉隆起，肩部形成撞角状硬块 | armor 8.0 的外形依据 |
| 四肢 | 四蹄硬化、步幅明显大于同化牛 | 群冲行为 |
| 群冲姿态 | 低头时两侧导流板张开，与同化牛相同但更宽 | `status == 3 && kind == Kind.COW` 的专属状态分支 |
| 颜色 | 深红寄生组织 + 残留的牛皮斑块 | SRP 模型配色 |

**动作姿势**：低头疾冲、身体拉直；与同化牛相同，但**转向时会朝邻近同类靠拢**——这是牛群的本能残留。

## SRP 特征保留

1. **火焰弱点**——类注释：*"fire weakness"*
2. **击杀回复**——类注释：*"kill-fuelled recovery"*
3. **专属状态分支**——`if (status == 3 && kind == Kind.COW && still)` 与 `if (status == 3 && (kind == Kind.COW || kind == Kind.HORSE))`，**野化熊没有这一支**
4. **牛群本能**——宿主的核心行为被推到极限
5. **数值与野化熊完全相同**——38.0 / 15.0 / 8.0 / 0.8 / 0.28 / 32 / 16

## 宝可梦化改造

* **"数值与野化熊完全相同"是一个必须正面处理的事实**。我没有靠数值区分，而是靠**源码里的状态分支**：野化牛（与野化马）拥有 `status == 3` 的专属分支，野化熊没有
* **牛的本能是群体**，所以它的失控方向是"一群一起冲"。这是与野化熊（独行猛兽）最本质的区别
* 它的专属招式因此围绕**同类数量**展开，而不是单体的力量

## 特性

**普通特性：焦灼之躯（`scorchedflesh`）**

自身受到的火属性招式伤害提高 50%。对应 `FeralParasiteEntity` 类注释中的 fire weakness。

**隐藏特性：群冲本能（`herdcharge`）**

我方场上每存在另一只 FERAL 层级宝可梦，自身接触类招式威力提高 15%（最多 +45%）。对应野化牛的牛群本能——**它的强度取决于身边有多少同类**。

## 独家技能 1：群冲践踏 / Herd Charge

| 字段 | 值 |
|---|---|
| 属性 | 格斗 |
| 分类 | 物理 |
| 威力 | 85 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体 |

**效果**：先制 +1。**我方场上每存在另一只 FERAL 层级宝可梦，威力提高 20%（最多 +60%）**。使用后自身防御下降 1 阶段（群冲不回头）。

**触发条件**：取决于我方 FERAL 单位数量。

**视觉表现**：低头压到最低，颈侧导流板全开；视野边缘能看到其他同类以同样姿势并排冲来。

**为什么只有它**：牛群本能 + `status == 3 && kind == Kind.COW` 专属分支的翻译。**与野化熊的对照最直接**：野化熊是单体最强，野化牛是**越多越强**。

## 生态

* **生活环境**：感染区外围的开阔地带
* **食物**：任何能撞倒的东西
* **猎物**：不筛选，群体冲锋
* **天敌**：火焰（50% 额外伤害）；以及AOE清场手段
* **行为**：**成群冲锋**。与野化熊的独行形成对比
* **群体**：**它仍然成群**——这是这一对最重要的区别
* **巢穴**：不建巢，是被巢穴放弃的失控个体
* **繁殖**：不繁殖，由同化牛转化而来
* **与其他 SRP 宝可梦关系**：**由同化牛转化**；与野化熊**数值完全相同但机制不同**（后者无 `status == 3` 分支）
