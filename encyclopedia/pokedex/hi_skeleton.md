## 设计核心

“骷髅本来就会在远处射箭。被劫持之后它换了一种箭——**还是站得很远**。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 骷髅的头骨保留，眼窝里是两处暗红光点 | 宿主外形保留 |
| 躯干 | 骨架结构保留，骨缝间填满寄生组织 | 宿主结构 |
| 手臂 | 右臂骨被改造成骨刺球发射腔 | ranged spineball attacker |
| 弓 | **原来的弓已经不在了**——它不再需要 | 射程由自身提供 |
| 背脊 | 脊骨沿线上长出一排骨刺 | damage 来源 |
| 颜色 | 暗红寄生组织 + 发黄的骨骼 | SRP 模型配色 |

**动作姿势**：直立、双臂保持拉弓的姿势（习惯残留），但手上没有弓；发射时骨刺球直接从右臂射出。

## SRP 特征保留

1. **远程攻击者的定位**——类注释：ranged spineball attacker
2. **骨架结构与站姿**——宿主外形完整保留
3. **配置驱动的数值**——MobsConfig.hiskeletonHealthMultiplier() 等逐项倍率
4. **骨刺球**——与其他两个劫持体共用的 fireSpineball 实现
5. **宿主战斗方式完整保留**——HijackedParasiteEntity 类注释：Shared hostile state for legacy hijacked mobs。
6. **骨刺球投射物**——三个劫持体共用 fireSpineball(LivingEntity target) 实现
7. **实现层级为 Primitive**——源码中 HijackedParasiteEntity extends PrimitiveParasiteEntity

## 宝可梦化改造

* **「手上没有弓了，姿势还是拉弓」**——这是我为它设计的核心视觉。宿主的行为模式被保留了，工具被替换了
* **它的数值是配置驱动的**，这一点我如实记录：源码用的是 MobsConfig.hiskeleton 逐项倍率（原版默认 1.0F）。所以它的强度**取决于玩家配置**，不是固定值
* 它与劫持烈焰人都是远程，但方向不同：烈焰人**从空中齐射并照明**，骷髅**站在地面单发点射**

## 特性

**普通特性：骨刺装填（`boneloading`）**

自身使用骨刺球类招式后，若目标未更换，下一回合的骨刺球招式威力提高 20%（连续点射同一目标）。对应 ranged spineball attacker 的定位。

**隐藏特性：配置驱动（`configdriven`）**

—（说明性特性）：源码中它的全部属性由 MobsConfig.hiskeleton 逐项倍率决定（原版默认 1.0F），因此本条目给出的数值是**默认倍率下的基准值**，实际强度随配置变化。

## 独家技能 1：骨刺点射 / Bone Spine Shot

| 字段 | 值 |
|---|---|
| 属性 | 虫 |
| 分类 | 特殊 |
| 威力 | 70 |
| 命中 | 100 |
| PP | 15 |
| 范围 | 单体，全场 |

**效果**：无视距离造成伤害并附加 1 层【感染】（对应 followRange 48）。**若上一回合也对同一目标使用过本招式，威力提高 20%**。

**触发条件**：连续点射同一目标时生效。

**视觉表现**：右臂骨腔张开并射出一枚高速旋转的骨刺球，弹道笔直，发射后手臂短暂后坐。

**为什么只有它**：ranged spineball attacker 与 fireSpineball 的翻译。**与劫持烈焰人的齐射形成对照**：烈焰人是 3 发小威力齐射，骷髅是单发高威力点射——同样是骨刺球，两种用法。

## 生态

* **生活环境**：感染区各处——它需要视野，不需要距离
* **食物**：不需要
* **猎物**：视野内的任何目标
* **天敌**：能快速贴近它的近战单位；27 点生命经不起贴身
* **行为**：远距离单发点射。**姿势仍是拉弓，但已经不需要弓**
* **群体**：通常 2~3 只分散站位
* **巢穴**：巢穴的**远程点射单位**
* **繁殖**：不繁殖
* **与其他 SRP 宝可梦关系**：与劫持烈焰人同为远程但分工不同（齐射 + 照明 vs 单发点射）
