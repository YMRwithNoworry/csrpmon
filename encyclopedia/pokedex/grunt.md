总和 326。SRP 中 health **20.0** / armor 7.0 / damage 13.0 / speed 0.274172325 / knockbackResistance 0.40 / followRange 32。它是 PURE 层唯一的低数值成员——**其余六只生命都在 70 以上**。它靠的不是数值，是 `climbs = true`。

## 设计核心

“它不是精锐。**它只是会爬墙**——而在一个到处都是墙的地方，这就够了。”

**动作姿势**：平时四足着地快速移动；遇到垂直面直接贴上去攀爬，**不绕路**。

## SRP 特征保留

1. **攀爬**——`Kind.GRUNT(false, true, ...)`，第二个参数 climbs = **true**
2. **PURE 层唯一的低数值**——health 20.0，其余六只为 70~80
3. **最快的移动速度之一**——speed 0.274172325
4. **低击退抗性**——0.40，容易被推开
5. **不飞行**——第一个参数 flying = false

## 宝可梦化改造

* **`climbs = true` 是一个布尔值，不是数值**。我把它当作它的核心身份：整个 PURE 层只有它和君主、典狱长会攀爬，而它是最弱的那一个
* **它的生命只有 20.0，是这一层唯一低于 70 的**。所以我没有把它做成精锐战士，而是**机动兵卒**——靠路径而不是靠强度
* 它与掠夺者的关系：掠夺者是改造主脑，它只是被派出去的量产单位

## 特性

**普通特性：钩足攀附（hookclimb）**

自身免疫场地类效果（隐形岩、撒菱等），且面对飞行/浮空目标时接触类招式必中。对应 `climbs = true`。

**隐藏特性：量产兵卒（massgrunt）**

自身被击倒时，我方下一只上场的 PURE 层级宝可梦回复 15% 最大 HP。对应它是被批量派出的兵卒单位。

## 独家技能 1：钩足翻越 / Hook Scramble

| 字段 | 值 |
|---|---|
| 属性 | 格斗 |
| 分类 | 物理 |
| 威力 | 75 |
| 命中 | 100 |
| PP | 15 |
| 范围 | 单体 |

**效果**：先制 +1。**若目标处于浮空状态或场地存在障碍效果，威力提高 30%**（它直接爬过去）。命中后自身速度提升 1 阶段。

**触发条件**：与场地/浮空状态相关。

**视觉表现**：四对钩足交替扣入垂直面，身体几乎贴着墙面横向掠过，从目标侧上方翻落并钩击。

**为什么只有它**：`climbs = true` 的翻译。**它是全族唯一「地形越复杂越强」的招式**——一个会爬墙的东西，墙就是它的优势。

## 独家技能 2：顶面伏击 / Ceiling Drop

| 字段 | 值 |
|---|---|
| 属性 | 格斗 |
| 分类 | 物理 |
| 威力 | 80 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体 |

**效果**：**若自身前一回合位于垂直面，先制 +1 且威力提高 35%**（从上方落下）。命中后目标命中率下降 1 阶段。

**触发条件**：需要垂直面环境。

**视觉表现**：钩足扣住顶面后整体脱离，自由落体砸向目标，落地瞬间四对钩足同时张开扣住对方。

**为什么只有它**：兵卒是全层唯一生命 20.0 的成员，`climbs = true` 是它唯一的身份。主招式表达翻越，**这一招表达攀爬带来的高度优势**——它打不赢你，但它总能到你头上。
