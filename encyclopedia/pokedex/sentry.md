总和 336。SRP 中 health 30.0 / armor 10.0 / damage 5.0 / movementSpeed **0.0** / **followRange 32** / experience 36。**它拥有全部阻遏体中最远的感知范围（32），却一步都不能移动。**

## 设计核心

“它看得见你从三十二格外走过来。**它只是不能过来。**”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 分化为一个朝上的观察球体，可 360 度转动 | followRange 32 |
| 眼睛 | 环绕球体的一整圈单眼，没有盲区 | 全向警戒 |
| 躯干 | **下段完全植根**，上段只有一个可转动的颈柱 | movementSpeed 0.0 |
| 肩部 | 两侧伸出短小的发射管，只能朝固定方向射击 | damage 5.0 |
| 基部 | 根须向四周延伸并彼此连接 | 巢穴警戒网 |
| 颜色 | 暗红寄生组织 + 骨白色观察球 | SRP 模型配色 |

**动作姿势**：完全静止，只有顶端的观察球持续转动扫描；发现目标后球体停住并朝向目标，随后发射管开火。

## SRP 特征保留

1. **最远的感知范围**——followRange **32**，五个阻遏体中最远
2. **零移动速度**——`movementSpeed = 0.0`
3. **带经验值**——experience **36**（tentacle / seizer / worm 都是 0）
4. **中等耐久**——health 30.0 / armor 10.0
5. **低伤害**——damage 5.0，它的作用在于发现而不是击杀

## 宝可梦化改造

* **followRange 32 配 movementSpeed 0.0 是这一层最尖锐的对比**：它能看见 32 格外的你，然后什么也做不了。我据此把它设计成**警戒节点**——它的价值是"提供信息"，而不是"造成伤害"
* 它 damage 只有 5.0，所以我没有给它像样的输出。它的专属招式围绕**标记与预警**展开
* 它与其余阻遏体的分工：哨卫负责**发现**，其他负责处理

## 特性

**普通特性：固定植入（`anchored`）**

自身**完全无法被替换下场**，也免疫一切强制位移与击退效果；但自身也**无法主动替换**。对应 `DeterrentParasiteEntity.Kind` 中全部五个成员的 `movementSpeed = 0.0`。

**隐藏特性：警戒网（`sentrynet`）**

我方场上有其他 DETERRENT 层级宝可梦时，自身受到的伤害减少 30%（根须相互支撑）。对应五个阻遏体成片植入的行为。

## 独家技能 1：远眺锁定 / Farsight Lock

| 字段 | 值 |
|---|---|
| 属性 | 超能 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 15 |
| 范围 | 单体，全场 |

**效果**：**无视距离**（followRange 32）对目标施加【猎物标记】，持续 3 回合。**被标记的目标无论替换到哪只宝可梦身上，标记都会转移**（哨卫一直在看着）。造成 0 点伤害。

**触发条件**：无。

**视觉表现**：顶端观察球停住并朝向目标，球体表面的单眼依次亮起，目标身上浮现一圈暗红锁定纹。

**为什么只有它**：followRange **32** 的翻译。**它是全族唯一「标记会跟随替换转移」的招式**——因为它看的不是某一具身体，是那个位置上的东西。

## 生态

* **生活环境**：感染区的高处与关键通道——它被植入在需要监视的位置
* **食物**：通过根须吸取养分
* **猎物**：无。它不狩猎，只观察
* **天敌**：任何东西。它不能移动、不能逃跑、不能换位
* **行为**：**完全静止**。转动、扫描、锁定、开火
* **群体**：成片植入并根须相连，形成警戒网
* **巢穴**：巢穴的**外围警戒节点**
* **繁殖**：通过根须分裂
* **与其他 SRP 宝可梦关系**：五个阻遏体之一；与其余四个共享 `movementSpeed = 0.0`，且与畸形体同带 experience 36
