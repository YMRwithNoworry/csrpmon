## 基础种族值

| HP | 攻击 | 防御 | 特攻 | 特防 | 速度 | 总和 |
|---|---|---|---|---|---|---|---|
| 44 | 32 | 40 | 88 | 52 | 68 | **324** |

总和 324。**攻击只有 32（SRP 中 `damage = 3.5D`）**，但特攻 88。它几乎不做近战——SRP 给它的属性是 health 30 / armor 3.5 / damage 3.5 / knockbackResistance 0.20，是全族最脆的一档，换来的是一门**射程 65 格**的炮。

## 设计核心

“它打不到你，也挨不了你一下。它只是**一直看着你**——等你听到那声提示音的时候，已经来不及了。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 一枚占据面部大部分的黄色复眼结构，没有其他五官 | 名称与 `YELLOWEYE_*` 常量 |
| 眼睛 | **单枚巨大黄眼**，锁定目标时会收缩成一条竖缝 | `YELLOWEYE_WARNING_TICK = 70` 的凝视过程 |
| 炮口 | 头部下方的囊状发射腔，装填时鼓起 | `yelloweyeNadeDamage` 的榴弹 |
| 肢体 | 四足退化成挂钩，无法行走，只能悬停 | `setNoGravity(true)` 与 `YelloweyeRandomFlightGoal` |
| 体表 | 两套可替换的皮（`YELLOWEYE_SKIN_NORMAL / HEAVY`） | `YELLOWEYE_SKIN_*` 常量 |
| 颜色 | 暗褐主体 + 单眼亮黄 + 发射腔暗绿 | SRP 模型配色 |

**动作姿势**：悬停在高处，黄眼持续对着目标；锁定完成时发射腔会明显鼓起——这是它唯一的预警。

## SRP 特征保留

1. **远程炮击**——`YelloweyeRangedGoal`，伤害来自 `MobsConfig.yelloweyeNadeDamage()`（榴弹）
2. **超远射程**——`YELLOWEYE_MAX_ATTACK_DISTANCE_SQR = 4225.0D`，即 **65 格**
3. **锁定—预警—开火的三段节奏**——`YELLOWEYE_WARNING_TICK = 70`、`YELLOWEYE_FIRE_TICK = 100`，中间有 30 tick 的预警窗口
4. **飞行滞空**——`setNoGravity(true)` 与 `YelloweyeRandomFlightGoal`
5. **极脆**——health 30 / armor 3.5 / knockbackResistance 0.20
6. **极低近战伤害**——damage 3.5，几乎不能打近身
7. **具备适应能力**——原生体层级 `supportsDamageAdaptation()` 返回 true

## 宝可梦化改造

* **我按你在这条 brief 里给的示例设计它**：不做成"黄眼激光"，而是做成**凝视锁定 → 标记 → 后续炮击自动追踪 → 离开视线解除**。源码里的 `WARNING_TICK / FIRE_TICK` 三段节奏正好支持这个结构
* `YELLOWEYE_MAX_ATTACK_DISTANCE_SQR = 4225` 换算过来是 65 格，在宝可梦里不可能有这种射程——所以我把它翻译成"**只要在场上就能打到**"，用必中 + 无视保护来表达
* 它 3.5 的近战伤害我如实保留：**这只生物没有近战能力**，被贴脸就是等死

## 特性

**普通特性：黄瞳锁定（`yellowgaze`）**

出场时自动对场上一个对手施加【猎物标记】。自身对其造成的伤害 +20%，且自身招式对其必中。

**隐藏特性：易碎外壳（`brittleframe`）**

自身受到的接触类招式伤害提高 25%，但被击退距离翻倍（对应 `knockbackResistance = 0.20`）。

## 独家技能 1：凝视锁定 / Gaze Lock

| 字段 | 值 |
|---|---|
| 属性 | 超能 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 10 |
| 范围 | 单体 |

**效果**：锁定目标 4 回合：期间自身对其**所有招式必中**，且每回合结束标记层数 +1（最多 3 层）。每层使自身对其下一发炮击威力 +25%。**目标替换下场则锁定立即解除，层数清零。**

**触发条件**：无。

**视觉表现**：单眼收缩成一条竖缝并持续对准目标；每回合结束眼周亮起一圈额外光晕表示层数。

**为什么只有它**：`YELLOWEYE_WARNING_TICK = 70` 到 `FIRE_TICK = 100` 的三段节奏被翻译成"锁定—累积—开火"。**你在这条 brief 里亲手给出的示例就是这个结构**，我按源码的时序参数把它落成了可执行规则。与感染标记/猎物标记的区别：那两个是阵营共享的增伤，这个只对自身生效，但会随回合数成长。

## 独家技能 2：榴弹抛射 / Nade Shot

| 字段 | 值 |
|---|---|
| 属性 | 虫 |
| 分类 | 特殊 |
| 威力 | 85 |
| 命中 | 90 |
| PP | 10 |
| 范围 | 单体，全场 |

**效果**：**无视距离**（只要目标在场即可命中）。命中率 90，但若目标已被自身锁定则改为必中且威力提高（每层锁定 +25%）。

**触发条件**：无。

**视觉表现**：发射腔鼓起后向前抛出一枚暗绿色泡状榴弹，飞行轨迹带轻微下坠，落地后炸出一小片寄生组织。

**为什么只有它**：`yelloweyeNadeDamage` 与 `YELLOWEYE_MAX_ATTACK_DISTANCE_SQR = 4225.0`（65 格）的翻译。**它是全族唯一无视距离的招式**——SRP 里它真的能在 65 格外打到你，宝可梦里用"全场"来表达这个事实。

## 生态

* **生活环境**：感染区上空的高处——它需要视野而不是掩体
* **食物**：不需要近身进食，靠巢群供给
* **猎物**：任何进入它视野的目标；它不挑体型
* **天敌**：能打到空中或能强行拉近的对手。它 30 生命值经不起一次有效攻击
* **行为**：悬停凝视—锁定—抛射。全程不落地，被接近就拉开距离
* **群体**：单独悬停，多只之间会错开视野范围
* **巢穴**：巢穴的**远程火力点**
* **繁殖**：不繁殖
* **与其他 SRP 宝可梦关系**：适应黄瞳的前置形态（`pri_yelloweye -> ada_yelloweye`）
