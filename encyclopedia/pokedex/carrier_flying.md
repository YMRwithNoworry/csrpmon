# No.8028 飞行载虫 / Flying Carrier

| | |
|---|---|
| **SRP Source** | `csrp:carrier_flying` |

| **SRP 分类** | INBORN（`RelayScanReportFactory.Tier.INBORN` 与 `bestiary/carrier_flying.json` 一致） |

| **分类名** | 空中投放寄生宝可梦 |

## 基础种族值

| HP | 攻击 | 防御 | 特攻 | 特防 | 速度 | 总和 |
|---|---|---|---|---|---|---|---|
| 52 | 62 | 40 | 60 | 44 | 78 | **336** |

总和 336。速度 78 是全族最高，但 HP 52、防御 40 都很低——SRP 中它的击退抗性只有 **0.15**（轻型/重型是 0.95），意味着它**几乎是纸做的、一推就飞**。它靠高度和机动活命，不靠体格。

## 设计核心

“它不是走过去炸的，它是**飞过去扔下来**的——而且扔完就跑，因为被碰一下它就会掉下去。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 朝下的锥形投放口，没有眼睛 | SRP 飞行载虫的头部结构 |
| 翅膀 | 两对宽大的膜翅，飞行时有明显残余震动 | `CarrierFlyingMoveControl` 的飞行控制 |
| 腹部 | 下垂的载荷囊，比轻型载虫略小 | `carrierFlyingMobTable` 的小载荷表 |
| 引信 | 载荷囊底部一圈发光环，投放下落时最亮 | `FUSE_TICKS` 的空中版本 |
| 肢体 | 六足退化成挂载钩，无法行走，只能抓握 | `FlyingCombatGoal` 的空中战斗 |
| 颜色 | 暗红褐主体 + 半透明翅面 | SRP 模型配色 |

**动作姿势**：几乎不落地。俯冲投放时会短暂收翅呈纺锤形，投完立刻爬升——因为一旦被拽到地面它就没有防御手段。

## SRP 特征保留

1. **真实飞行**——`Attributes.FLYING_SPEED` 0.25 + `FlyingCombatGoal` + `FlyingRandomMoveGoal` + 专用 `MoveControl`
2. **极易被击退**——击退抗性 0.15，与另两只载虫的 0.95 形成鲜明对比
3. **飞行上限**——`carrierFlyingMaxY = 256`
4. **最小载荷表**——`carrierFlyingMobTable()` 默认 `rupter;3;1`、`buglin;3;2`
5. **变体病毒参数**——`variantViralAmplifier() = 1`、`variantViralRadius() = 4.0`
6. **自爆与毒云**——继承自 `CarrierEntity`

## 宝可梦化改造

* 它的 0.15 击退抗性不是一个可以忽略的数字，所以我把它做成**机制**而不是数值：它自带被击退倾向，这直接决定了它必须保持距离
* 载荷表上限最低（rupter 3 / buglin 3）被如实保留——它是三只载虫里扔得最少的
* `carrierFlyingMaxY` 说明它有高度概念，翻译成"高空投放时命中更稳，被拉低时更容易失手"

## 特性

**普通特性：滞空（`airborne`）**

自身受到的接触类招式伤害减少 25%。对应它在空中、难以被近身命中的定位。

**隐藏特性：轻质躯体（`lightframe`）**

自身受到的任何击退效果翻倍，但 HP 低于 50% 时速度提升 2 阶段。0.15 击退抗性的直接翻译。

## 独家技能 1：空投 / Aerial Drop

| 字段 | 值 |
|---|---|
| 属性 | 飞行 |
| 分类 | 物理 |
| 威力 | 85 |
| 命中 | 95 |
| PP | 10 |
| 范围 | 单体 |

**效果**：先制 +1。命中后对目标附加 2 层【感染】并使目标速度下降 1 阶段。若使用者在本回合开始时位于空中（未受到接触类招式），威力额外 +25%。

**触发条件**：无。

**视觉表现**：从高空收翅俯冲，载荷囊在接触瞬间裂开，暗红色内容物沿目标体表铺开，使用者立刻爬升离开。

**为什么只有它**：把 `carrierFlyingMobTable` 的"从空中扔下寄生虫"做成一次性俯冲——与另两只载虫的载荷释放不同，**它自己带着载荷砸下去**，是一次攻击而不是一次部署。

## 生态

* **生活环境**：感染区上空，`carrierFlyingMaxY = 256` 说明它能长期停留在高空
* **食物**：不进食
* **猎物**：不选择目标，只选择**落点**
* **天敌**：任何能把它拉下来的手段——它 0.15 的击退抗性意味着一次命中就可能摔落
* **行为**：盘旋观察，俯冲投放，立刻爬升，从不缠斗
* **群体**：通常单独投放，因为载荷量小、需要覆盖更广
* **巢穴**：由巢穴生产，投放在远距离目标上
* **繁殖**：不繁殖
* **与其他 SRP 宝可梦关系**：它是**远程投放工具**，负责把虫崽兽/裂噬兽送到地面单位去不了的位置；`carrierFlyingGriefing` 说明它投放时是否破坏方块可配置

> 观察记录：用一发击退类手段命中样本，它横向飞出 11 格并撞上树干。

 ——但在此之前，它已经向我们的营地方向投下了 3 次载荷。
