总和 402。特攻 82 明显高于攻击 66——它的伤害主要来自**喷散**而不是撕咬。SRP 中它的近战效果是一整套：中毒 100 tick，并**根据皮肤**追加 Viral 或 Bleed，同时 `launchSlime(target)` 把目标弹飞。

## 设计核心

“它身上那层皮决定了你中的是什么毒——同一只生物，五种不同的坏消息。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 前端是一圈可外翻的喷散腔，没有明显颚部 | SRP Reeker kind 的喷散结构 |
| 眼睛 | 四枚分散在喷散腔周围的黄绿色点 | SRP 模型头部结构 |
| 皮肤 | **体表有多套可替换的皮**：正常 / 脆弱 / 病毒 / 狂战 / 厚重 | `REEKER_SKIN_NORMAL/FRAGILE/VIRULENT/BERSERKER/HEAVY = 0/1/5/6/7` |
| 背腺 | 成排的囊状腺体，不同皮肤下颜色不同 | 皮肤决定命中追加效果的机制 |
| 肢体 | 四足短粗，几乎不用于战斗 | 攻击力 66 的外形依据 |
| 颜色 | 随皮肤变化：正常暗红 / 病毒暗紫 / 狂战猩红 / 厚重深灰 | SRP 皮肤系统 |

**动作姿势**：身体鼓起、喷散腔半开，随时准备喷出内容物；使用冲锋时会把整个身体拉成一条线。

## SRP 特征保留

1. **中毒近战**——`target.addEffect(new MobEffectInstance(MobEffects.POISON, 100, 0), this)`
2. **皮肤决定追加效果**——`REEKER_SKIN_VIRULENT` → `EffectStacking.apply(target, ModMobEffects.VIRAL, 40, 0)`；`REEKER_SKIN_BERSERKER` → `EffectStacking.apply(target, ModMobEffects.BLEED, 40, 0)`
3. **弹飞目标**——`launchSlime(target)`
4. **招募同伴**——`ReekerRecruitFollowersGoal`：无目标且无 leader 时每 20 tick 尝试一次
5. **冲锋蓄力**——`REEKER_CHARGE_TICKS = 40`，含 `REEKER_CHARGE_NONE / WINDUP / CHARGING` 三态
6. **专属球体效果**——`MobsConfig.reekerOrbEffects()`
7. **Ricardo 变体自爆**——`isRicardoVariant()` 时以 1.8F 强度爆炸

## 宝可梦化改造

* **皮肤系统是我见过最现成的宝可梦化素材**：五种皮肤（正常/脆弱/病毒/狂战/厚重）各自改变命中追加效果。我把它做成特性——**同一只生物，配置不同就是不同的对手**
* `launchSlime()` 把目标弹飞，这个动作在宝可梦里翻译成"强制对手换场"是过度解读——所以我只做成**降低速度并打断连续行动**，不虚构换场效果
* 招募同伴是明确写出的目标（`ReekerRecruitFollowersGoal`），所以我给了它召唤类招式，且召唤物必须来自正典

## 特性

**普通特性：皮肤分化（`skindifferentiation`）**

出场时随机获得一种皮肤，决定自身接触类招式的追加效果：正常＝无追加；脆弱＝自身防御 -1 阶段但速度 +1；病毒＝附加【病毒侵蚀】；狂战＝附加流血；厚重＝速度 -1 但受到伤害 -15%。对应 `REEKER_SKIN_*` 常量。

**隐藏特性：喷散腺体（`sprayglands`）**

自身使用毒属性招式后，目标速度下降 1 阶段。对应 `launchSlime(target)` 的弹飞效果在宝可梦侧的等价表达（位移 → 减速）。

## 独家技能 1：腐嗅喷散 / Reeker Spray

| 字段 | 值 |
|---|---|
| 属性 | 毒 |
| 分类 | 特殊 |
| 威力 | 80 |
| 命中 | 95 |
| PP | 10 |
| 范围 | 全体对手 |

**效果**：对场上所有对手造成伤害并使其中毒。**根据当前皮肤追加不同效果**：病毒皮肤 → 额外附加【病毒侵蚀】；狂战皮肤 → 额外附加流血；厚重皮肤 → 威力提高 20%；脆弱皮肤 → 自身速度提升 1 阶段。

**触发条件**：效果取决于出场时随机到的皮肤，不可主动更换。

**视觉表现**：喷散腔完全外翻，不同皮肤下喷出的雾色不同（暗绿 / 暗紫 / 猩红 / 深灰），雾体贴地扩散。

**为什么只有它**：近战那套 `POISON + 皮肤决定 Viral/Bleed` 的机制被提升为一个主动招式。**这是全族唯一"同一个招式因个体皮肤而完全不同"的技能**——它把 SRP 的外观变体系统变成了实际的战斗变量。

## 生态

* **生活环境**：感染区的低洼与潮湿处——雾体需要贴地扩散
* **食物**：被毒倒的猎物，雾化吸收
* **猎物**：成群的目标（喷散是范围手段）
* **天敌**：免疫毒属性的对手；它 66 的攻击力很难靠物理解决
* **行为**：游走喷散，不主动缠斗。没有目标时会尝试招募附近同伴
* **群体**：会主动聚集——`ReekerRecruitFollowersGoal` 记录它寻找 leader 的行为
* **巢穴**：巢穴的**化学单位**，负责区域压制
* **繁殖**：不繁殖
* **与其他 SRP 宝可梦关系**：适应腐嗅的前置形态（`pri_reeker -> ada_reeker`）
