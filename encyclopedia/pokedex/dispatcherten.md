## 设计核心

“它不是一只生物，是**一根伸出来的线**——调度者（Dispatcher）伸到远处的接口。”

3. **经验值为 0**——experience 0

5. **tier 冲突记录**——本图鉴正典中该实体存在 tier 记载分歧（见下）

## 宝可梦化改造

* **damage 2.0 说明源码不把它当作攻击单位**。它的价值在于它是**调度者的一部分**——一个伸出去的接口，而不是独立的猎手
* 所以我把它做成**连接型**：它自己不产生效果，而是**把别的阻遏体连起来**。它让成片的阻遏体变成一个整体
* 它与 `marauder_tendril`（另一根触手实体）的关系：两者都是「某个更大东西的延伸」，但后者的 tier 在源码中没有记载，因此仍未设计

## 特性

**普通特性：固定植入（`anchored`）**

自身**完全无法被替换下场**，也免疫一切强制位移与击退效果；但自身也**无法主动替换**。对应 `DeterrentParasiteEntity.Kind` 中全部五个成员的 `movementSpeed = 0.0`。

**隐藏特性：中继连接（`relaylink`）**

我方场上有其他 DETERRENT 层级宝可梦时，**该宝可梦的招式威力提高 20%**（触手把能量送过去）。自身不获得任何增益——**它是为了别人存在的**。

## 独家技能 1：调度脉冲 / Relay Pulse

| 字段 | 值 |
|---|---|
| 属性 | 超能 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 10 |
| 范围 | 我方 DETERRENT 单体 |

**效果**：**指定我方一只 DETERRENT 层级宝可梦**，使其立刻回复 25% 最大 HP 并在本回合内招式威力提高 40%。**自身不获得任何效果**。造成 0 点伤害。

**触发条件**：我方场上必须有其他 DETERRENT 层级宝可梦。

**视觉表现**：末端球体的端口依次亮起，一条暗紫色的脉冲沿触手向根部传导，随后在另一只阻遏体身上显形。

**为什么只有它**：damage **2.0**（有攻击力的阻遏体中最低）与它作为 Dispatcher 延伸的身份翻译。**它是全族唯一一个「自身完全不获得任何效果」的专属招式**——它的存在意义就是连接别人。

## 生态

* **生活环境**：连接巢穴与外围阻遏体的沿线——它被铺设在需要传导的位置
* **食物**：通过根须从网络获取
* **猎物**：无。它不狩猎
* **天敌**：任何东西。10 点生命、2 点攻击、0 速度
* **行为**：**完全静止**。等待—传导—继续等待
* **群体**：成段铺设，彼此连接成网
* **巢穴**：巢穴的**外围连接节点**
* **繁殖**：由 Dispatcher 延伸产生，不自行繁殖
* **与其他 SRP 宝可梦关系**：五个阻遏体之一；它是 **Dispatcher（NEXUS 层级）的延伸结构**——这一身份构成了本图鉴的一处 tier 记载分歧
