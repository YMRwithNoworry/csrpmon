# No.8050 适应掘地 / Adapted Burrower

|---|---|

## 基础种族值

| HP | 攻击 | 防御 | 特攻 | 特防 | 速度 | 总和 |
|---|---|---|---|---|---|---|---|
| 96 | 92 | 126 | 44 | 68 | 38 | **464** |

总和 464（原初形态 368）。**防御 126 是全图鉴最高值**——SRP 中 armor 9.0 → **24.0**，是目前所有生物里最高的一个数字。击退抗性同时从 0.70 提到 **1.0**：它不只是硬，而是**完全推不动**。速度仅 38。

## 设计核心

“同一套连击、同一个掘地动作。区别是原初形态你还能把它推开，适应形态**你推不动它，也打不动它**。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 装甲 | 全身覆有厚重的分节甲壳，层数明显多于原初形态 | armor 9.0 → 24.0 的外形依据 |
| 掘土刃 | 四片掘土刃加大并加厚，破土时掀起的土量倍增 | 体型与质量提升 |
| 底座 | 腹部下方出现整片硬化底盘，贴地时几乎与地面齐平 | knockbackResistance 0.70 → 1.0 |
| 前肢 | 挖掘肢更粗，连击时碎屑飞溅范围更大 | damage 15 → 27 |
| 体表 | 甲壳缝隙渗出暗红生物质并快速硬化 | 护甲自修的外形表现 |
| 颜色 | 深灰褐主体 + 甲壳深灰 + 刃口象牙白 | SRP 模型配色 |

**动作姿势**：破土后不急于攻击，会把底盘完全贴地、四肢撑开——**先把自己变成一个足以承受一切的重物**。

## SRP 特征保留

1. **保留快速攻击**——`BurrowerMeleeGoal` 的 10 tick 间隔与 1.30 速度在两个形态中都存在
2. **护甲翻近三倍**——armor 9.0 → **24.0**，全族最高
3. **完全免疫击退**——knockbackResistance 0.70 → **1.0**
4. **保留掘地移动**——`createBurrowMovementGoal()`
5. **仍具备适应能力**——`supportsDamageAdaptation()` 返回 true

## 宝可梦化改造

* **armor 24.0 是这个模组里最高的数值**，所以我把它做成了这只生物的核心身份：**它是一堵会掘地的墙**
* 击退抗性 1.0 意味着完全推不动，我翻译成"免疫一切强制换场"——这是全族第二只具备该特性的生物（另一只是蠕虫载虫）
* 它的攻击节奏与原初形态**完全相同**（同为 `BurrowerMeleeGoal`），所以我没有给它任何新招式类型，只是把连击的段数与单段威力按攻击力提升做了调整

## 特性

**普通特性：固定底盘（`anchoredbase`）**

自身完全免疫强制换场与击退类效果。对应 `knockbackResistance = 1.0D`。

**隐藏特性：重甲镜面（`mirrorplate`）**

自身受到的特殊攻击伤害减少 25%，但速度下降 1 阶段。对应 armor 24.0 带来的极端物理耐久与更慢的体型。

## 独家技能 1：掘地连打·适应 / Burrow Flurry (Adapted)

| 字段 | 值 |
|---|---|
| 属性 | 地面 |
| 分类 | 物理 |
| 威力 | 34 |
| 命中 | 100 |
| PP | 15 |
| 范围 | 单体，连续 5~6 次 |

**效果**：第一回合潜入地下（受伤减 60%），第二回合破土并连续攻击 **5~6 次**。**每次命中后自身防御提升 1 阶段（最多 +4）**。目标处于浮空/飞行状态时本招式失败。

**触发条件**：两回合结算；目标在空中则无法使用。

**视觉表现**：破土时掀起的土量明显大于原初形态，五到六次打击残影连成一片，每命中一次体表甲壳亮起一层。

**为什么只有它**：**与原初掘地的掘地连打是同一个招式**：段数 4~5 → 5~6、单段威力 30 → 34、潜入减伤 50% → 60%、新增"每段命中加防御"（对应护甲从 9.0 到 24.0 的质变与 `knockbackResistance = 1.0` 的稳固）。同一套连击，变成了边打边把自己彻底焊在地上。

## 独家技能 2：深层潜掘 / Deep Drill

| 字段 | 值 |
|---|---|
| 属性 | 地面 |
| 分类 | 物理 |
| 威力 | 95 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体 |

**效果**：**潜入地下后从目标正下方发动攻击**：本回合不可被选中，下回合造成伤害且**无视目标的防御提升**（从下方打，护甲挡不住）。

**触发条件**：无。

**视觉表现**：地面塌陷一处，随后在目标脚下爆开，钻出的躯体上仍带着未脱落的深层岩屑。

**为什么只有它**：适应掘地者的核心是「它已经不只是钻洞了」。原初掘地者只能藏，**它能从地下打上来且无视护甲**——同一个物种更专业的地下作战版本。

## 生态

* **生活环境**：感染区的地下——比原初形态潜得更深，因为它更重
* **食物**：被拖入地下的猎物
* **猎物**：站在它正上方的目标
* **天敌**：无视防御的固定伤害，以及能打穿地下的手段
* **行为**：掘进—潜伏—破土—连击。与初形态相同，但它不需要担心被推开
* **群体**：单独埋点，占地比初形态更大
* **巢穴**：巢穴地下层的**重装突击单位**
* **繁殖**：不繁殖
* **与其他 SRP 宝可梦关系**：与原初掘地同名成对，但**源码显式排除了二者的转化关系**

## 进化 / 阶段

```
【资料冲突】本对关系未被源码确认。

- 版本 A（命名约定）：`pri_burrower` 与 `ada_burrower` 成对存在，暗示同一物种的两个成熟度。
- 版本 B（`ParasiteTransformation.java`）：`evolutionType()` 中 `PRI_BURROWER` 被显式排除（`return null`），`devolutionType()` 同样排除 `ADA_BURROWER`。
- 本次采用：**不承认二者之间存在转化关系**。两只实体都真实存在、都可以设计，但关系标注为【待核实】。
```
