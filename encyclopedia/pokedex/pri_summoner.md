# No.8016 原初召生体 / Primitive Summoner

| | |
|---|---|
| **SRP Source** | `csrp:pri_summoner` |

| **分类名** | 生体孵化寄生宝可梦 |

## 基础种族值

| HP | 攻击 | 防御 | 特攻 | 特防 | 速度 | 总和 |
|---|---|---|---|---|---|---|---|
| 68 | 52 | 60 | 88 | 72 | 40 | **380** |

总和 380。特攻 **88** 是全族 PRIMITIVE 层最高——SRP 中它是唯一以"生产"为主业的原生体（`SummonerEntity` 类注释原文：*"Summoning pillars are intentionally aggressive: one summon every second."*）。攻击只有 52，因为它的打法不是自己上。

## 设计核心

“它不是战士，是**产房**。它吐出一团生物质，生物质里爬出一只裂噬兽。然后它再做一次。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 无面部结构，顶部是一圈可外翻的产出口 | `summonBiomass()` 的产出位置 |
| 产出口 | 六瓣结构，张开时露出内部的生物质囊 | `VOMIT_COOLDOWN_TICKS = 180` |
| 体表 | 下方固定着根系状的附着组织，让它难以被推动 | 击退抗性 0.4 与"pillar"定位 |
| 生物质囊 | 体外挂着尚未成熟的半透明囊体，内部有轮廓在动 | `BiomassEntity.spawnFromVomit(this, this, 5, ...)` |
| 颜色 | 暗红褐主体 + 囊体内部的半透明暗绿 | SRP 模型配色 |

**动作姿势**：几乎不移动，靠根系固定；产出时会整株绷紧、产出口外翻到极限。

## SRP 特征保留

1. **每秒一次的生产节奏**——类注释原文：*"one summon every second."*，`SPAWN_INTERVAL = 20`
2. **同时两只、上限四只**——`SUMMON_LIMIT = 2`、`TOTAL_SUMMON_CAPACITY = 4`
3. **召唤冷却**——`SUMMON_COOLDOWN_TICKS = 50`（2.5 秒）
4. **确切的产出物**——`summonBiomass()` 生成 `BiomassEntity`，其 `SummonOption(ModEntities.RUPTER.get(), 1.0D, 1)` 明确指向**裂噬兽**，一只、满血
5. **呕吐冷却**——`VOMIT_COOLDOWN_TICKS = 180`
6. **具备适应能力**——`summoner` 属于原生体层级，`supportsDamageAdaptation()` 返回 true

## 宝可梦化改造

* **它的召唤物是完全可以被证实的**：`BiomassEntity.spawnFromVomit(..., List.of(new SummonOption(ModEntities.RUPTER.get(), 1.0D, 1)))` —— 现场吐出一枚生物质囊，囊里孵出一只裂噬兽。**没有任何虚构生物**
* 注意 `biomass` 本身在 `ModEntities` 里注册为 `MobCategory.MISC`，是**实体而非生物**。所以我把它描述成"生物质囊"这个中间物，而不是把它当成一只宝可梦
* `SUMMON_LIMIT = 2`（同时两只）与 `TOTAL_SUMMON_CAPACITY = 4`（场上上限四只）是两个不同的数字，我把它们分别做成"单次召唤数"与"场上召唤物上限"

## 特性

**普通特性：生体产出（`biomassproduction`）**

自身在场时，我方召唤类招式的冷却每回合减少 1 回合。对应 `SPAWN_INTERVAL = 20` 的快速生产节奏。

**隐藏特性：满产（`fullcapacity`）**

我方场上每存在一个召唤物，自身特攻提升 1 阶段（最多 +2）。对应 `TOTAL_SUMMON_CAPACITY = 4` 的同时上限。

## 独家技能 1：生体孵化 / Biomass Spawn

| 字段 | 值 |
|---|---|
| 属性 | 虫 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 5 |
| 范围 | 我方场地 |

**效果**：吐出一枚生物质囊：在其后 2 回合内每回合结束对目标造成 1/12 最大 HP 伤害；第 3 回合囊体孵化，对目标追加一次等同于裂噬兽一击的伤害（威力 65）并附加 2 层【感染】。场上同时最多存在 2 枚囊体。

**触发条件**：无。

**视觉表现**：顶部产出口外翻，吐出一枚半透明暗绿色囊体落在目标脚下，囊内轮廓逐回合变清晰，第三回合破裂。

**为什么只有它**：`summonBiomass()` 的完整翻译：**囊体 → 裂噬兽** 的两段结构被保留为主题曲（先囊后孵化），而不是直接召唤。它与其他召唤类招式的区别是**延迟兑现**——你需要等两回合才能拿到实际收益。

## 生态

* **生活环境**：巢穴内部的固定生产位——它移动很慢，通常长期待在同一点
* **食物**：由其他单位带回的生物质
* **猎物**：不狩猎
* **天敌**：能快速突进到它身边的单位。它速度只有 40，跑不掉
* **行为**：固定—产出—固定。它的根系组织会把自己锚在原地
* **群体**：单独占据一个生产位，两个召生体不会共用一处
* **巢穴**：**它就是巢穴的生产器官之一**
* **繁殖**：它本身就是繁殖环节：产出生物质囊并孵化出裂噬兽
* **与其他 SRP 宝可梦关系**：适应召生体的前置形态（`pri_summoner -> ada_summoner`）；与 Nexus 系是生产与被调度关系
