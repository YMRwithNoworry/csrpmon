## 基础种族值

总和 444（原初形态 324）。这一对的数值跃升是全族最大的：SRP 中 health 30 → **55**、armor 3.5 → **13.5**、damage 3.5 → **17.0**。**伤害翻了近 5 倍、护甲近 4 倍**——原初形态的"玻璃大炮"定位被彻底改写。

## 设计核心

“同一只眼睛、同一门炮。区别是原初形态打你一下就得跑，适应形态**敢停在原地把整场打完**。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 黄眼外圈长出装甲环，只在锁定瞬间露出发光部分 | armor 3.5 → 13.5 的外形依据 |
| 眼部 | 单眼改为分层的复合结构，锁定时可切换焦距 | `YelloweyeFlightGoal` 的主动定位 |
| 炮口 | 发射腔从单管变为三管交错，可连续抛射 | damage 3.5 → 17.0 |
| 肢体 | 挂钩状四足重新发育出短翼状结构，可主动爬升 | `YelloweyeFlightGoal`（原初为 `RandomFlight`） |
| 装甲 | 躯干覆有分节的硬壳，关节处露出暗红生物质 | 护甲提升的外形依据 |
| 颜色 | 暗褐主体 + 装甲环深灰 + 单眼亮黄 | SRP 模型配色 |

**动作姿势**：悬停高度比原初形态更低、更稳定；抛射时不再需要整体后坐卸力，可以连续开火。

## SRP 特征保留

1. **保留远程炮击**——`YelloweyeRangedGoal` 在两个形态中都存在
2. **保留锁定—预警—开火节奏**——`YELLOWEYE_WARNING_TICK = 70` / `YELLOWEYE_FIRE_TICK = 100`
3. **保留 65 格射程**——`YELLOWEYE_MAX_ATTACK_DISTANCE_SQR = 4225.0D`
4. **飞行改为主动**——`YelloweyeFlightGoal`（原初形态为 `YelloweyeRandomFlightGoal`，随机漂移）
5. **大幅提升耐久与伤害**——health 30→55、armor 3.5→13.5、damage 3.5→17.0
6. **仍具备适应能力**——`supportsDamageAdaptation()` 返回 true

## 宝可梦化改造

* **这一对的 tier 差异是"它终于挨得住了"**：原初形态被贴脸就等于死，适应形态的护甲从 3.5 涨到 13.5，近战伤害从 3.5 涨到 17——**它从"只能远程的玻璃"变成了"能正面站住的炮台"**
* 飞行目标从 `YelloweyeRandomFlightGoal` 变成 `YelloweyeFlightGoal`：前者是随机漂移，后者是主动定位。所以我给了它一个**主动调整高度**的机制
* 锁定与炮击两个核心招式都与原初形态**同源**，只是层数上限与数值按源码提高

## 特性

**普通特性：装甲眼环（`armoredeye`）**

出场时自动对场上一个对手施加【猎物标记】。自身对其造成的伤害 +20% 且招式必中；**同时自身受到的接触类招式伤害不再有额外惩罚**（原初形态的易碎外壳在适应形态被装甲环抵消）。

**隐藏特性：主动滞空（`activehover`）**

自身每回合结束可自由选择是否保持在浮空状态；处于浮空时受到的多数地面类招式无效，但受到的飞行/远程招式伤害 +15%。对应 `YelloweyeFlightGoal` 相较 `YelloweyeRandomFlightGoal` 的主动性。

## 独家技能 1：凝视锁定·适应 / Gaze Lock (Adapted)

| 字段 | 值 |
|---|---|
| 属性 | 超能 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 10 |
| 范围 | 单体 |

**效果**：锁定目标 5 回合：期间自身对其所有招式必中，每回合结束层数 +1（**最多 5 层**，原初形态为 3 层）。每层使下一发炮击威力 +30%。目标替换下场仍会解除，但**解除时保留一半层数**（原初形态清零）。

**触发条件**：无。

**视觉表现**：三层复合眼环同时收拢，眼周亮起的光晕比原初形态更密；即便目标短暂脱离，眼环也不会完全熄灭。

**为什么只有它**：**与原初黄瞳的凝视锁定是同一个招式**：回合数 4→5、层数上限 3→5、每层加成 25%→30%、替换后保留一半层数。四处强化对应它更稳定的定位能力（`YelloweyeFlightGoal`）。

## 独家技能 2：三连榴弹 / Triple Nade Shot

| 字段 | 值 |
|---|---|
| 属性 | 虫 |
| 分类 | 特殊 |
| 威力 | 55 |
| 命中 | 95 |
| PP | 10 |
| 范围 | 单体，全场 |

**效果**：无视距离，连续抛射 3 枚榴弹（对应三管发射腔）。每枚独立结算命中；若目标已被自身锁定，每枚威力按锁定层数提高（每层 +30%）。

**触发条件**：无。

**视觉表现**：三管交错发射，三枚泡状榴弹以略微不同的弧线同时飞出，落地后炸出成片的寄生组织。

**为什么只有它**：`damage 3.5 → 17.0` 与三管造型的翻译。与原初形态的单发榴弹抛射**同源**：单发 85 威力 → 三连 55×3，总输出接近翻倍，但更依赖锁定层数。

## 生态

* **生活环境**：感染区上空的固定火力位——它不再随机漂移，会主动选择射界最好的高度
* **食物**：靠巢群供给
* **猎物**：视野内的一切，优先已被标记的目标
* **天敌**：能强行拉近或造成固定伤害的对手；它虽然变硬了，但速度仍然只有 58
* **行为**：主动选择高度—锁定—连续抛射。会为了保持射界主动调整位置
* **群体**：通常单独占据一个射界，多只之间会分层错开
* **巢穴**：巢穴的**主火力点**
* **繁殖**：不繁殖
* **与其他 SRP 宝可梦关系**：原初黄瞳的直接上位形态（`pri_yelloweye -> ada_yelloweye`）
