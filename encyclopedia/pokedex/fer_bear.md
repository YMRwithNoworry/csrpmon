总和 314。SRP 中 health 38.0 / damage 15.0 / armor 8.0 / knockbackResistance 0.8 / speed 0.28 / followRange 32。**与野化牛逐项相同**。区别在源码的行为分支：野化熊走 `status == 1`（与人类、村民同组），**没有野化牛与野化马拥有的 `status == 3` 分支**。

## 设计核心

“野化牛是数量，野化熊是**单体的极限**——它不需要同伴，也不需要计划。”

## 视觉设计

| 部位 | 设计 | 来源 |

**动作姿势**：四足着地但重心明显偏后，蓄力时会把整个上半身抬起；独行——从不与其他野化体并排移动。

## SRP 特征保留

1. **火焰弱点**——类注释：*"fire weakness"*
2. **击杀回复**——类注释：*"kill-fuelled recovery"*
3. **独立的行为分支**——`if (status == 1 && (kind == Kind.BEAR || kind == Kind.HUMAN || kind == Kind.VILLAGER))`，与牛/马的 `status == 3` 不同组
4. **独行猛兽的本能**——宿主的核心行为被推到极限
5. **数值与野化牛完全相同**——38.0 / 15.0 / 8.0 / 0.8 / 0.28 / 32 / 16

## 宝可梦化改造

* **它与野化牛数值逐项相同**，所以我靠源码分支区分：野化熊属于 `status == 1` 组（与野化人类、野化村民一起），而野化牛与野化马拥有 `status == 3` 的独立分支
* **熊的本能是独行**，所以它的失控方向是"单体的绝对力量"。它的专属招式因此围绕**自身状态**而不是队友数量展開——与野化牛正好相反
* 它的肩背隆起是唯一的外形区分点：野化牛是条纹状隆起（冲锋导流），野化熊是整片甲板（承受反冲）

## 特性

**普通特性：焦灼之躯（`scorchedflesh`）**

自身受到的火属性招式伤害提高 50%。对应 `FeralParasiteEntity` 类注释中的 fire weakness。

**隐藏特性：独行重击（`solitarymight`）**

我方场上**不存在**其他 FERAL 层级宝可梦时，自身接触类招式威力提高 40%。对应野化熊的独行本能——**它越孤立越强**。

## 独家技能 1：孤熊重砸 / Solitary Maul

| 字段 | 值 |
|---|---|
| 属性 | 格斗 |
| 分类 | 物理 |
| 威力 | 110 |
| 命中 | 95 |
| PP | 10 |
| 范围 | 单体 |

**效果**：造成伤害。**若我方场上不存在其他 FERAL 层级宝可梦，威力提高 30% 且自身受到的反伤减半**（独行时不必顾虑同伴）。若本次攻击击倒目标，回复 30% 最大 HP。

**触发条件**：取决于我方 FERAL 单位数量——**与野化牛的条件完全相反**。

**视觉表现**：整只身体抬起后用双掌垂直下砸，肩背甲板在落点处绷紧承受反冲，扬起一圈尘土。

**为什么只有它**：与野化牛的**镜像招式**：牛要求同伴越多越强，熊要求**独自一人**。两者数值相同、触发条件完全相反——这就是"宿主本能极端化"最干净的对照。

## 生态

* **生活环境**：感染区外围的林地与洞穴
* **食物**：任何能打倒的东西
* **猎物**：不筛选，但一次只处理一个
* **天敌**：火焰（50% 额外伤害）；以及能持续消耗它的对手
* **行为**：**独行**。与野化牛的群冲形成对比，它从不与其他野化体并排移动
* **群体**：完全独居——这是这一对最重要的区别
* **巢穴**：不建巢，是被巢穴放弃的失控个体
* **繁殖**：不繁殖，由同化熊转化而来
* **与其他 SRP 宝可梦关系**：**由同化熊转化**；与野化牛**数值完全相同但机制相反**（牛靠同伴，熊靠孤立）
