总和 300。SRP 中 health 15.0 / **damage 11.0** / armor 5.0 / speed 0.26。攻击力是同层家畜里最高的（牛 7.0、羊 6.0、猪 3.5）——**因为它是掠食者，不是家畜**。

## 设计核心

“牛和猪是被改造的家畜，鱿鱼本来就是会抓东西的。所以它不需要重新学怎么杀——它只需要学会**在水里等**。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 保留了鱿鱼的筒状外套膜，前端被寄生组织加厚成撞击面 | SRP `sim_squid` 的宿主外形 |
| 眼睛 | 原本的大眼分裂成多枚小眼环列 | 同化特征 |
| 触腕 | 八条触腕 + 两条加长的捕食腕，腕内侧长出倒刺 | 宿主结构 + 寄生改造 |

| 体表 | 覆有湿润的暗红寄生膜，离水后迅速干瘪 | `!isInWaterOrBubble()` 时的下沉行为 |
| 颜色 | 暗红寄生膜 + 残留的鱿鱼青灰 | SRP 模型配色 |

**动作姿势**：水中水平悬浮、触腕向后收拢随时弹射；离水后身体迅速塌软并下沉。

## SRP 特征保留

1. **水域绑定**——`WaterBoundPathNavigation`
2. **离水即下沉**——`if (kind == Kind.SQUID && !isInWaterOrBubble()) setDeltaMovement(...add(0.0D, -0.02D, 0.0D))`
3. **八腕 + 捕食腕的宿主结构**
4. **同层最高的家畜攻击力**——damage 11.0
5. **熔解时长为 0、融合值为 0**——`SQUID(..., 0, 0)`
6. **死亡不生成头颅**——`case BEAR, SQUID -> null`
7. **不会转化为野化体**——`case SQUID -> null`

## 宝可梦化改造

* **它是一个"死胡同"**：源码里它的熔解时长为 0、融合值为 0、死亡不生成头颅、也不转化为野化体。**四条下游路径全部为 null。** 我没有为它发明任何后续形态，而是把这个事实写进设计
* **"离水即下沉"是一条很具体的物理行为**，我把它做成硬机制：不在水属性场地/雨天时，它的速度与输出都大幅下降
* 它的攻击力高于牛和羊，说明源码把它定位成**掠食者而非家畜**。所以我没有给它"温顺的家畜"设计，而是给它伏击型打法

## 特性

**普通特性：离水瘫软（`stranded`）**

自身在水属性场地或雨天时速度提升 1 阶段；**不在水域时速度下降 1 阶段且受到的伤害提高 15%**。对应 `WaterBoundPathNavigation` 与离水下沉逻辑。

**隐藏特性：无后续形态（`terminalform`）**

—（本特性仅用于说明）：**源码中该生物的四条下游路径全部为 null**（熔解时长 0、融合值 0、无头颅、无野化体）。因此不提供任何基于"后续形态"的机制。

## 独家技能 1：腕足伏击 / Tentacle Ambush

| 字段 | 值 |
|---|---|
| 属性 | 水 |
| 分类 | 物理 |
| 威力 | 85 |
| 命中 | 100 |
| PP | 10 |

**效果**：**必须先处于水属性场地或雨天**才可使用。先制 +1，命中后使目标速度下降 2 阶段并在 2 回合内无法被替换下场（触腕缠住）。

**触发条件**：**必须有水**。干燥场地上此招式不可用。

**视觉表现**：外套膜压缩蓄力后从水底弹射，八条触腕同时张开包向目标，捕食腕收紧拖拽。

**为什么只有它**：`WaterBoundPathNavigation` 与八腕结构的翻译。**它与其他同化体最大的区别在于"必须先有水"**——家畜同化体在陆地作战，它不行。

## 生态

* **生活环境**：感染区的水体——它**不能离开水**
* **食物**：水中的猎物
* **猎物**：进入水域或在水边停留的目标
* **天敌**：任何能把它逼上岸的对手（离水后它几乎失去战斗力）
* **行为**：水底伏击，弹射缠斗。从不主动上岸
* **群体**：通常单独占据一片水域
* **巢穴**：不属于巢穴结构，是水域的被感染原住民
* **繁殖**：不繁殖，由被感染的鱿鱼转化而来
* **与其他 SRP 宝可梦关系**：**在所有同化体中，它是唯一没有下游路径的**：不熔解、不融合、不留头颅、不野化（源码中四个分支全为 null）
