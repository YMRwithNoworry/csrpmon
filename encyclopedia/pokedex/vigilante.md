总和 438。SRP 中 health 70.0 / **armor 25.0（PURE 层最高，也是全图鉴最高之一）** / damage 23.0 / **speed 0.20（PURE 层最慢）** / knockbackResistance 1.0 / followRange 32。**它既不会飞也不会爬**——`flying = false, climbs = false`。

## 设计核心

“别的纯化体会飞、会爬、会绕。它什么都不会——**它只是走过来，而且你打不动它。**”

## SRP 特征保留

1. **PURE 层最高护甲**——armor **25.0**
2. **PURE 层最慢速度**——speed **0.20**
3. **完全免疫击退**——knockbackResistance **1.0**
4. **既不会飞也不会爬**——`Kind.VIGILANTE(false, false, ...)`，两个布尔值都是 false
5. **高生命**——health 70.0

## 宝可梦化改造

* **`flying = false, climbs = false` 是 PURE 层唯一的双 false**（其余六只至少会飞或会爬）。我把它当作它的核心身份：**它只能走，而且走得很慢**
* **armor 25.0 是全图鉴最高档**，所以它是纯粹的坦克。我没有给它任何机动手段——那会否定它的两个 false
* 它的名字 Vigilante（治安者）与它的行为一致：不追、不绕、不逃，只是**站在你必须经过的地方**

## 特性

**普通特性：全覆甲板（fullplate）**

自身受到的物理招式伤害减少 40%，且**完全免疫击退与强制换场**。对应 armor 25.0 与 knockbackResistance 1.0。

**隐藏特性：不会飞也不会爬（groundbound）**

—（说明性特性）：源码中它的 `flying` 与 `climbs` 两个布尔值**均为 false**，是 PURE 层唯一一个。因此本条目不提供任何浮空或攀爬类招式。

## 独家技能 1：装甲推进 / Armored Advance

| 字段 | 值 |
|---|---|
| 属性 | 钢 |
| 分类 | 物理 |
| 威力 | 100 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体 |

**效果**：造成伤害。**自身本回合每受到过一次攻击，威力提高 20%（最多 +60%）**——它把被打当成前进的动力。使用后自身速度不变（它本来就不会变快）。

**触发条件**：取决于本回合受击次数。

**视觉表现**：缓慢抬步向前压上，甲板上的凹痕在推进过程中逐渐增多，撞上目标时整体重量压过去。

**为什么只有它**：armor **25.0** + knockbackResistance **1.0** + 两个 false 的组合翻译。**它是全族唯一「挨打越多打得越重」的招式**——因为它除了挨打什么也做不了。

## 独家技能 2：落锚固守 / Plate Anchor

| 字段 | 值 |
|---|---|
| 属性 | 钢 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 10 |
| 范围 | 自身 |

**效果**：**完全固定自身位置**：此后 3 回合内自身**无法被任何方式移动**（包括自身招式），但受到的伤害减少 35% 且不会被强制换场。造成 0 点伤害。

**触发条件**：无。

**视觉表现**：整片甲板向下沉压并嵌入地面，甲板之间渗出硬化生物质把躯体锚在地上，几乎无法再抬起。

**为什么只有它**：治安者是 PURE 层唯一 `flying = false` 且 `climbs = false` 的成员，护甲 25.0 为该层最高。主招式用它挨打换输出，**这一招干脆把自己钉死在地上**——一个连爬都不会的东西，只剩下站得更稳。

## 生态

* **生活环境**：感染区的通道与要冲——它被放在必须通过的位置
* **食物**：被感染的猎物
* **猎物**：不追。它等目标自己进入范围
* **天敌**：能无视物理减伤的手段，以及能完全绕过它的机动单位
* **行为**：直线推进，不转向、不攀爬、不浮空。**它只有一条路径**
* **群体**：通常单独驻守
* **巢穴**：巢穴的**重装守卫**
* **繁殖**：不繁殖，由巢穴生产
* **与其他 SRP 宝可梦关系**：PURE 层唯一既不会飞也不会爬的成员；与兵卒（会爬）、轻轰炸机（会飞）形成明确的机动性对照
