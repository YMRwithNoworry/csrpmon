## 宝可梦化改造

* **`isRooterBall()` 的提前 return 是这一只的全部定义**：它不移动、不感知、不召唤、不铺雾、不加持、不破坏方块——**它什么都不做**
* **但仍然给了它 20 点生命与 10 点护甲**，说明源码希望它**能被打破，只是不会还手**。所以我把它的种族值做成了极端防御向：防御 120 / 特防 110，攻击 8 / 特攻 14 / 速度 2
* **它是全图鉴唯一"零行为"的生物**。按你的规则十六，我把它定位成**纯结构体**而不是战斗单位——这正是它被设计成的样子

## 特性

**普通特性：惰性结构（inert）**

**自身不会执行任何主动行为**：不受召唤、场地、位移类效果影响；但自身也**无法使用任何需要主动发动的招式**。对应源码 `if (activeKind.isRooterBall()) { return; }`。

**隐藏特性：零参数（zeroparams）**

—（说明性特性）：源码中它的 `attackDamage`、`bombCount`、`activeCap`、`summonCooldown`、`maxBlockHardness`、`blockRange`、`experience` **全部为 0**。因此本条目不提供任何攻击、召唤或环境改造手段。

**为什么只有它**：`isRooterBall()` 提前 return 与全部参数为 0 的翻译。**它是全族唯一「效果栏里什么都没有」的专属招式**——不是设计偷懒，这就是源码里的它。
