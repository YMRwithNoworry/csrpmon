## SRP 特征保留

1. **攀附（MOUNT）机制**——`MOUNT_COOLDOWN_TICKS = 40`
2. **人类的徒手战斗方式**——没有武器、没有工具
3. **`status == 1` 组**——与野化熊、野化村民同组的动画分支
4. **数值全项居中**——24.0 / 7.0 / 15.0 / 0.3 / 0.27 / 32
5. **15% 流血几率**——`MarauderizedParasiteEntity` 的共享常量 `BLEED_CHANCE = 0.15F`
6. **攻击动画时长 12 tick**——`ATTACK_ANIMATION_TICKS = 12`
7. **来源**——由掠夺者（Marauder，PURE 层级）改造生物而成

## 宝可梦化改造

* **`MOUNT_COOLDOWN_TICKS = 40` 是掠夺化人类独有的常量**，源码里其他掠夺化体都没有。对攻击性改造体而言，MOUNT 意味着**它会扑到猎物身上不下来**
* 所以我没有把它设计成又一个徒手打手，而是**攀附型**：一旦贴上就持续造成伤害，且很难被甩掉
* 它与掠夺化村民的对照：村民是站桩射击，人类是**贴身缠斗**

## 特性

**普通特性：攀附（cling）**

自身使用的接触类招式命中后，**目标无法在本回合替换下场**；且自身下一次受到的攻击伤害减少 20%（贴在对方身上不好打）。对应 `MOUNT_COOLDOWN_TICKS = 40`。

**隐藏特性：甩不掉（hardtoshake）**

自身攀附状态下每回合结束时，对目标造成 1/16 其最大 HP 的固定伤害。**只有击倒自身或目标才能解除**。对应 MOUNT 的持续时间特性。

## 独家技能 1：攀附钩击 / Mount Claw

| 字段 | 值 |
|---|---|
| 属性 | 格斗 |
| 分类 | 物理 |
| 威力 | 70 |
| 命中 | 100 |
| PP | 15 |
| 范围 | 单体 |

**效果**：造成伤害并**攀附到目标身上**：此后每回合结束对目标造成 1/16 最大 HP 固定伤害，目标无法替换下场，直到自身被击倒。**攀附期间自身受到的伤害减少 20%**。

**触发条件**：无。

**视觉表现**：扑向目标并用手部钩爪扣住对方肩背，整个身体贴上去，之后无论目标如何移动都不松手。

**为什么只有它**：`MOUNT_COOLDOWN_TICKS = 40` 与人类「徒手」特征的翻译。**它是全族唯一拥有持续攀附状态的生物**——其他掠夺化体都是一次性攻击，它是**一段关系**。
