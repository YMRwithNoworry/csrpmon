总和 414。**这是全族最"能打"的原生体之一**：SRP 中 health 45 / armor 15.0 / damage 30.0，而同期其他原生体多在 30~45 血、4~9 甲、6~15 伤害。它还是唯一拥有 **5 个飞行相关目标**的生物。

## 设计核心

“它不落地、不咬人、不喷毒。它**在你头顶盘旋，然后扔东西下来**。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 朝下的扁平投放腔，两侧各有进气孔 | `DropPayloadGoal` 与 `bomb.configure(...)` |
| 眼睛 | 四枚朝下的复眼，只在俯冲时张开 | SRP VerminEntity 的飞行形态 |
| 载荷腔 | 腹部中空的挂载腔，装填时可见轮廓 | `DropPayloadGoal` 的炸弹 |

| 颜色 | 暗褐主体 + 投放腔暗绿 | SRP 模型配色 |

**动作姿势**：全程滞空。充能时会悬停并整体绷紧，投弹瞬间短暂收翅俯冲后立刻爬升。

## SRP 特征保留

1. **飞行**——`setNoGravity(true)` + 五套飞行目标
2. **充能攻击**——`ChargeAttackGoal`，`FLIGHT_FLAGS` 的 bit 1 记录 charging 状态
3. **投弹**——`DropPayloadGoal`，内部 `bomb.configure(this, 60, 0.0F, ATTACK_DAMAGE, ...)`
4. **飞行高度限制**——`FlightHeightLimitGoal(MobsConfig.yelloweyeMaxFlightHeight())`
5. **高数值**——health 45 / armor 15.0 / damage 30.0
6. **具备适应能力**——原生体层级 `supportsDamageAdaptation()` 返回 true

## 宝可梦化改造

* **它有一套完整的空中作战循环**：充能 → 投弹 → 随机飞行调整位置。这比大多数原生体复杂得多，我如实保留为"蓄力一回合 → 投弹 → 重新定位"的三段结构
* **它是唯一以投弹为主要输出手段的原生体**。近战对它是次要的，所以我没有给它任何近战专属招式
* `yelloweyeMaxFlightHeight` 这个配置名很有意思——飞行高度上限是共用参数，说明飞翔类在实现上属于同一套系统

## 特性

**普通特性：滞空投弹（`airbombing`）**

自身处于浮空状态时，使用投弹类招式的威力提高 25%；被强制落地（受到地面类招式命中）的回合内无法使用投弹类招式。对应 `DropPayloadGoal` 与 `setNoGravity(true)`。

**隐藏特性：充能前兆（`chargewarning`）**

自身使用蓄力类招式的回合结束时，全身纹路亮起；下一回合投弹威力提高 50%。对应 `FLIGHT_FLAGS` 的 charging 位与 `ChargeAttackGoal`。

## 独家技能 1：载荷投下 / Payload Drop

| 字段 | 值 |
|---|---|
| 属性 | 虫 |
| 分类 | 物理 |
| 威力 | 95 |
| 命中 | 95 |
| PP | 10 |
| 范围 | 单体，全场 |

**效果**：无视距离，对目标投下一枚载荷。**必须先蓄力一回合**（本回合不造成伤害）；蓄力回合结束时对手可看到预警。命中后对目标周围造成 25% 的溅射伤害。

**触发条件**：需蓄力一回合；若蓄力回合中自身被强制落地则中断。

**视觉表现**：悬停并整体绷紧、纹路亮起；下一回合收翅俯冲，从腹部投放一具暗绿色载荷，落地炸开并溅出寄生组织。

**为什么只有它**：`DropPayloadGoal` 与 `bomb.configure(this, 60, 0.0F, ATTACK_DAMAGE, ...)` 的翻译。**原初害兽是全族唯一的空中投弹单位**——它的输出不来自接触，而来自"从上方扔下来"。

## 生态

* **生活环境**：感染区上空——它与载虫飞行的方式完全不同，是持续滞空而不是投放后离开
* **食物**：靠巢群供给，自身不落地进食
* **猎物**：地面上的移动目标
* **天敌**：能打到高空的手段；它 armor 15.0 虽然高，但一旦被强制落地就失去投弹能力
* **行为**：盘旋—充能—俯冲投弹—爬升。全族唯一的循环式空中攻击
* **群体**：通常 2~3 只分层盘旋，错开投弹节奏
* **巢穴**：巢穴的**空中打击单位**
* **繁殖**：不繁殖
* **与其他 SRP 宝可梦关系**：适应害兽的前置形态（`pri_vermin -> ada_vermin`）
