总和 354。SRP 中 health 22.0 / damage 9.0 / armor 3.0 / knockbackResistance **0.5**。但它的核心不在数值——源码里有一段明确注释描述了它的攻击方式：**蓄力 60 tick，然后以 15 tick 间隔吐出 3 枚蛛网球，射程 65 格**。

## 设计核心

“别的同化体冲上来。它**在 65 格外蓄力，然后连续吐三发网**——等它停下来的时候，你已经动不了了。”

## SRP 特征保留

1. **蛛网齐射**——注释原文：*"the spider charges for sixty ticks, then spits three web balls fifteen ticks apart while its target stays alive, within 65 blocks"*
2. **蓄力状态**——`webChargeCued`
3. **射击计数**——`webVolleyShots` / `webVolleyTimer`
4. **高击退抗性**——0.5，比牛（0.4）还高
5. **内部名 dorpa**——源码注释明确记录
6. **四条下游路径全部为 null**——`case BIGSPIDER -> null`（头颅与野化各一处）、`meltDuration = 0`、`mergeValue = 0`

## 宝可梦化改造

* **"蓄力 60 tick，然后 3 发，间隔 15 tick，射程 65 格"是一组非常精确的参数**，我把它完整翻译成"蓄力一回合 → 连续三回合各射一发"，而不是一次性三连
* **它是一个和同化鱿鱼一样的终点**：`case BIGSPIDER -> null` 出现了两次（头颅与野化），熔解时长与融合值也都是 0。我没有为它发明后续形态
* **65 格射程在宝可梦里不存在**，所以我用"无视距离但可被规避"来表达——与黄瞳的"必中"区分开：它的网**可以被躲开**

## 特性

**普通特性：蛛网蓄力（`webloading`）**

自身使用蓄力类招式的回合结束时，全身纹路亮起；下一回合的蛛网类招式威力提高 40%。对应 `webChargeCued` 与 60 tick 蓄力。

**隐藏特性：无后续形态（`terminalform`）**

—（说明性特性）：源码中它的头颅生成与野化转化**两个分支都返回 null**，熔解时长与融合值均为 0。因此不提供任何基于后续形态的机制。

## 独家技能 1：蛛网齐射 / Web Volley

| 字段 | 值 |
|---|---|
| 属性 | 虫 |
| 分类 | 特殊 |
| 威力 | 45 |
| 命中 | 90 |
| PP | 10 |
| 范围 | 单体，全场 |

**效果**：**蓄力一回合**（本回合不造成伤害，但对手可见蓄力前兆），之后连续 3 个回合每回合各射出 1 枚蛛网球（共 3 枚，对应 3 shots）。每次命中使目标速度下降 1 阶段；累计命中 3 次后目标在 1 回合内无法被替换下场。

**触发条件**：需完成蓄力回合；若蓄力中被击倒则中断。

**视觉表现**：吐丝腔鼓起并发亮，随后连续三轮各吐出一枚拖着黏丝的球体，命中后在地面留下大片蛛网痕迹。

**为什么只有它**：`EntityAIAttackProjectile(this, 60, 15, 3)` 的逐字翻译：60 tick 蓄力、3 发、15 tick 间隔。**命中率 90 而不是必中**——因为源码里它是投射物，可以被打断或躲开。这是它与黄瞳"必中炮击"的关键区别。
