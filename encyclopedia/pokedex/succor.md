## 设计核心

“其他纯化体都在杀。**它是唯一一个来救的**——虽然它自己脆得像纸。”

**动作姿势**：始终悬浮在同伴上方不远处，不停移动；从不接近敌方。

## SRP 特征保留

1. **攻击力几乎为零**——attackDamage **1.0**
2. **最低护甲之一**——armor **2.0**
3. **PREEMINENT 层最快速度**——speed **0.32**
4. **独立实现类**——`FlamEntity`，与其余四只 Preeminent 的 `PreeminentParasiteEntity` 不同
5. **最远的感知范围**——followRange **80**

## 宝可梦化改造

* **damage 1.0 与 armor 2.0 同时出现**，说明源码把它定义为一个**完全非战斗**的单位。我没有给它任何攻击手段——它连自保都做不到
* **它用的是独立的 `FlamEntity` 类**，而其余四只 Preeminent 共用 `PreeminentParasiteEntity`。这在源码里就是一个明确的信号：**它不是战斗单位**
* 它是全图鉴唯一的**纯治疗/援护型**——按你的规则十六，辅助型也必须有真实战斗价值，所以它的价值是**让其他 Preeminent 活得更久**

## 特性

**普通特性：援护辉光（succorglow）**

自身在场时，我方**所有 PREEMINENT 层级宝可梦每回合回复 6% 最大 HP**。对应它持续散发的低频辉光与 Succor（援护）之名。

**隐藏特性：脆弱本体（fragilebody）**

—（说明性特性）：源码中它的 attackDamage 为 **1.0**、armor 为 **2.0**，两者都接近下限。因此本条目不提供任何直接攻击招式，其价值完全来自对队友的支援。

## 独家技能 1：援护波动 / Succor Wave

| 字段 | 值 |
|---|---|
| 属性 | 妖精 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 10 |
| 范围 | 我方全体 |

**效果**：我方全体回复 25% 最大 HP，并清除所有【感染】层数。**自身不回复**（它把资源全给了别人）。造成 0 点伤害。

**触发条件**：无。

**视觉表现**：全身辉光骤然增强并向外扩散成一圈粉色波纹，波纹扫过的同伴身上寄生组织暂时转为稳定色，而它自己的体表则变得更薄。

**为什么只有它**：attackDamage **1.0** 与 *Succor*（援护）之名的翻译。**它是全族唯一以治疗为核心、且自身完全不获得治疗效果的招式**——一个 85 血 2 甲的东西，靠活得比队友短来体现价值。

## 独家技能 2：援护链接 / Suckling Link

| 字段 | 值 |
|---|---|
| 属性 | 妖精 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 10 |
| 范围 | 我方单体 |

**效果**：**与一只我方宝可梦建立链接**（3 回合）：期间该宝可梦每回合回复 6% 最大 HP，而**自身受到的伤害提高 30%**（它把防护也一并承担了）。造成 0 点伤害。

**触发条件**：无。

**视觉表现**：背侧膜翼状结构伸出一条半透明的粉紫丝线连向同伴，丝线持续搏动，而它自己的体表变得更薄更透。

**为什么只有它**：援护的攻击力只有 **1.0**、护甲 **2.0**（`FlamEntity`），是 PREEMINENT 层唯一的非战斗单位。主招式是群体治疗，**这一招把「替别人承担」推到极致——连伤害都替对方挨**。

## 生态

* **生活环境**：感染区后方——它从不接近前线
* **食物**：靠巢群供给
* **猎物**：无。**它完全不攻击**
* **天敌**：任何东西。armor 2.0、damage 1.0，它连自保都做不到
* **行为**：悬浮—移动—释放辉光。**永远在同伴上方**
* **群体**：通常伴随其他 Preeminent 一起出现
* **巢穴**：巢穴的**后勤援护单位**
* **繁殖**：不繁殖，由巢穴生产
* **与其他 SRP 宝可梦关系**：PREEMINENT 层唯一的支援单位；**其实现类 `FlamEntity` 与其余四只不同**，源码层面就把它独立了出来
