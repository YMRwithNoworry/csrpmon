总和 334。**攻击只有 26**——SRP 里 `damage = 6.0D`，是全族最低的攻击力。速度 **0.19** 也是最低档。它的资源全在支援与特防上：`BolsterSupportGoal` 每 60 tick（3 秒）为附近同伴施加一次增益。

## 设计核心

“它自己打不动任何人。它的作用是**让旁边那些打得动的东西更强**。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 钝圆无棱角，正面是一圈持续开合的气孔 | `BolsterSupportGoal` 的增益释放口 |
| 眼睛 | 两枚低垂的暗色眼，不看前方而看两侧同伴 | 支援定位的外形化 |
| 背腺 | 成排的囊状腺体，释放时会依次鼓起 | 60 tick 的周期性增益 |
| 肢体 | 四足粗短，步频极低 | 速度 0.19 的外形依据 |
| 皮肤 | 出生时随机获得**病毒皮或厚重皮**（源码里二选一） | `setBolsterSkin(random.nextBoolean() ? BOLSTER_SKIN_VIRULENT : BOLSTER_SKIN_HEAVY)` |
| 颜色 | 随皮肤变化：病毒皮暗紫 / 厚重皮深灰 | SRP 皮肤系统 |

**动作姿势**：永远站在同伴中间，身体持续微幅鼓动；释放增益时背腺会从后向前依次亮起。

## SRP 特征保留

1. **周期增益**——`BolsterSupportGoal` 中 `buffTimer < 60` 的判断，即每 60 tick 释放一次
2. **极低攻击**——`damage = 6.0D`，全族最低
3. **极低速度**——`speed = 0.19D`
4. **皮肤二选一**——出生时 `random.nextBoolean()` 决定是 `BOLSTER_SKIN_VIRULENT` 还是 `BOLSTER_SKIN_HEAVY`
5. **病毒接触**——病毒皮时近战施加 `ModMobEffects.VIRAL` 40 tick；`push()` 中同样会施加
6. **专属球体效果**——`MobsConfig.bolsterOrbEffects()`
7. **具备适应能力**——原生体层级 `supportsDamageAdaptation()` 返回 true

## 宝可梦化改造

* **`damage = 6.0D` 这个数字我完全保留**：它几乎不能造成伤害，所以它的价值必须全部来自增益。我不给它任何高威力招式
* **皮肤在出生时二选一**是一条明确的分支逻辑，我把它做成特性：**同一只生物，两种完全不同的辅助路线**
* 它的增益周期是 60 tick（3 秒），比 Reeker 的招募（20 tick）慢得多——说明它是**低频高效**型，而不是高频骚扰型

## 特性

**普通特性：援护分泌（`bolstersecretion`）**

每 3 回合结束，我方其他宝可梦的攻击与特防各提升 1 阶段（下场后失效）。对应 `BolsterSupportGoal` 的 60 tick 周期。

**隐藏特性：皮肤二选一（`skinchotomy`）**

出场时随机获得一种皮肤：**病毒皮**——自身接触类招式附加【病毒侵蚀】；**厚重皮**——自身受到的伤害减少 15% 但速度下降 1 阶段。对应出生时 `random.nextBoolean()` 的固定分支。

## 独家技能 1：援护脉冲 / Bolster Pulse

| 字段 | 值 |
|---|---|
| 属性 | 虫 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 10 |
| 范围 | 我方全体 |

**效果**：我方全体回复 25% 最大 HP 并清除一项能力下降。**病毒皮时**：追加使对手全体获得 1 层【感染】；**厚重皮时**：追加使我方全体防御 +1 阶段。

**触发条件**：效果取决于出场时的皮肤。

**视觉表现**：背腺从后向前依次鼓起，向四周扩散出可见的脉冲环；病毒皮时环呈暗紫，厚重皮时呈灰白。

**为什么只有它**：`BolsterSupportGoal` 的 60 tick 周期增益被提升为一个主动招式，并按皮肤分化为两条路线。**它是全族攻击力最低、但辅助能力最纯的生物**——这一点来自 `damage = 6.0D` 这个事实。

## 生态

* **生活环境**：感染区的中心与巢穴内部——它总是待在同伴最多的地方
* **食物**：靠同伴带回，自身不狩猎
* **猎物**：不狩猎（攻击力 6.0）
* **天敌**：能越过前排直取它的高速单位。它耐久一般、速度极低
* **行为**：跟随同伴移动，保持在群体中心；受威胁时不会逃跑，只是继续释放增益
* **群体**：它本身就是群体单位——单独出现时几乎无价值
* **巢穴**：巢穴的**支援核心**
* **繁殖**：不繁殖
* **与其他 SRP 宝可梦关系**：适应援护的前置形态（`pri_bolster -> ada_bolster`）
