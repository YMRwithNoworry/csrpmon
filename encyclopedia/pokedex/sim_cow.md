总和 280。SRP 中 health 18.0 / damage 7.0 / armor 5.0 / knockbackResistance **0.4** / speed 0.25。击退抗性 0.4 在牛类里偏高，且它有一项专属同步数据 **`COW_CHARGE_STATE`**——它会**冲锋**。

## 设计核心

“它还是牛。它还是会低头、加速、撞过来——只是撞完之后，你身上会多出点东西。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 保留了牛的头骨轮廓，额角被寄生组织包裹并加长 | SRP `sim_cow` 的头部 |
| 眼睛 | 原本的牛眼位置被一层暗红薄膜覆盖 | 同化特征 |
| 背部 | 脊椎沿线长出一排低矮的寄生结节 | 同化体的寄生组织 |
| 四肢 | 仍是牛的四蹄，但关节外翻、蹄部硬化 | 宿主外形保留 |
| 冲锋姿态 | 低头时会从颈侧张开两片导流板 | `COW_CHARGE_STATE` 同步数据 |
| 颜色 | 暗红褐寄生组织 + 残留的牛皮色斑块 | SRP 模型配色 |

**动作姿势**：平时低头吃草式的缓慢移动；冲锋时把头压到最低、身体拉直，颈侧导流板张开。

## SRP 特征保留

1. **冲锋行为**——专属同步数据 `COW_CHARGE_STATE`
2. **牛的外形与四蹄**——同化体保留宿主轮廓
3. **击退抗性 0.4**——比同层多数更高，冲锋时不易被打断
4. **死亡后留下行走头颅**——`AssimilatedParasiteEntity` 中 `case COW -> ModEntities.SIM_COW_HEAD.get().create(serverLevel)`
5. **可参与融合**——`meltDuration = 73`、`mergeValue = 1`
6. **攻击附带恐惧**——`ParasiteCombatEffects.applyFearFromDamage(...)` 是所有同化体共有的

## 宝可梦化改造

* **"宿主能力 + 寄生能力"是这一层的设计铁律**。牛的能力是**冲锋**，寄生的能力是**腐蚀接触**——两者叠在一起，而不是变成一只普通的毒虫
* **死亡后头颅会站起来走掉**是源码写死的行为。我把它做成机制：被击倒时会留下一个"余韵"效果（下回合对击倒者施加标记），代表头还在
* 它的数值刻意偏低（总和 280）——**同化体不是战斗精英，它是被改造的家畜**

## 特性

**普通特性：低头冲锋（`headlongcharge`）**

自身使用接触类招式时，若本回合未受到过伤害，先制 +1 且威力提高 20%。对应 `COW_CHARGE_STATE` 的冲锋行为。

**隐藏特性：头颅残余（`residualhead`）**

自身被击倒时，对击倒者施加【猎物标记】2 回合。对应死亡时生成 `sim_cowhead` 的源码行为。

## 独家技能 1：低头冲撞 / Headlong Charge

| 字段 | 值 |
|---|---|
| 属性 | 一般 |
| 分类 | 物理 |
| 威力 | 80 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体 |

**效果**：先制 +1。命中后使目标获得 1 层【感染】，并使自身受到的反伤减半（冲锋的惯性抵消了反冲）。

**触发条件**：无。

**视觉表现**：低头压到最低、颈侧导流板张开，四蹄交替加速撞向目标，撞击处溅出暗红寄生组织。

**为什么只有它**：`COW_CHARGE_STATE` 的翻译。**它是全族唯一以"牛式冲锋"为核心的招式**——宿主的行为被完整保留，寄生只负责在撞击瞬间注入。

## 生态

* **生活环境**：感染区外围的“牧场”——它仍停留在牛原本活动的地方
* **食物**：被同化的草料与生物质
* **猎物**：不主动狩猎，但会冲锋任何靠近的东西
* **天敌**：能打断冲锋的控制手段
* **行为**：平时缓慢游荡；一旦锁定目标就低头冲锋
* **群体**：与被同化的同类一起活动，仍保持牛群习惯
* **巢穴**：不建巢，属于巢穴的**外围单位**
* **繁殖**：不繁殖，由被感染的牛转化而来
* **与其他 SRP 宝可梦关系**：**死亡后留下同化牛头**（`sim_cowhead`）；可转化为**野化牛**（`fer_cow`）；凑齐条件会熔解进入蠕动血肉融合系统
