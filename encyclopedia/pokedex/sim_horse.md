总和 312。SRP 中 health 24.0 / damage 7.5 / armor **0.5** / speed 0.27。它是同化家畜里**体型最高的一只**（`baseHeight = 1.75`，与人类同级），且拥有一个额外的动画状态 `AGE_STATUS_2`——源码里 `case HORSE -> status == 2 ? AGE_STATUS_2 : AGE`。

## 设计核心

“它还是四足奔跑的东西，只是现在它的每一次冲刺都带着感染。**家畜里跑得最稳的一只。**”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 保留了马的狭长颅骨与鬃毛根部 | SRP `sim_horse` 的宿主外形 |
| 眼睛 | 原本的马眼被暗红薄膜覆盖，侧位视野保留 | 同化特征 |
| 躯体 | **最高的同化家畜**，四肢细长、胸腔大 | `baseHeight = 1.75` |
| 四肢 | 保留完整的马蹄与奔跑结构 | 唯一拥有第二套动画状态的同化体 |
| 鬃尾 | 鬃毛与尾巴大部分脱落，只留根部 | 寄生组织侵蚀 |
| 颜色 | 暗红寄生组织 + 残留的棕/黑色马毛 | SRP 模型配色 |

**动作姿势**：四足站立、颈部高抬；冲刺时头部前伸、鬃根处的寄生组织向后翻卷。

## SRP 特征保留

1. **体型最高的同化家畜**——`baseHeight = 1.75D`，与人类同级
2. **额外动画状态**——`case HORSE -> status == 2 ? AGE_STATUS_2 : AGE`
3. **完整马蹄与奔跑结构**——mobilitySpeed 0.27
4. **低护甲**——armor 0.5，仅高于猪（0.1）
5. **熔解时长 73**——与牛、熊相同
6. **死亡后留下头颅**——`case HORSE -> ModEntities.SIM_HORSE_HEAD.get().create(serverLevel)`
7. **转化为野化马**——`case HORSE -> ModEntities.FER_HORSE.get().create(level)`

## 宝可梦化改造

* **`AGE_STATUS_2` 是马独有的第二套动画状态**——说明它在实现上有比其他家畜更丰富的动作集。我把它做成"冲刺姿态"：进入冲刺后模型与判定都会改变
* 它**体型最高但护甲极低**（0.5），所以设计上不是坦克而是**高速撞击单位**——靠动能而不是靠甲
* 马的本能是奔跑，所以它的专属招式围绕"距离"与"惯性"，而不是撕咬

## 特性

**普通特性：疾驰姿态（`galloppose`）**

自身使用先制招式或冲刺类招式的回合，速度提升 1 阶段（最多 +2）。对应马独有的 `AGE_STATUS_2` 第二动画状态。

**隐藏特性：惯性冲击（`momentum`）**

自身与目标距离 ≥3 格时，接触类招式威力提高 30%。对应马的冲刺撞击方式。

## 独家技能 1：疾驰冲撞 / Gallop Charge

| 字段 | 值 |
|---|---|
| 属性 | 格斗 |
| 分类 | 物理 |
| 威力 | 95 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体 |

**效果**：先制 +1。**若自身与目标距离 ≥3 格，威力提高 30% 且必定命中**（冲刺距离越长撞得越重）。命中后自身速度提升 1 阶段。

**触发条件**：距离条件——它需要助跑。

**视觉表现**：后腿蹬地起步，四蹄依次加速，头部前伸撞向目标，撞击处溅出寄生组织并向前滑行数格。

**为什么只有它**：`baseHeight = 1.75` 与马独有的 `AGE_STATUS_2` 的翻译。**它是全族唯一把"助跑距离"直接换算成威力的招式**——马的本能被完整保留为机制。

## 生态

* **生活环境**：感染区外围的开阔地带——它需要助跑距离
* **食物**：被同化的草料与生物质
* **猎物**：不主动狩猎，但会冲撞移动中的目标
* **天敌**：能打断冲刺的手段；armor 0.5 让它经不起正面交换
* **行为**：四足游荡—加速—冲撞。冲刺姿态与平时的动作明显不同
* **群体**：与同化牛、羊一同活动，保持原本的牧场结构
* **巢穴**：不建巢，属于巢穴的外围单位
* **繁殖**：不繁殖，由被感染的马转化而来
* **与其他 SRP 宝可梦关系**：同化马头（`sim_horsehead`）；可转化为野化马（`fer_horse`）
