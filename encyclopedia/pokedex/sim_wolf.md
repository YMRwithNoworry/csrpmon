## 基础种族值

| HP | 攻击 | 防御 | 特攻 | 特防 | 速度 | 总和 |
|---|---|---|---|---|---|---|---|
| 46 | 72 | 36 | 40 | 42 | 84 | **320** |

总和 320。速度 **84** 是所有同化体里最高的——SRP 中 mobilitySpeed 0.34，比牛（0.25）、羊（0.28）都快。但它的真正特征不在数值：它有一套**独立于其他同化体的缩解系统**，`SIZE_DECREASE_RATE = 0.005F`、`HEIGHT_DECREASE_RATE = 0.01F`、`MELT_TRANSFORM_THRESHOLD = 0.7F`。

## 设计核心

“别的同化体死后留下头颅。狼不一样——**它在你面前一点点变小，然后变成别的东西。**”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 保留了狼的尖吻，额部被寄生组织从内侧撑裂 | SRP `AssimilatedWolfEntity` 的宿主外形 |
| 眼睛 | 原本的狼眼被暗红薄膜覆盖，夜间会反光 | 同化特征 |
| 体表 | 覆有暗红寄生组织，**体积会随时间持续缩小** | `SIZE_DECREASE_RATE = 0.005F` / `HEIGHT_DECREASE_RATE = 0.01F` |
| 四肢 | 仍是狼的四足，奔跑姿态完整保留 | host 行为保留 |
| 肩部 | 有一处**驯化纹理**残留 | `TAMED_TEXTURE` 同步数据 |
| 腹部 | 进食后会出现明显的鼓胀标记 | `SHRIMP_FED` 同步数据 |
| 颜色 | 暗红寄生组织 + 残留的狼毛灰 | SRP 模型配色 |

**动作姿势**：奔跑时贴地疾冲、尾巴平伸——完全是狼的跑法；缩解过程中体型会肉眼可见地一圈圈变小。

## SRP 特征保留

1. **狼的速度与群猎行为**——mobilitySpeed 0.34，同化体最高
2. **缩解系统**——`SIZE_DECREASE_RATE = 0.005F`、`HEIGHT_DECREASE_RATE = 0.01F`、`MELT_TRANSFORM_THRESHOLD = 0.7F`、`MELT_SOUND_INTERVAL = 20`
3. **驯化纹理**——`TAMED_TEXTURE` 同步数据
4. **进食标记**——`SHRIMP_FED` 同步数据
5. **熔解时长最短**——`WOLF(..., meltDuration = 19, mergeValue = 1)`，其他同化体多在 63~127
6. **两套转化系统的分歧点**——`ParasiteTransformation.evolutionType()` 明确排除 `sim_wolf`，但 `AssimilatedParasiteEntity.transformToFeral()` 中 `case WOLF -> ModEntities.FER_WOLF.get().create(level)` 又确实会把它转成野化狼。**两套机制不一致，本图鉴如实记录**

## 宝可梦化改造

* **"缩解"是这个模组里最诡异的机制之一**：它不是爆炸式变形，而是**体积一帧一帧地缩小**（0.005/0.01 每 tick），到 0.7 阈值才转化。我把它做成"每回合失去一部分体型，但获得速度"的倒计时机制
* **它是两套转化系统的分歧点**：`ParasiteTransformation`（进化法杖）明确排除它，而 `AssimilatedParasiteEntity.transformToFeral()`（熔解系统）中 `case WOLF -> FER_WOLF` 又会转化它。**同一份源码里两种说法**，我两处都记，不替它选一个
* `TAMED_TEXTURE` 说明**被驯服的狼也会被同化**——这一点我保留在特性里：它对人形目标有特殊的追击倾向

## 特性

**普通特性：缩解（`shrinkmelt`）**

自身每回合结束时防御下降 1 阶段（可降至 -3），但速度提升 1 阶段（最多 +3）。**当防御降至 -3 时，本场战斗结束后有特殊转化效果**（对应 `MELT_TRANSFORM_THRESHOLD = 0.7F`）。

**隐藏特性：驯化残留（`tamedresidue`）**

自身对拥有"训练师"类特征的目标（或我方宝可梦所对应的对手）造成的伤害提高 20%。对应 `TAMED_TEXTURE`——连被驯服的狼也会被同化，而它记得这一点。

## 独家技能 1：缩解突袭 / Shrink Rush

| 字段 | 值 |
|---|---|
| 属性 | 恶 |
| 分类 | 物理 |
| 威力 | 80 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体 |

**效果**：先制 +1。**自身每损失 1 阶段防御，本招式威力提高 10%**（最多 +30%）。命中后自身防御再下降 1 阶段。

**触发条件**：无。

**视觉表现**：体型比上一回合更小的狼贴身掠过，速度肉眼可见地加快，命中的瞬间体表又缩了一圈。

**为什么只有它**：`SIZE_DECREASE_RATE` / `HEIGHT_DECREASE_RATE` / `MELT_TRANSFORM_THRESHOLD` 三项常量的翻译。**它是全族唯一"越打越小、越小越快、越快越痛"的机制**——代价是它自己也在解体。

## 生态

* **生活环境**：感染区外围——它保留了狼的活动范围
* **食物**：被同化的猎物，包括被驯服的动物
* **猎物**：优先追击仍保有"被驯养"特征的目标
* **天敌**：能快速击杀它的对手——它耐久极低（armor 2.0）
* **行为**：群体追猎；一旦受伤会加速缩解
* **群体**：保持狼群结构，是少数仍成群行动的同化体
* **巢穴**：不建巢，狼群自己占据一片领地
* **繁殖**：不繁殖，由被感染的狼转化而来
* **与其他 SRP 宝可梦关系**：同化狼头（`sim_wolfhead`）；**但源码明确排除了 sim_wolf 到 fer_wolf 的路径**，它走自己的缩解转化

## 进化 / 阶段

```
来源：被感染的狼
  ↓

  ↓  缩解（`MELT_TRANSFORM_THRESHOLD = 0.7F`）

⚠ **它是唯一不按 syn -> fer 规则走的同化体**：
`ParasiteTransformation` 的路径规则明确写着 `sim_X -> fer_X` 但**排除 `sim_wolf`**。

```
