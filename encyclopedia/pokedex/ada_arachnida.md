## 宝可梦化改造

* **蓄力 20 tick + 6 发 × 20 tick 间隔**是一套有明确节奏的连射系统，我把它做成"蓄力一回合、之后三回合持续自动射击"的形态，而不是一次性六段攻击——因为源码用的是间隔而不是同时
* 原初形态**完全没有远程招式**，所以这一只的远程系统是纯粹的 tier 增益，不是强化版。但拉拽是共通的，保留为同一招式
* 它拿到了水域跳跃，所以我给了水域相关的通用技能——这是有 `ArachnidaWaterLeapGoal` 作为依据的

## 特性

**普通特性：环列纺器（`ringspinner`）**

自身使用连射类招式的回合结束时，若目标仍在场上，追加一次威力为上回合 1/2 的射击（最多追加 2 次）。对应 `ARACHNIDA_SKILL_SHOT_INTERVAL = 20` 的持续射击节奏。

**隐藏特性：蓄力加速（`chargehaste`）**

自身在蓄力回合受到的伤害减少 30%，且蓄力回合结束时速度提升 1 阶段。对应 `ARACHNIDA_SKILL_CHARGE_TICKS = 20` 的蓄力窗口。

## 独家技能 1：六重牵丝 / Sixfold Volley

| 字段 | 值 |
|---|---|
| 属性 | 虫 |
| 分类 | 特殊 |
| 威力 | 30 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体 |

**效果**：蓄力 1 回合（本回合不造成伤害但受伤减 30%），之后**连续 3 个回合每回合自动造成 2 次攻击**（共 6 次，对应 6 发）。每次命中使目标速度下降 1 阶段（最多 -3），全部命中后目标无法被替换下场 1 回合。

**触发条件**：必须完成蓄力回合；蓄力期间若自身被击倒则中断。

**视觉表现**：腹部抬起、六个喷口同时外翻并亮起暗青；随后每回合射出两束丝，每束命中时目标身上多缠一圈。

**为什么只有它**：`ARACHNIDA_SKILL_CHARGE_TICKS = 20` + `ARACHNIDA_SKILL_SHOTS = 6` + `ARACHNIDA_SKILL_SHOT_INTERVAL = 20` 三项常量的完整翻译。**原初蛛形完全没有远程招式**，所以这不是强化版而是新增系统——tier 差异体现在"有没有这条输出线"上。

## 独家技能 2：牵丝拉拽·适应 / Web Pull (Adapted)

| 字段 | 值 |
|---|---|
| 属性 | 虫 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 100 |
| PP | 15 |
| 范围 | 单体 |

**效果**：把目标拉近并使其在 3 回合内无法被替换下场（原初形态为 2 回合）；速度下降 2 阶段。若目标已处于移动受阻状态，改为使其本回合无法使用先制招式。

**触发条件**：无。

**视觉表现**：六束丝同时射出粘住目标并收紧，八足向后划动把目标拖来。

**为什么只有它**：**与原初蛛形的牵丝拉拽是同一个招式**：回合数 2→3、减速 1→2 阶段、追加先制封锁（对应 `ArachnidaPullSkillGoal` 相较 `WebPullGoal` 的技能化）。同一张网，拉得更紧。
