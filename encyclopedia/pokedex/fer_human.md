总和 300。SRP 中 health 24.0 / damage 15.0 / armor 7.0 / knockbackResistance 0.3 / speed 0.26 / followRange 32。**每一项都在野化层的中段**——它没有一项极端值。

## 设计核心

“野化熊靠重量，野化狼靠速度，野化村民靠硬度。野化人类**什么都没有**——它只有一双还在挥的手。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 人类颅骨被撑裂，面部只剩裂口结构 | 宿主本能极端化 |
| 眼睛 | 两处暗红光点，深陷在骨窝里 | 野化特征 |
| 躯干 | **完全裸露出的人形**——没有护甲、没有衣物残留、没有硬质板 | armor 7.0（全部来自肌肉） |
| 双臂 | 前臂极度发达，指骨外翻成钩状 | damage 15.0 的来源 |
| 背部 | 脊背沿线上只有一列浅层结节 | 没有夸张的寄生结构 |
| 颜色 | 深红寄生组织 + 残存的肤色 | SRP 模型配色 |

**动作姿势**：直立、双臂微微抬起呈抓握姿态；攻击时是连续的多段徒手挥击，没有任何一次性重击。

## SRP 特征保留

1. **火焰弱点**——类注释：*"fire weakness"*
2. **击杀回复**——类注释：*"kill-fuelled recovery"*
3. **完全徒手**——没有武器、没有工具、没有甲板
4. **`status == 1` 组**——与野化熊、野化村民同组
5. **数值全项居中**——24.0 / 15.0 / 7.0 / 0.3 / 0.26 / 32，没有任何一项是极端值

## 宝可梦化改造

* **"没有任何一项极端值"本身就是它的身份**。野化层的其他成员都有鲜明的偏向（熊重、狼快、村民硬、马破甲、羊围堵），人类没有——**它是最平均的那一个**
* 所以我把它做成**连击型**：不靠单次重击，靠多段徒手挥击。这也是唯一符合"徒手"这个特征的方向
* 它与野化村民的关系与本项目其他几组"同源不同向"的案例一致：**村民把"负重"推到极限（击退抗性 0.9），人类把"徒手"推到极限（多段连击）**

## 特性

**普通特性：焦灼之躯（`scorchedflesh`）**

自身受到的火属性招式伤害提高 50%。对应 `FeralParasiteEntity` 类注释中的 fire weakness。

**隐藏特性：不知疲倦（`tirelesshands`）**

自身使用连续攻击类招式时，第二段与第三段不消耗额外 PP，且每段威力递增 10%。对应"徒手连击"的野化形态——**它没有武器可以挥断**。

## 独家技能 1：狂徒连击 / Feral Flurry

| 字段 | 值 |
|---|---|
| 属性 | 格斗 |
| 分类 | 物理 |
| 威力 | 35 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体，连续 3 次 |

**效果**：**连续攻击 3 次**，每次威力 35（合计约 105）。每命中一次使目标防御下降 1 阶段（最多 -3）。**无任何追加条件或威力加成**——它靠段数而不是靠条件。

**触发条件**：无。

**视觉表现**：双臂交替挥出，攻击没有停顿也没有蓄力动作，每一击都比上一击更低、更快，直到手骨外翻的钩状指节砸在目标身上。

**为什么只有它**：damage 15.0 与"完全徒手、无任何极端值"的翻译。**与野化熊的单次重砸（110 一击）形成明确对照**：一个靠重量，一个靠次数。

## 生态

* **生活环境**：感染区外围的人类据点遗址
* **食物**：任何能打倒的东西
* **猎物**：不筛选
* **天敌**：火焰（50% 额外伤害）；它没有任何一项能扛住专精攻击
* **行为**：直线逼近、连续挥击。**没有战术、没有节奏变化**
* **群体**：通常 2~4 只结伴，保留原本的小队结构
* **巢穴**：不建巢，是被巢穴放弃的失控个体
* **繁殖**：不繁殖，由同化人类转化而来
* **与其他 SRP 宝可梦关系**：**由同化人类转化**；与野化村民同为徒手型但方向相反（村民靠硬度、人类靠次数）
