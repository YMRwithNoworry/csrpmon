总和 438（原初形态 378）。攻击 102、速度 74 双升——它不再需要靠"咬住不放"取胜，因为**它可以选择什么时候咬**。SRP 中它获得了 `CloakGoal`、`ManducaterEvadeGoal`、`ManducaterVomitGoal` 三个新目标，近战速度也从 1.0 提到 1.20。

## 设计核心

“同一副颚，只是它学会了先消失。原初形态咬住就不走，适应形态咬完就走——**因为它已经不需要赖着你了**。”

**动作姿势**：默认半蹲、拟态层半开；进入隐匿时轮廓几乎消失，只在攻击瞬间完全显形。

## SRP 特征保留

1. **继承咬合注染**——它仍然属于 MANDUCATER kind，近战注染逻辑与原生体同源
2. **新增隐匿**——`CloakGoal`
3. **新增闪避**——`ManducaterEvadeGoal`
4. **新增呕吐**——`ManducaterVomitGoal`
5. **近战更快**——`MeleeAttackGoal(this, 1.20D, false)`（原初形态为 1.0）
6. **仍具备适应能力**——`supportsDamageAdaptation()` 返回 true

## 宝可梦化改造

* **这一对是规则九的正样本**：适应噬颚不是新物种，它保留原初形态的注染咬合作为核心招式（只是强化了），另外获得三个新系统（隐匿 / 闪避 / 呕吐脱离）
* 三个新目标翻译成宝可梦机制就是：**隐匿**＝一回合内无法被选中；**闪避**＝提高回避；**呕吐**＝主动降低自身受益以换取脱离
* 它的攻击与速度上升、而防御只略微提高——**适应带来的是"打得更准更快"，不是"更能挨打"**

## 特性

**普通特性：拟态薄膜（`cloakfilm`）**

自身在未使用攻击招式的回合结束时进入隐匿：下一回合对手对其使用单体招式的命中率降低 30%。对应 `CloakGoal`。

**隐藏特性：吐囊脱离（`evacuate`）**

自身 HP 低于 35% 时，可在回合结束时脱离战斗（相当于使用急速折返），但脱离时失去 1 层自身增益。对应 `ManducaterEvadeGoal` 与 `ManducaterVomitGoal` 的组合。

## 独家技能 1：巢令噬咬·适应 / Hive-Command Bite (Adapted)

| 字段 | 值 |
|---|---|
| 属性 | 虫 |
| 分类 | 物理 |
| 威力 | 85 |
| 命中 | 100 |
| PP | 15 |
| 范围 | 单体 |

**效果**：造成伤害后**必定**使目标获得 2 层【感染】；若目标已带【感染】，改为 3 层并使其本回合无法被替换。使用后自身进入隐匿（下回合对手单体招式命中率 -30%）。

**触发条件**：无概率判定——适应形态把原初形态的 40% 变成了必然。

**视觉表现**：副颚先快速连咬两次制造伤口，主颚随后合拢注入；注入完成后全身拟态层收拢，轮廓迅速模糊。

**为什么只有它**：**与原初噬颚的巢令噬咬是同一个招式**。三处强化对应源码证据：概率 40%→100%（适应形态不再赌运气）、威力 75→85（近战速度 1.0→1.20）、追加隐匿（`CloakGoal`）。这就是规则九要的"同一物种的专业化版本"，而不是另一套招式表。

## 独家技能 2：匿袭 / Cloaked Ambush

| 字段 | 值 |
|---|---|
| 属性 | 恶 |
| 分类 | 物理 |
| 威力 | 95 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体 |

**效果**：只有在自身处于隐匿状态时可用：必定命中且必定要害。使用后隐匿解除。

**触发条件**：需要先通过拟态薄膜或巢令噬咬·适应进入隐匿。

**视觉表现**：从模糊的轮廓中直接显形并咬向目标侧颈，攻击完成后再次模糊。

**为什么只有它**：`CloakGoal` 与 `ManducaterEvadeGoal` 的组合翻译。它是全族**唯一需要"先隐藏再出手"**的招式——把 SRP 中"先披上伪装再突袭"的两步顺序做成硬前置条件。

## 生态

* **生活环境**：感染区的外围与阴影处——它比原初形态更依赖掩体
* **食物**：被注染后失去抵抗的猎物
* **猎物**：体型中等、落单的目标
* **天敌**：范围伤害与必中类招式——隐匿对它们无效
* **行为**：潜行接近—突袭注染—立刻隐匿脱离。不再长时间缠斗
* **群体**：单独行动，两只适应噬颚会互相回避（争夺同一片潜行区）
* **巢穴**：巢穴的**渗透单位**，被派往需要精确打击的位置
* **繁殖**：不繁殖
* **与其他 SRP 宝可梦关系**：原初噬颚的直接上位形态（`pri_manducater -> ada_manducater`）；与狂噬兽同属注染系但一个靠隐身一个靠吃
