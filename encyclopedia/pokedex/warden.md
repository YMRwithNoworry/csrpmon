## 设计核心

“治安者只会走，君主只会伸。**它会爬到你躲的地方，然后堵在那里。**”

**动作姿势**：贴附在垂直面上时身体完全贴墙、六对钩足分散受力；落地后转为直立，前肢向前张开。

## SRP 特征保留

1. **攀爬**——`Kind.WARDEN(false, true, ...)`，climbs = true
2. **不飞行**——flying = false
3. **PURE 层最高生命档**——health **80.0**
4. **完全免疫击退**——knockbackResistance **1.0**
5. **方块破坏能力**——`blockHardness = 5.0F` / `blockRange = 2.0D`

## 宝可梦化改造

* **`climbs = true` 配 `knockbackResistance = 1.0`** 是一个很明确的组合：它**能到达你所在的位置，而且到了就推不走**。这与治安者（两个都是 false，只能走）形成完整对照
* **它的定位是「看守」**：不追猎（不像兵卒），不支配（不像君主），而是**占据并守住一个位置**
* 它与兵卒同为攀爬者，但兵卒是量产的数量单位（20 血），它是 80 血的固定守卫——**同一层里两种完全不同的攀爬者**

## 特性

**普通特性：分段甲板（segmentedplate）**

自身受到的物理招式伤害减少 25%，且**完全免疫击退与强制换场**。对应 armor 15.0 与 knockbackResistance 1.0。

**隐藏特性：看守本能（wardeninstinct）**

自身在场时，**对手无法对自身以外的目标使用换人类招式**（它堵住了路）。对应它占据位置、攀附看守的定位。

## 独家技能 1：典狱擒抱 / Warden Grasp

| 字段 | 值 |
|---|---|
| 属性 | 地面 |
| 分类 | 物理 |
| 威力 | 95 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体 |

**效果**：造成伤害并使目标**本回合与下回合无法替换下场**。**若自身从攀附状态发动本招式，威力提高 25%**（从上方压制）。

**触发条件**：与自身是否处于攀附状态相关。

**视觉表现**：六对钩足扣住垂直面固定身体，一对抓捕前肢张开并合拢扣住目标，无论对方如何挣扎都不松。

**为什么只有它**：climbs = true + knockbackResistance 1.0 的翻译。**与君主的区别是「方式」**：君主从 2 格外伸手，它**爬到你身边再抓住你**。

## 独家技能 2：看守封锁 / Guard Lock

| 字段 | 值 |
|---|---|
| 属性 | 地面 |
| 分类 | 物理 |
| 威力 | 60 |
| 命中 | 100 |
| PP | 15 |
| 范围 | 单体 |

**效果**：造成伤害并使目标**无法使用替换类招式与道具，持续 3 回合**（对应 `knockbackResistance = 1.0` 的看守定位）。命中后自身防御提升 1 阶段。

**触发条件**：无。

**视觉表现**：六对钩足从垂直面撑开把目标夹在中间，环形扣收紧后不再移动，像把门堵死一样。

**为什么只有它**：典狱长与兵卒同为攀爬者，但它是 80 血守卫而非 20 血量产单位。主招式是擒抱，**这一招把擒抱延展成长期看守**——它不追你，它负责让你走不了。

## 生态

* **生活环境**：感染区的垂直结构与高处——它占据并守住
* **食物**：被抓住的猎物
* **猎物**：不追猎，等待目标靠近它占据的位置
* **天敌**：能无视物理减伤或绕过它的手段
* **行为**：攀附驻守—擒抱—不放手。**它不巡逻，只占据**
* **群体**：通常单独驻守一处关键位置
* **巢穴**：巢穴的**看守单位**
* **繁殖**：不繁殖，由巢穴生产
* **与其他 SRP 宝可梦关系**：与兵卒同为攀爬者但定位相反（兵卒是量产 20 血，它是 80 血守卫）；与治安者形成机动性对照（一个会爬，一个只会走）
