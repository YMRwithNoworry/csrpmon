1. **召唤职能**——`bombCount = 4` / `activeCap = 4` / `summonCooldown = 50`

## 宝可梦化改造

* **它不是战斗单位，是设施。** 25 点生命与 2.5 点攻击说明源码根本没打算让它打架——它的全部价值在 `bombCount` / `activeCap` / `summonCooldown` 三个参数上
* **`storedParasiteIds` 是一个很关键的字段**：它**先把要召唤的个体存起来**，之后再释放。我把它做成了"预先装填"机制
* 按你的规则十，Stage I 应该只有**基础召唤、感染、小范围污染**。这三个正好对应它的 4 个召唤口、25 点生命与 3 格 `blockRange`

## 特性

**普通特性：初阶装填（storedids）**

自身出场时**预先装填 4 只召唤单位**（对应 `bombCount = 4`）。**每次召唤消耗 1 只，装填不可在本场战斗中补充**。对应源码字段 `storedParasiteIds`。

**隐藏特性：固定柱体（immobilepillar）**

自身**完全无法被替换下场，也免疫一切强制位移**；但自身也无法主动替换。对应柱体形态与 `Family.BECKON` 的设施定位。

## 独家技能 1：初级召唤 / Beckon Call I

| 字段 | 值 |
|---|---|
| 属性 | 超能 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 10 |
| 范围 | 自身周围 3 格 |

**效果**：从装填中释放 **1 只寄生体**（只能在白名单内的层级中选择）。**最多同时存在 4 只**（对应 `activeCap = 4`）。使用后需间隔 1 回合（对应 `summonCooldown = 50`）。造成 0 点伤害。

**触发条件**：需要装填数 > 0，且当前召唤数 < 4。

**视觉表现**：柱顶 4 个召唤口中的 1 个张开，暗红生物质从端口涌出并在地面聚合成一具躯体，地表 3 格纹路同时亮起。

**为什么只有它**：`bombCount = 4` / `activeCap = 4` / `summonCooldown = 50` / `blockRange = 3.0` 四项参数的翻译。**它是全族唯一以「装填—释放」为机制的召唤招式**。
