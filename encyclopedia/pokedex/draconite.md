## 设计核心

“它不是被寄生感染的。**它是寄生体长出来的一个新物种**——而且它比这个模组里所有别的东西都强。”

|---|---|---|
| 头部 | **真正的龙形颅骨**，双角向前延伸 | Derived 的异常进化结果 |
| 眼睛 | 成对的纵向竖瞳，飞行时会转为亮色 | FLIGHT_TRANSITION 状态 |

**动作姿势**：滞空时四翼完全展开、颈部前伸；喷火时整个胸腔会明显膨胀一次。

## SRP 特征保留

1. **全图鉴最高攻击力**——damage **210.0**
2. **全图鉴最高生命值**——health **525.0**
3. **四个专属状态**——`STATUS_IDLE = 0` / `STATUS_COMBAT = 1` / `STATUS_FLIGHT_TRANSITION = 3` / **`STATUS_FLAME = 10`**
4. **龙息时长常量**——`FIRE_BREATH_DURATION_TICKS = 40`
5. **飞行**——`FLYING_SPEED = 0.27`
6. **DERIVED 身份**——它是寄生体自行衍生出的新物种，而非被感染的宿主

## 宝可梦化改造

* **`STATUS_FLAME = 10` 与 `FIRE_BREATH_DURATION_TICKS = 40` 是两个明确的常量**：它有一套完整的喷火系统，持续 40 tick。我把它做成独立的龙息招式，而不是普通的火属性攻击
* **210 点攻击力与 525 点生命都是全图鉴最高**——按你的规则，**DERIVED 的核心是「异常进化结果」**，所以我没有把它做成"更强的纯化体"，而是**一个寄生体自己长出来的新物种**
* **它有一条完整的飞行状态链**（IDLE → COMBAT → FLIGHT_TRANSITION → FLAME）——四个状态各有作用，我据此把它做成**多阶段形态**，符合规则对 DERIVED「异常」的要求

## 特性

**普通特性：衍化龙躯（derivedragon）**

自身免疫**火属性招式**（对应 `STATUS_FLAME` 与龙息能力）；且自身的龙属性招式威力提高 25%。

**隐藏特性：四态循环（statuscycle）**

自身在 IDLE / COMBAT / FLIGHT_TRANSITION / FLAME **四种状态间循环**（对应四个 `STATUS_` 常量）：每次切换状态时，本回合使用的招式属性随之改变。

## 独家技能 1：衍化龙息 / Derived Breath

| 字段 | 值 |
|---|---|
| 属性 | 龙 |
| 分类 | 特殊 |
| 威力 | 180 |
| 命中 | 95 |
| PP | 5 |
| 范围 | 全体对手 |

**效果**：对场上**所有对手**造成极高伤害并使各获得 3 层【感染】。**持续 2 回合**（对应 `FIRE_BREATH_DURATION_TICKS = 40`，本图鉴以回合折算）。对应 `STATUS_FLAME = 10`。

**触发条件**：无。

**视觉表现**：胸腔明显膨胀一次，随后从龙颚喷出持续两回合的暗红金色龙息，扫过之处地面熔出沟痕并残留寄生组织。

**为什么只有它**：`STATUS_FLAME = 10` 与 `FIRE_BREATH_DURATION_TICKS = 40` 的翻译。**它是全族威力最高、且持续时间最长的范围招式**——525 点生命与 210 点攻击力支撑得起这个规格。

## 独家技能 2：翔态转换 / Flight Transition

| 字段 | 值 |
|---|---|
| 属性 | 龙 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 10 |
| 范围 | 自身 |

**效果**：在**地面形态**与**飞行形态**之间切换（对应 `STATUS_FLIGHT_TRANSITION = 3`）：地面形态防御提升 1 阶段；飞行形态速度提升 2 阶段且免疫地面类招式。造成 0 点伤害。

**触发条件**：无。

**视觉表现**：四翼从贴伏状态逐节展开，鳞片沿翼骨翻开并发出暗金光泽——整个转换过程耗时一个完整回合。

**为什么只有它**：`STATUS_FLIGHT_TRANSITION = 3` 的翻译。**它是全族唯一拥有「形态转换中间态」的生物**——源码为这个转换过程单独留了一个状态编号。
