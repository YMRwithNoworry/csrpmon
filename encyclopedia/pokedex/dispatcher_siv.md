## 宝可梦化改造

* **`tryPlaceFirstColony()` 是终阶独有的方法**，前三阶没有。而且它的触发条件非常明确：**世界上一块殖民地都没有的时候**才会尝试——**它是"第一块殖民地"的奠基者**
* **它与其他终阶的区别就在这里**：召唤柱终阶扩大召唤规模、根须柱终阶扩大支援范围，而**调度柱终阶建造一个永久结构**
* 我把它做成了**一次性但永久**的机制：定场后本场战斗双方都无法再改变场地——与前三阶的"临时雾幕"形成质变

## 特性

**普通特性：终阶收纳（storeids）**

自身每回合结束时记录对手场上一只宝可梦的招式属性（最多 6 条）。记录过的属性对本次战斗的对手额外生效 30% 伤害。对应 `storedParasiteIds`。

**隐藏特性：第一殖民地（firstcolony）**

自身入场后**满 3 回合**，若场上尚无永久场地结构，则以 100% 概率**建立一块殖民地**：此后**双方均无法改变场地类效果**，且我方全体每回合回复 8% 最大 HP。对应 `tryPlaceFirstColony()`。

## 独家技能 1：殖民地奠基 / Colony Founding

| 字段 | 值 |
|---|---|
| 属性 | 幽灵 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 5 |
| 范围 | 全场 |

**效果**：在场上建立**永久殖民地**：此后**双方的场地类效果都无法被替换或清除**，我方全体每回合回复 8% 最大 HP，对手每回合结束获得 1 层【感染】。**每场战斗只能使用一次**（对应 `!colonies().isEmpty()` 时不再触发）。造成 0 点伤害。

**触发条件**：**必须在场上尚无永久场地结构时使用**。

**视觉表现**：底部奠基腔向下掘进并注入生物质，整片地面从柱体开始向外浮现永久性的暗红脉络——与前三阶的雾幕不同，**这一次的痕迹不会消失**。

**为什么只有它**：`tryPlaceFirstColony()` 的完整翻译：条件为 `tickCount >= 1200`、`random.nextInt(10) == 0`、且 `SrpWorldData.colonies()` 为空。**它是全族唯一「建立永久结构」的招式**——前三阶铺的雾会散，它建的不会。

## 生态

* **生活环境**：感染区的中心——**它建立的位置会成为永久殖民地**
* **食物**：通过庞大的根系吸取整个区域的养分
* **猎物**：无。它不狩猎
* **天敌**：能突破 250 点生命与 28 点护甲的持续输出
* **行为**：**完全静止**。铺雾—收纳—奠基。**建立之后不再迁移**
* **群体**：周围有 7~9 只被收纳后又放出的个体
* **巢穴**：**第一块殖民地的奠基者**，九阶体系的终点
* **繁殖**：不繁殖，通过建立殖民地扩张
* **与其他 SRP 宝可梦关系**：**DISPATCHER 家族终阶**；与其他两个家族终阶的区别：它建造永久结构，另两个只扩大临时影响
