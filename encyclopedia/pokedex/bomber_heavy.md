## 设计核心

“轻轰炸机是侦察机。**它是一整座会飞的要塞**——而它和轻轰炸机一样，一推就飘。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 宽扁的流线型头部，前端有三组投弹口 | 重装轰炸定位 |
| 眼睛 | 朝下的复眼阵列，覆盖整个前缘 | 空中投弹 |
| 翼膜 | **四对翼膜**，跨度远超体型比例，翼根有加固结构 | flying = true |
| 弹仓 | 腹部中空，可见多层载荷架 | damage 33.0 |
| 体表 | 装甲厚重但翼根处仍是薄结构 | knockbackResistance 0.15 |
| 颜色 | 暗红寄生组织 + 翼膜暗褐 + 弹仓暗绿 | SRP 模型配色 |

**动作姿势**：全程滞空、飞行高度比轻轰炸机更高；投弹时不做俯冲，而是**从上方垂直投放**。

## SRP 特征保留

1. **全图鉴最高生命值**——health **420.0**
2. **飞行**——`Kind.BOMBER_HEAVY(true, ...)`
3. **最低击退抗性**——**0.15**，PREEMINENT 层唯一低于 2.0 的成员
4. **最远的感知范围**——followRange **80**
5. **最远的方块触及**——`blockRange = 5.0D`
6. **与轻轰炸机同系列**——两者击退抗性都是 0.15，是这一层唯一共享该数值的一对

## 宝可梦化改造

* **420 点生命配 0.15 击退抗性是一个极端矛盾**：全图鉴最耐打的东西，同时是最容易被推动的东西。我完整保留了这个矛盾，并把它做成机制
* **它与轻轰炸机（PURE 层）共享 0.15 这个数值**，而 PREEMINENT 层其余四只都是 2.0。这说明轰炸机系列在源码里被统一标记为「空中轻质单位」
* **它不做俯冲投弹**（轻轰炸机做），因为它的体型不允许——所以它的攻击方式是从上方垂直投放

## 特性

**普通特性：重装翼膜（heavywings）**

自身受到的远程招式伤害减少 35%；但**受到任何击退/位移类效果时，位移量加倍**。对应 health 420.0 与 knockbackResistance 0.15 的矛盾组合。

**隐藏特性：垂直投放（verticaldrop）**

自身处于浮空状态时，投弹类招式**无视目标的速度变化**（从正上方落下，躲不掉）。对应它与轻轰炸机不同的投放方式。

**效果**：**只有自身处于浮空状态时可用**。对场上**所有对手**造成伤害并各附加 2 层【感染】。**使用后自身击退抗性在本回合内降为 0**。

**触发条件**：**必须浮空**。

**视觉表现**：四对翼膜完全展开保持高度，腹部分层弹仓依次开启，载荷从正上方垂直落下并在多个位置同时炸开。

**为什么只有它**：health **420.0** 与 flying = true 的翻译，并与轻轰炸机的单体投弹形成对照：**轻轰炸机打一个，它清一片**。

* **生活环境**：感染区高空——它飞得比轻轰炸机更高
* **食物**：靠巢群供给
* **猎物**：地面上的集群目标
* **天敌**：**任何位移类效果**——0.15 的击退抗性意味着 420 点生命也可能被推走
* **行为**：高空盘旋—垂直投放—维持高度。**从不降落**
* **群体**：通常单独盘旋，因为它的投放范围已经覆盖整片区域
* **巢穴**：巢穴的**重型空中打击单位**
* **繁殖**：不繁殖，由巢穴生产
* **与其他 SRP 宝可梦关系**：与轻轰炸机（`bomber_light`，PURE 层）同系列的两端：**同一套 0.15 击退抗性，一个是侦察机一个是要塞**
