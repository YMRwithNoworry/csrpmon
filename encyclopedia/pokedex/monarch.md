## 设计核心

“别的纯化体在打你。**它在指挥它们打你**——而它的手能伸到四格外。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 高耸的冠状头骨，向后延伸成两片旗状结构 | Monarch 的「王冠」 |
| 眼睛 | 一整圈环列单眼，没有盲区 | 支配全场 |
| 肢体 | **一对异常修长的前肢**，长度远超身体比例 | blockRange 4.0 |
| 躯干 | 细长、直立，重心稳定 | knockbackResistance 1.0 |
| 钩足 | 下段有可攀附垂直面的钩足 | climbs = true |
| 颜色 | 暗红寄生组织 + 冠部暗紫 | SRP 模型配色 |

**动作姿势**：直立、冠部高抬、长前肢垂在身侧；攻击时前肢不做大幅动作，只是**伸出去**——距离本身是它的武器。

## SRP 特征保留

1. **PURE 层最远的接触范围**——`blockRange = 4.0D`，其余多为 1.0~2.0
2. **最高档击退抗性**——knockbackResistance **1.0**
3. **攀爬**——`Kind.MONARCH(false, true, ...)`，climbs = true
4. **不飞行**——flying = false
5. **中等护甲**——armor 10.0，是 PURE 层较低的一档
6. **方块破坏能力**——`blockHardness = 5.0F`

## 宝可梦化改造

* **`blockRange = 4.0D` 是 PURE 层唯一的极端值**（其余 1.0~2.0）。源码里这个参数决定它能触及多远，所以我把它做成了**超长触及**——它的前肢比身体还长
* **knockbackResistance 1.0 配 armor 只有 10.0** 是一个有趣的组合：它推不动，但也不抗打。我据此把它做成**站桩支配型**——靠位置和触及范围，不靠硬度
* 它与兵卒的关系：兵卒会爬、会冲，君主**会爬、会指挥**。同一层的两个攀爬者，一个当手一个当脑

## 特性

**普通特性：长距支配（longreach）**

自身使用的接触类招式**可以攻击到非邻接的目标**（触及范围视为 2 格）。对应 `blockRange = 4.0D`——PURE 层最远的触及距离。

**隐藏特性：君主威仪（monarchpresence）**

自身在场时，对手全体**无法使用先制招式**（先制度全部归零）。对应 knockbackResistance 1.0 与它「支配者」的定位——**它不动，但场面按它的节奏走**。

## 独家技能 1：君威长击 / Monarch Reach

| 字段 | 值 |
|---|---|
| 属性 | 超能 |
| 分类 | 物理 |
| 威力 | 95 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 2 格内单体 |

**效果**：**可以攻击到非邻接的目标**（触及 2 格）。命中后使目标**本回合无法使用先制招式**，且自身防御提升 1 阶段。

**触发条件**：无。

**视觉表现**：修长的前肢以极小幅度伸出，越过中间的距离直接触及目标，冠部同时微微后仰——动作幅度与攻击距离完全不成比例。

**为什么只有它**：`blockRange = 4.0D` 的翻译。**它是全族唯一「触及范围超出邻接」的招式**——别的生物要贴上来，它不用。

## 生态

* **生活环境**：感染区的建筑群与高处——它需要能俯视的位置
* **食物**：被感染的猎物
* **猎物**：不追。它让其他纯化体去追
* **天敌**：能无视触及距离的远程单位
* **行为**：驻守高处—长击—指挥。**它自己移动得很少**
* **群体**：通常单独居于高处，下方有其他纯化体活动
* **巢穴**：巢穴的**支配节点**
* **繁殖**：不繁殖，由巢穴生产
* **与其他 SRP 宝可梦关系**：与兵卒同为 PURE 层的攀爬者，但兵卒是执行者、君主是支配者
