总和 **720，全图鉴第二高**（衍化龙兽 756）。SRP 中 health **410.0** / armor **30.0** / **attackDamage 155.0** / speed **0.24** / followRange **80（全图鉴最远）**。**它没有飞行速度属性**——与衍化龙兽不同，它是地面型。

## 设计核心

“衍化龙兽是从天上来的。**麒麟是从远处走来的**——而且它能看见八十格。**”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | **独角向前伸出**，与龙兽的双角形成明确区别 | 麒麟的形态标志 |
| 眼睛 | 温和的暗金色纵瞳，不随战斗变色 | 与龙兽的 FLAME 状态对照 |
| 躯干 | **四足着地**，体型厚重、重心极低 | 地面型 |
| 体表 | 覆有鳞片与皮毛交错的复合结构 | armor 30.0 |
| 背部 | 背脊有一列节状突起，无翼 | 无飞行能力 |
| 颜色 | 深红寄生组织 + 鳞片暗金 + 毛色暗褐 | SRP 模型配色 |

**动作姿势**：四足站立、独角前指；移动时步伐缓慢但极稳，**从不奔跑**。

## SRP 特征保留

1. **全图鉴第二高攻击力**——damage **155.0**
2. **极高生命**——health **410.0**
3. **全图鉴最远的感知范围**——followRange **80**
4. **最慢速度之一**——speed **0.24**
5. **无飞行属性**——源码中没有 `FLYING_SPEED`，与衍化龙兽形成明确区别
6. **DERIVED 身份**——寄生体自行衍生出的新物种
7. **原始类名**——`KirinEntity` 直接以麒麟命名

## 宝可梦化改造

* **它和衍化龙兽共享 `armor = 30.0`，但数值完全不同**：龙兽 525/210（偏高攻），麒麟 410/155（偏均衡）
* **`followRange = 80` 是全图鉴最远**——比衍化龙兽的 64 还远。所以它的定位不是"冲过来打你"，而是**它早就看见你了**
* **它没有 `FLYING_SPEED`**——这一点与龙兽的关键区别。它只能走，但由于感知 80 格，**它在到达之前就已经锁定了你**

## 特性

**普通特性：独角感知（kirinsense）**

自身**永远不会失去目标**（对手的替换、闪避、隐匿类效果对自身无效）。对应 `followRange = 80.0D`——全图鉴最远的感知范围。

**隐藏特性：神兽步伐（mythicalstep）**

自身免疫击退与强制位移；**每回合结束时若不移动，则防御提升 1 阶段（最多 +2）**。对应它 0.24 的速度与四足厚重的体型。

## 独家技能 1：麒麟裁断 / Kirin Judgement

| 字段 | 值 |
|---|---|
| 属性 | 妖精 |
| 分类 | 特殊 |
| 威力 | 140 |
| 命中 | 100 |
| PP | 10 |
| 范围 | 单体，全场 |

**效果**：**无视距离**（followRange 80）造成伤害。**若目标距离自身 3 格以上，威力提高 25%**；若已贴身，改为使目标特防下降 2 阶段。

**触发条件**：与距离相关。

**视觉表现**：独角尖端凝聚出暗金色光点，随后射出一道笔直的光带跨越整个场地命中目标；距离越远，光带越亮。

**为什么只有它**：`followRange = 80.0D` 与 damage 155.0 的翻译。**它是全族射程最远的单体招式**——因为它看得见 80 格外的东西。

## 独家技能 2：神兽踏地 / Kirin Step

| 字段 | 值 |
|---|---|
| 属性 | 地面 |
| 分类 | 物理 |
| 威力 | 120 |
| 命中 | 95 |
| PP | 10 |
| 范围 | 自身周围 2 格 |

**效果**：对周围所有对手造成伤害并使地面类场地效果**对自身不再生效**（它把地面踩平）。副作用：自身速度下降 1 阶段。

**触发条件**：无。

**视觉表现**：四足依次重踏地面，每一踏都产生环状裂纹并向外扩散，周围地面被压平。

**为什么只有它**：speed 0.24 与四足厚重体型的翻译。**与龙兽的空中形态形成对照**：龙兽靠翅膀与火，麒麟靠**站在地上不走**。

## 生态

* **生活环境**：感染区的大地——它是地面型，从不升空
* **食物**：不需要
* **猎物**：它早在 80 格之外就已经选定
* **天敌**：几乎没有。410 点生命与 30 点护甲让它极难被击破
* **行为**：缓慢推进—锁定—裁断。**从不奔跑，也从不升空**
* **群体**：从不群居——它是单独的灾害
* **巢穴**：DERIVED 不属于巢穴体系，它是**异常进化的产物**
* **繁殖**：不繁殖。**它是寄生体自行衍生出的新物种**
* **与其他 SRP 宝可梦关系**：与衍化龙兽（`csrp:draconite`）同为 DERIVED 层的两只异常进化结果；两者共享 `armor = 30.0`
