| 46 | 10 | 88 | 20 | 74 | 8 | **246** |

总和 246。SRP 中 health 10.0 / armor 10.0 / **attackDamage 0.0** / movementSpeed **0.0** / followRange 16 / experience 0。**它的攻击力是 0.0——源码里它根本打不出伤害。** 这是全图鉴唯一一只攻击力为零的生物。

## 设计核心

“它不会咬你，也不会撞你。**它只是一直在那里**——而你在它旁边待得越久，问题就越大。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 几乎没有分化，前端只是一圈向内收拢的口器 | damage 0.0——它不咬 |
| 眼睛 | 没有眼睛，取而代之的是一圈感光带 | followRange 16 |
| 体表 | **整段躯体都植根在土里**，只有前段露出地面 | movementSpeed 0.0 |
| 环带 | 体节之间有一圈持续脉动的暗红环带 | 感染扩散的来源 |
| 根系 | 向四周延伸的寄生根须，是它唯一的作用面 | 感染地面 |
| 颜色 | 暗红寄生组织 + 泥土色 | SRP 模型配色 |

**动作姿势**：**完全静止**。整段躯干固定在原地，只有前段的环带持续脉动——它没有移动这个动作。

## SRP 特征保留

1. **攻击力为 0**——`WORM(10.0D, 10.0D, 0.0D, 0.0D, 16.0D, 0)`，第三个参数 0.0 就是 attackDamage
2. **无法移动**——`movementSpeed = 0.0`
3. **高护甲低血**——armor 10.0 但 health 只有 10.0
4. **经验值为 0**——击杀它不给经验（源码最后一个参数为 0）
5. **全部五个阻遏体都不移动**——这是这一层的共同特征

## 宝可梦化改造

* **attackDamage = 0.0 是一个极端值**，我没有给它补任何伤害。它的设计必须完全建立在**非伤害效果**上——感染、削弱、限制
* **它的种族值里攻击只有 10**，而防御 88、特防 74 是全图鉴少见的防御向分布。它靠**待在场上**产生价值
* 它与「阻遏」这个名字的关系：它不阻止你前进，它让你**停下来之后不想再动**

## 特性

**普通特性：固定植入（`anchored`）**

自身**完全无法被替换下场**，也免疫一切强制位移与击退效果；但自身也**无法主动替换**。对应 `DeterrentParasiteEntity.Kind` 中全部五个成员的 `movementSpeed = 0.0`——**这一层没有一只会移动**。

**隐藏特性：零值攻击（`zerodamage`）**

—（说明性特性）：源码中它的 attackDamage 为 **0.0**，因此本条目**不提供任何直接伤害招式**，其全部价值来自感染与削弱。

## 独家技能 1：植根封锁 / Burrow Anchor

| 字段 | 值 |
|---|---|
| 属性 | 地面 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 10 |
| 范围 | 自身周围 2 格 |

**效果**：在场地一侧展开寄生根须：此后**双方在该场地内均无法使用替换类效果**（3 回合）。同时对手全体各获得 1 层【感染】。**造成 0 点伤害**。

**触发条件**：无。

**视觉表现**：躯干周围的寄生根须同时向两侧伸展并钻入地面，地面浮现出暗红线状的根网，缓慢搏动。

**为什么只有它**：attackDamage **0.0** 与 movementSpeed **0.0** 的组合翻译。**它是全族唯一以「封锁场地」为唯一作用的招式**——一个打不出伤害的东西，只能改变规则。

## 生态

* **生活环境**：感染区的地表——它生根的位置就是它的全部领地
* **食物**：通过根须吸取周围养分
* **猎物**：无。**它不狩猎**
* **天敌**：任何东西。10 点生命、0 点攻击、0 速度
* **行为**：**完全静止**。扩张、脉动、扩散——仅此而已
* **群体**：通常成片植入，彼此根须连接
* **巢穴**：巢穴的外围**植入体**
* **繁殖**：通过根须分裂，而非繁殖
* **与其他 SRP 宝可梦关系**：五个阻遏体之一；与其余四个共享 `movementSpeed = 0.0`
