总和 574。SRP 中 health 310.0 / armor 15.5 / damage 70.0 / speed 0.28 / knockbackResistance 2.0 / followRange 80 / blockRange 5.0。**与 `BOGLE` 逐项完全相同**。区分在于一个计数器：**`wraithProjectileCount`**——它在 `ELVIA_BALL` 与 `ELVIA_NADE` 之间交替。

## 设计核心

“波格尔每次都用同一种。**幽魂会换**——一发球，一发雷，再一发球。”

**动作姿势**：滞空高度与波格尔相同，但发射时会有一次明显的"停顿—切换"动作——两组弹药腔交替工作。

## SRP 特征保留

1. **交替弹种**——`if (activeKind() == Kind.WRAITH) { wraithProjectileCount++; }` 与 `else if (wraithProjectileCount >= 1) { mode = Mode.ELVIA_NADE; } else { mode = Mode.ELVIA_BALL; }`
2. **专用计数器**——`wraithProjectileCount`，波格尔没有这个字段
3. **共享发射参数**——`LegacyProjectileAttackGoal(60, 30, 3)`
4. **完全免疫击退**——knockbackResistance **2.0**（超过 1.0）
5. **最远的感知范围**——followRange **80**
6. **最远的方块触及**——`blockRange = 5.0D`
7. **飞行**——`flying = true`
8. **共享的目标组**——`PreeminentChargeAttackGoal` / `LegacyProjectileAttackGoal(60, 30, 3)` / `PreeminentRandomFlightGoal`

## 宝可梦化改造

* **`wraithProjectileCount` 是一个只属于幽魂的字段**——波格尔没有。它存在的唯一目的就是让弹药在球体与雷体之间交替
* 所以我把它设计成**交替型**：一发球、一发雷、再一发球。**同样的数值，完全不同的节奏感**
* 它与波格尔是同一层里最典型的一对"数值相同、机制不同"——这也是本项目第五次遇到这种情况，而这次连目标组都完全相同，**唯一的区别就是那三行弹药代码**

## 特性

**普通特性：交替装填（alternateloading）**

自身使用的投射物招式**自动交替两种形态**：第一次为普通弹（无附加效果），第二次为**雷弹**（威力 -20% 但命中后使目标速度下降 1 阶段）。对应 `wraithProjectileCount` 的交替逻辑。

**隐藏特性：计数交替（counterswitch）**

—（说明性特性）：源码中幽魂拥有专属字段 `wraithProjectileCount`，波格尔没有。该字段唯一的作用就是驱动弹药交替。

## 独家技能 1：幽魂交替投掷 / Elvia Alternating Throw

| 字段 | 值 |
|---|---|
| 属性 | 幽灵 |
| 分类 | 特殊 |
| 威力 | 75 |
| 命中 | 95 |
| PP | 10 |
| 范围 | 单体，全场 |

**效果**：**连续攻击 3 次**，但三次的形态不同：**第 1 发为普通弹**（威力 75）、**第 2 发为雷弹**（威力 60，命中后目标速度下降 1 阶段）、**第 3 发为普通弹**。对应 `ELVIA_BALL → ELVIA_NADE → ELVIA_BALL` 的交替。

**触发条件**：无。

**视觉表现**：第一发是暗蓝色的球体，第二发换成拖着暗紫尾迹的雷体并在命中处炸开，第三发又变回球体——三发的形态肉眼可辨。

**为什么只有它**：`wraithProjectileCount` 交替逻辑的逐字翻译。**与波格尔的定式弹幕形成直接对照**：同样 3 发，波格尔三发一样，幽魂一发一换。

## 独家技能 2：幽魂过载 / Elvia Overload

| 字段 | 值 |
|---|---|
| 属性 | 幽灵 |
| 分类 | 特殊 |
| 威力 | 120 |
| 命中 | 90 |
| PP | 5 |
| 范围 | 单体，全场 |

**效果**：**把两种弹体合并成一次投射**：造成高额伤害并使目标速度下降 2 阶段。**使用后本招式进入 2 回合冷却**（需要重新装填两种弹体）。

**触发条件**：无。

**视觉表现**：两组弹药腔同时开启，球体与雷体在半空中并合成一发拖着双重尾迹的投射物，命中后同时产生爆炸与持续电流。

**为什么只有它**：幽魂拥有波格尔没有的 `wraithProjectileCount` 字段，其唯一作用就是驱动 `ELVIA_BALL` 与 `ELVIA_NADE` 的交替。主招式表达交替，**这一招表达把两种弹药合并使用**——同一个身体，两种装填策略。
