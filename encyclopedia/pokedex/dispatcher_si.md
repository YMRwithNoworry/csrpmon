## 设计核心

“召唤柱把东西放出来。**调度柱把东西收起来**——然后在你身后铺一层雾。”

## 视觉设计

| 部位 | 设计 | 来源 |
|---|---|---|
| 头部 | 柱顶的膨大核心，表面有 4 个收容口 | bombCount = 4 |
| 眼睛 | 核心四周环列一圈暗红光点，朝向内侧 | 收纳而非放出 |
| 躯干 | 柱状躯体植根地面，下段埋入土中 | 柱体形态 |

**动作姿势**：**完全静止**。核心缓慢旋转，收容口与雾孔按 40 tick 的固定间隔交替工作。

## SRP 特征保留

1. **收纳职能**——`storeNearbyParasite()`：以 `FOLLOW_RANGE` 为范围搜索附近的寄生体，并把它们的实体 ID 存入 `storedParasiteIds`
2. **铺雾职能**——`placeNestFog(stage)`：`count = Math.min(3, 1 + stage)`，即一阶铺 2 块
3. **固定工作节奏**——`if (activeKind.family == Family.DISPATCHER && tickCount % 40 == 0)`
4. **雾的高度范围**——`DISPATCHER_FOG_MIN_Y_OFFSET = -2` 到 `MAX_Y_OFFSET = 4`

## 宝可梦化改造

* **它和召唤柱用的是同一张数值表**（同阶 health/armor/damage/bombCount/activeCap 完全同构）。**家族行为才是区分点**：召唤柱释放，调度柱收纳
* **`storeNearbyParasite()` 会把实体 ID 写进 `storedParasiteIds`**——也就是说它**记得**附近有谁。我把它做成"记录"机制：它把见过的东西存起来，之后再放出来
* **铺雾的块数是 `min(3, 1 + stage)`**——一阶只有 2 块，三阶起就封顶 3 块。这说明雾的**强度靠半径而不是数量**增长

## 特性

**普通特性：收容记录（storeids）**

自身每回合结束时，把对手场上一只宝可梦的**招式属性记录一次**（最多记录 3 条）。**记录过的属性在本次战斗中对该对手额外生效 15% 伤害**。对应 `storedParasiteIds` 与 `storeNearbyParasite()`。

**隐藏特性：雾幕（nestfog）**

自身入场时铺设**雾幕**（持续 4 回合）：雾幕内对手的命中率下降 10%，且**场地类效果无法被清除**。对应 `placeNestFog(stage)` 的 `count = min(3, 1+stage)`。

## 独家技能 1：雾幕铺设 / Nest Fog

| 字段 | 值 |
|---|---|
| 属性 | 幽灵 |
| 分类 | 变化 |
| 威力 | - |
| 命中 | 必中 |
| PP | 10 |
| 范围 | 自身周围 3 格 |

**效果**：在场上铺设 **2 处**雾幕（对应 `count = min(3, 1 + stage)`，一阶为 2）：雾幕内对手命中率下降 10%，且**我方场地效果在雾幕内无法被清除**。持续 3 回合。造成 0 点伤害。

**触发条件**：无。

**视觉表现**：柱体中段的雾孔同时开合，向四周喷出两团缓慢扩散的暗红色雾，雾体贴近地面并沿地形蔓延（对应高度偏移 -2 到 4）。

**为什么只有它**：`placeNestFog(stage)` 与 `DISPATCHER_FOG_MIN_Y_OFFSET/MAX_Y_OFFSET` 的翻译。**与召唤柱的对照最直接**：它不放出生物，它改变战场。

## 生态

* **生活环境**：感染区的地表——与召唤柱占据同类位置，但职能相反
* **食物**：通过根部吸取养分
* **猎物**：无。它不狩猎
* **天敌**：任何东西。33 点生命、3 点攻击、0 移动
* **行为**：**完全静止**。收纳—铺雾—再收纳。每 40 tick 一次
* **群体**：周围通常有被它收纳后又放出的个体
* **巢穴**：**巢穴的遮蔽层**，九阶体系第一环
* **繁殖**：不繁殖，通过收纳与释放扩张
* **与其他 SRP 宝可梦关系**：**DISPATCHER 家族第一阶**；与 BECKON 家族共用数值表但行为完全不同（收纳 vs 召唤）
